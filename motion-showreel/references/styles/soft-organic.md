# 柔光有機（soft-organic）

> 溫暖的顆粒漸變、慢慢變形的有機形狀、優雅的襯線斜體：畫面像清晨的光，安靜、親密、讓人放鬆。
> 參照（只學語法）：生活方式和健康品牌的動態識別、顆粒漸變海報、有機形態的當代平面設計、人文主義的編輯排版。不照搬具體品牌。

## 本質 / 不是什麼
- 本質：**溫度和呼吸感**。顏色像光一樣柔和地過渡，形狀像生物一樣緩慢變形，排版有人文氣息；運動慢、軟、沒有稜角，整體節奏像呼吸。
- 不是：AI 預設的紫粉漸變（沒有顆粒、沒有光源、飽和度太高、到處發光）；也不是 `liquid-shader` 的液態金屬和融球（那是強反光、強結構的）。

## 辨識訊號：每支片子挑 2–3 個
| 訊號 | 長什麼樣 | 適合的主題 |
|---|---|---|
| 顆粒漸變 | 兩三個顏色柔和過渡，表面有明顯的細顆粒 | 背景、情緒 |
| 有機形狀 | 圓潤不規則的團塊，緩慢變形 | 生命、成長 |
| 襯線斜體 | 優雅的襯線斜體大標題 | 品牌、宣言 |
| 彌散光斑 | 畫面一角一團柔和的光，緩慢移動 | 清晨、希望 |
| 紙張與布料 | 微微的紙紋、亞麻或棉布的紋理 | 手工、自然 |
| 植物剪影 | 葉子、花枝的柔和剪影或投影 | 自然、健康 |
| 細線插畫 | 極細的單線勾勒的人物或物件 | 人文、生活 |
| 圓角卡片 | 柔和投影的圓角卡片承載資訊 | 產品、功能 |
| 大留白 | 一屏只有一句話和一個形狀 | 剋制、高階 |
| 呼吸的圓 | 一個圓緩慢地放大縮小 | 冥想、專注 |
| 晨昏色溫 | 顏色隨時間從冷到暖或從暖到冷 | 一天、變化 |

規則：
- 每支挑 2–3 個，至少一個不在下面「最俗的版本」裡。
- 訊號從主題裡選，不按順序全上。
- 顆粒是這種風格防止滑向 AI 漸變的關鍵：漸變一定要帶顆粒（`--grain`），光要有方向和來源。

## 這個風格最俗的版本
- 畫面：粉橙紫的大漸變背景、幾個模糊的彩色光球慢慢飄、正中一句白色細體字、結尾 logo 淡入。
- 聲音：鋼琴單音加大混響的環境鋪底。
- brief 的 style 一欄寫明這支片子翻掉了哪幾條，或者為什麼刻意保留（比如使用者要的就是經典版）。保留時，把力氣花在構圖、鏡頭、節奏或一個意外的記憶點上。

## 適配
- 用途：品牌情緒片、生活方式和健康類產品的宣傳、App 的功能介紹、節日問候、Logo 演繹。
- 內容：健康、冥想、護膚、睡眠、心理、金融科技的「安心感」、女性向品牌、人文主題。
- 不適合：需要能量和衝擊的主題；硬核科技、遊戲。

## 技術路線
WebGL 片元著色器做漸變和有機形狀：漸變用幾個移動的高斯光源疊加（不是線性漸變），有機形狀用 SDF 加低頻噪聲擾動邊界；或者 Canvas 2D 用大半徑的徑向漸變疊加、`filter: blur()` 做柔化（先測速度）。文字和卡片用 DOM 或 Canvas 疊在上面。顆粒一定加：`--grain 4–8`。

## 材質與渲染
- 漸變：2–4 個顏色，用 OKLab 插值（不會在中間變灰或變髒）；顏色之間的過渡寬而軟。
- 光：一個主光源方向，光斑在一角，另一角稍暗，像窗邊的自然光。
- 有機形狀：邊界用低頻噪聲（頻率低、幅度小）緩慢擾動；不同形狀的變形週期錯開。
- 顆粒：細、均勻、單色（不要彩色噪點），在暗部稍明顯。
- 卡片：大圓角、很淺的投影，背景色比畫面略亮。

## 配色
下面的色值是示例，看思路，不要原樣照抄。
- 晨光：奶油 `#FFF4E6` / 杏 `#F7C59F` / 玫瑰灰 `#D8A7B1` / 墨 `#3A2E2A`
- 鼠尾草：米白 `#F4F1EA` / 鼠尾草綠 `#A3B18A` / 陶土 `#C97C5D` / 深綠 `#344E41`
- 暮色：霧藍 `#C9D6DF` / 薰衣草灰 `#B8A9C9` / 暖橙 `#E8A87C` / 深藍 `#22303C`
- 推導：從品牌色出發，降低飽和度、提高明度，再在 OKLab 裡找兩個相鄰的暖色或冷色做漸變；文字用深色（不是純黑）。所有顏色的飽和度都比你想的低一檔。粉橙紫是最常見的那組。

## 字型
- 標題：襯線斜體或優雅的襯線體（Instrument Serif、Fraunces 的斜體、Cormorant、Playfair Display）；中文用思源宋體或霞鶩文楷。
- 正文和標籤：人文主義無襯線（Inter、DM Sans、Manrope）。
- 字號對比大，字重輕；字距略放寬。

## 運動
- 慢：主要元素的進場 0.8–1.5 秒，用 `glide` 或彈簧 `{1.2, 1.0}`（無回彈）。
- 有機形狀的變形週期 6–12 秒，漸變的光源移動更慢。
- 字的進場：從輕微模糊和下方 10–20px 處浮上來，透明度和模糊同時變化。
- 幾乎不用硬切；段落之間用顏色的流動或形狀的變形過渡。

## 畫面怎麼活
- 漸變的光源緩慢移動，顏色像天光一樣變化；有機形狀輕輕呼吸、變形。
- 顆粒隨時間變化（`--grain` 的時間噪聲），讓平塗區域也有生命。
- 文字落定後不動，留給觀眾讀。

## 鏡頭語法
| 鏡頭運動 | 表達什麼 | 適合哪類內容 |
|---|---|---|
| 幾乎不動，形狀自己變化 | 平靜、專注 | 冥想、品牌 |
| 極慢的推近 | 親密、靠近 | 人物、情緒 |
| 橫移穿過前景的植物剪影 | 自然、日常 | 生活方式 |
| 從一個形狀里拉出 | 原來如此 | 揭示 |

## 聲音調色盤
溫暖柔軟的音色：`pad`（voices 少、cents 小、lowpass 低）、`mallet({ material: 'kalimba' })` 或 `'vibes'`、`pluck`（bright 低）；環境聲 `ambience({ kind: 'rain' })` 或鳥鳴質感的鋪底。第 2 檔的鋼琴取樣很合適。

律動與和聲（舉例，不止這些）：無鼓或只有很輕的手鼓和 shaker；大七和絃、九和絃、Lydian；慢速的 lo-fi 律動；或者完全沒有節拍，只有鋪底和幾個音符。混響大而柔，不側鏈。

## 原生手法
- 一個形狀緩慢變形成 logo：適合品牌出場。
- 色溫從冷到暖流過整個畫面，換到下一段：適合轉場和「一天」類結構。
- 一個呼吸的圓，文字跟著它的節奏出現：適合冥想、專注、引導。
- 光斑掃過一行字，字從光裡顯現：適合標題。
- 粉橙紫大漸變加模糊光球：經典，也最容易滑向 AI 預設味。

## 變化空間
- 結構：從清晨到夜晚的一天；一次呼吸（吸氣 → 停 → 呼氣）；一顆種子長成一株植物；三句話，每句一種色溫。
- 開場：一團光從畫面一角慢慢亮起；一個形狀從一個點長出來。
- 結尾：所有形狀融成 logo；光慢慢暗下去，只剩一句話。

## 坑
- 滑向 AI 預設的紫粉漸變：降低飽和度、加顆粒、讓光有方向、用溫暖的中性色打底。
- 漸變出現色帶（banding）：OKLab 插值 + `--grain`，必要時 `--crf 14`。
- 太慢太空，資訊出不來：每 3–4 秒至少有一個清楚的資訊點。
- 著色器在軟體渲染下很慢：先測單幀耗時。
- 文字太細太淺，手機上看不清：正文字號和對比度要在手機抽幀圖裡檢查。
