# 終端 / ASCII（terminal-ascii）

> 一切由等寬字元組成：命令列在打字、ASCII 圖形在流動、遊標在閃，冷靜又極客。
> 參照（只學語法）：命令列介面、ASCII art、demoscene 的文本模式作品、駭客電影的終端畫面（只取好的部分）。

## 本質 / 不是什麼
- 本質：**字元網格就是像素**；圖形用字元密度（` .:-=+*#%@`）表達明暗；文本真的按字元逐個出現；遊標是節奏器。
- 不是：綠色字元雨的陳詞濫調；也不是滿屏無意義的滾動程式碼。

## 辨識訊號：每支片子挑 2–3 個
| 訊號 | 長什麼樣 | 適合的主題 |
|---|---|---|
| 逐字打出的命令 | 提示符後的字一個個出現，回車後輸出 | 工具、安裝、一條命令 |
| ASCII 明暗圖 | 用字元密度畫出的圖形或 logo | 落版、圖形 |
| 遊標 | 閃爍的塊遊標或下劃線遊標 | 節奏、等待 |
| 字元進度條 | `[#####     ] 50%` 這類進度 | 構建、下載 |
| 日誌滾動 | 帶時間戳的日誌一行行往上冒 | 執行、監控 |
| TUI 面板 | 用製表符畫的邊框、分欄、選單 | 儀表盤、管理工具 |
| diff 著色 | 紅色刪除行、綠色新增行 | 程式碼變更、修復 |
| 目錄樹 | ├── 和 └── 組成的樹狀結構 | 專案結構 |
| 表格輸出 | 對齊的列、表頭分隔線 | 資料、對比 |
| 磷光屏 | 琥珀色或綠色單色屏，帶一點餘輝 | 復古、硬體 |
| 多窗格 | 幾個終端窗格並排同時滾動 | 並行、協作 |

規則：
- 每支挑 2–3 個，至少一個不在下面「最俗的版本」裡。
- 訊號從主題裡選，不按順序全上。
- 命令和輸出要真實，問使用者要或者用真實可執行的命令。

## 這個風格最俗的版本
- 畫面：黑底綠字、字元雨、滿屏滾動的假程式碼、結尾「ACCESS GRANTED」。
- 聲音：機械鍵盤聲、低頻嗡鳴、電子嗶聲。
- brief 的 style 一欄寫明這支片子翻掉了哪幾條，或者為什麼刻意保留（比如使用者要的就是經典版）。保留時，把力氣花在構圖、鏡頭、節奏或一個意外的記憶點上。

## 適配
- 用途：開發者產品的宣傳短片、片頭、Logo 演繹、作品集的一段。
- 內容：CLI 工具、AI agent、開源專案、安全、資料。

## 技術路線
Canvas 2D，固定字元網格（比如 1920×1080 下 120×45 格，按字型度量計算格子寬高）。把要顯示的圖形先畫到一塊離屏畫布，按格子取樣亮度對映到字元。打字效果按 t 計算已顯示的字元數。可選 CRT 後期（`crt-vhs.md`）。

## 材質與渲染
- 字元逐格對齊，字號統一（可以有一個更大的標題網格）。
- ASCII 圖形：取樣亮度 → 字元表；可以按亮度給不同的顏色深淺。
- 遊標：塊狀遊標，按 0.53 秒的週期閃爍（用 t 計算，不用計時器）。
- 命令輸出要像真的：路徑、提示符、引數都用使用者產品的真實命令（問使用者要，不要編）。

## 配色
下面的色值是示例，看思路，不要原樣照抄。
- 黑 `#0C0C0C` / 淺灰 `#D0D0D0` / 綠 `#5FD75F` / 黃 `#FFD75F`（標準終端配色的子集）
- 暖黑 `#1C1B19` / 米白 `#E8E3D3` / 橙 `#FF8C3B`（復古琥珀屏）
- 淺色終端：`#F6F6F2` / `#1E1E1E` / 藍 `#2F6FEB`
- 規則：語義配色（成功綠、警告黃、錯誤紅），不用於裝飾。
- 推導：終端配色本身就有語義（成功綠、警告黃、錯誤紅）；底色可以是黑、暖黑、淺色終端或品牌色的深版，強調色從品牌來。黑底綠字是最常見的那組。

## 字型
JetBrains Mono、IBM Plex Mono、Fira Code、Space Mono（OFL）。全片只用一種等寬字型。

## 運動
- 打字：每字元 20–45 毫秒，標點後稍停；命令回車後輸出一次性或分塊出現。
- ASCII 圖形的變化：每幀重新取樣，圖形本身可以平滑變化（字元是離散的，看起來會自然地「顆粒化」）。
- 滾動：整行向上跳，不做平滑滾動（終端就是這樣的）。

## 畫面怎麼活
- 遊標每 0.5 秒閃一次；日誌在後臺一行行往上冒；一個字元進度條 `[####    ]` 在走。
- ASCII 圖形裡留一小塊區域持續重取樣流動，其餘字元不動，眼睛才有落點。

## 鏡頭語法
| 鏡頭運動 | 表達什麼 | 適合哪類內容 |
|---|---|---|
| 固定終端視窗 | 真實的操作 | 命令演示 |
| 推近到一個字元，它變成下一個畫面 | 進入 | 轉場 |
| 拉遠，一個終端變成許多終端的陣列 | 規模、並行 | agent、分散式 |

## 聲音調色盤
鍵盤聲（短 `click` 不同音高隨機但固定種子）、回車聲、低沉的 drone、少量的 `blip`。第 1 檔合成即可。

律動與和聲（舉例，不止這些）：無拍（打字的節奏就是節奏），或者機械的十六分音符；一個和絃、持續低音、全音階；擬音主導很合適，底下鋪 `ambience({ kind: 'room' })`，要晶片味可以加 `crush`。

## 原生手法
- 一行命令執行後，ASCII 圖形從輸出裡生長出來：適合「一條命令完成一件事」。
- 字元網格整體變成一個 logo 的明暗圖：適合結尾落版。
- 多個終端同時滾動，再合併成一個：適合並行 / 協作。

## 變化空間
- 結構：一次安裝到成功的過程；一個 agent 的一次任務；一個 bug 從報錯到修好。
- 開場：一個閃爍的遊標；`$` 提示符後的第一個字。
- 結尾：最後一行輸出「✓」後，字元網格組成 logo。

## 坑
- 編造命令和輸出：命令要真實可用，問使用者要。
- 綠字元雨等陳詞濫調。
- 字號太小，手機上看不清：主要的命令列至少 28px（1080p）。
