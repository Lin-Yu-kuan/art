# 透光皮影（shadow-puppet）

> 染色皮革與鏤空紋樣在背光幕布上顯出形象，關節和操縱桿讓人物以清楚的側影表演。
> 參照（只學語法）：中國皮影的刻制、染色與操縱、幕布背光舞臺、關節偶的表演方式。不照搬具體流派的整套人物、傳統戲目造型或唱段。

## 本質 / 不是什麼

- 本質：**用透光材料、鉸接動作和幕面投影完成表演**。皮革色層過濾背光，鏤空處透出幕色，重疊部位更暗；人物的轉動從肩、肘、髖等連線處發生。
- 不是：`paper-cut` 的紙層厚度與投影，也不是純黑剪影動畫。這裡強調染色皮革透光、關節操縱與幕面距離，紙張纖維和立體書翻頁不承擔核心表現。

## 辨識訊號：每支片子挑 2–3 個

| 訊號 | 長什麼樣 | 適合的主題 |
|---|---|---|
| 透光染色 | 皮革透出溫暖色彩，厚處與疊層更暗 | 文化、人物、工藝 |
| 鏤空花紋 | 小孔、細縫與紋樣透出幕布亮色 | 材料、身份、細節 |
| 側身造型 | 側臉與側向動作構成清楚的剪影 | 對話、行進、表演 |
| 關節鉸接 | 肢體圍繞圓點轉動，分片形狀保持剛性 | 動作、協作、器物 |
| 操縱桿 | 細杆連線手部或身體，傳遞動作方向 | 幕後、製作、控制 |
| 疊片加深 | 手臂經過身體前後時色彩變深 | 層次、接觸、表演 |
| 離幕虛化 | 遠離幕布的片變軟，靠近後變清楚 | 出場、退場、情緒 |
| 幕面織紋 | 微弱纖維與不完全均勻的背光 | 舞臺、手作、空間 |
| 橫向舞臺排程 | 人物從兩側進入，動作在同一臺口展開 | 相遇、對話、旅程 |
| 場景片換景 | 樹、門、建築等平面片移動，改變地點 | 故事、章節、空間 |

規則：

- 每支挑 2–3 個，至少一個不在下面「最俗的版本」裡；訊號從主題裡選。
- 操縱桿可以按觀看角度顯露或隱藏，關節邏輯始終成立。現代人物與器物也可以製成皮影，不必預設傳統戲曲角色。

## 這個風格最俗的版本

- 畫面：泛黃幕布、紅黑武將、戲臺花邊，兩個人揮刀交手，最後一張紅印收尾。
- 聲音：鑼鼓不停，每抬一下手都配一下鑼，背景加來源不明的戲曲唱腔。
- brief 的 style 一欄寫明翻掉了哪幾條，或者為什麼保留經典版。可從日常相遇、器物合作或一隻皮影的製作過程入手。

## 適配

- 用途：文化工藝宣傳、故事向品牌片、原理講解、Logo 演繹、舞臺式循環。
- 內容：人物關係、傳承、控制與協作，以及適合側向動作表達的情節。
- 不適合：自由環繞的三維動作、精細麵部演技、密集 UI 操作和長篇圖表說明。

## 技術路線

- **分片與鏤空**：SVG、Canvas 都適合封閉輪廓與孔洞；Paper.js 可輔助紋樣求交和裁切。每個活動肢體作為獨立剛性片，明確連線點。
- **透光合成**：Canvas 或 PixiJS 可探索色片透光、疊層變暗與幕布紋理。合成方法先用兩片相疊的小樣驗證，不能直接透明疊加到發白。
- **距離與投影**：固定舞臺可用分層模糊和縮放近似；需要展示燈、偶和幕的位置時，再探索 Three.js 的平面幾何與投影。近似效果也應遵守一致的光源關係。
- 關節、操縱桿端點、離幕距離和背光按時間獨立還原，皮紋與幕紋固定種子。`--dpr` 先保鏤空孔與細杆；`--subframes` 從輕，`--grain` 不疊加到遮住紋樣。

以上是候選路線，不規定骨架結構、透光著色和投影實現。

## 材質與渲染

- 工藝依據：皮料刮薄、刻出孔紋、染色後分片連線，借背光在幕上顯形。先處理厚薄、孔洞與關節，再加舊物痕跡。
- 鏤空處顯示幕布本色，染色片保留透光感；較厚的輪廓、接頭和多層重疊更暗，不應都用一樣的不透明度。
- 孔洞與細橋的寬度要經得住最終尺寸，不能刻到整個主體碎成難以辨認的噪點。紋樣順著服裝和器物結構排列。
- 肢體片保持剛性，關節轉動可略有操縱的停頓。彎腰、揮手由分片和連線表達，不能像橡皮管一樣任意拉長。
- 明確燈、偶、幕的相對位置。離幕導致的大小與虛實變化應成組發生；幕紋固定在幕上，皮紋隨偶移動。

## 配色

下面的色值是示例，看思路，不要原樣照抄。

- 暖幕與硃色：幕 `#EAD4A5` / 皮色 `#A34A32` / 輔色 `#8D743D` / 厚邊 `#3E3027`。
- 象牙與青綠：幕 `#EDE3C9` / 皮色 `#4D7B6A` / 輔色 `#BA794A` / 厚邊 `#303F38`。
- 暗臺琥珀：環境 `#2C2926` / 亮幕 `#D7BB83` / 皮色 `#874D3E` / 強調 `#B39348`。
- 推導：先定幕色與燈色，再選穿過背光後仍可區分的皮料色組。品牌色可用於主要分片，疊層要自然變深；避免高飽和發光邊把皮革變成霓虹。

## 字型

中文展示可用思源宋體，輔助用思源黑體；英文可用 Alegreya 或 Libre Baskerville，自託管 OFL 字型。標題可作為獨立題簽或幕外說明，長字幕保持平穩清晰。鏤空字只適合短字與大字號，不把細小正文切成花紋。

## 運動

- 先確定身體的支撐和手中物件，再安排關節角度。動作有提、送、停的操縱感，不能每個關節同時自由搖擺。
- 人物多沿橫向舞臺移動，轉身可借換面、遮擋或短暫退幕後完成；不強行把側臉平面轉成三維頭部。
- 進場可以從幕邊、虛影或場景片後出現；退場也沿舞臺或離幕方向完成。擊打和接觸短促，閱讀與反應留停頓。

## 畫面怎麼活

- 停住時，手或操縱桿末端可有極小的餘擺，身體主姿態穩定。
- 背光允許緩慢、低幅變化，幅度不影響字幕和人物識別，不能整屏頻閃。
- 一片旗、枝葉或燈穗做稀疏擺動，其他佈景安靜；幕布紋理不遊走。

## 鏡頭語法

| 鏡頭運動 | 表達什麼 | 適合哪類內容 |
|---|---|---|
| 正面固定的舞臺全景 | 動作與人物關係 | 相遇、協作、故事 |
| 輕推到手與關節 | 如何操縱、如何接觸 | 工藝、控制、細節 |
| 沿幕面橫移 | 地點與人物行進 | 旅程、章節 |
| 從幕前轉到幕側的有限揭示 | 表演背後的材料與人力 | 製作、傳承、幕後 |

## 聲音調色盤

第 1 檔可用手鼓、木質敲擊、短撥絃與很輕的皮料摩擦噪聲。需要真實鑼鼓、傳統器樂或操縱擬音時，用第 2 檔 Tone.js 配合授權取樣，音色與題材相符。唱腔不作為預設裝飾；有口播時只在動作落點和段落間保留少量打擊。

律動與和聲（舉例，不止這些）：有問答與停頓的打擊節奏、安靜的撥絃敘事，或簡潔的現代環境音樂。劇烈動作與日常場景可以有不同密度，避免整片持續敲鑼。

## 原生手法

- 人物貼近幕布，由虛影變成清楚的鏤空色片：適合出場和首次揭示（經典）。
- 兩片重疊變暗，再分開露出各自紋樣：適合相遇、分工與關係變化。
- 操縱桿的動作傳到手中物件，再帶動另一個主體：適合控制、協作和連鎖。
- 場景片橫向換入，人物繼續沿同一臺口行動：適合旅程和章節交接。
- 鏡頭轉到幕側露出分片與燈，再回幕前看完整形象：適合工藝和幕後解釋。

## 變化空間

- 結構：圍繞兩者的一次相遇；跟隨一個角色換景；先看錶演，再逐層揭示製作方式。
- 開場：只有一隻手的虛影；幕上已有場景，角色從遮擋後出現；一塊未連線的皮片被提起。
- 結尾：人物退到幕邊留下佈景；動作停在關係明確的姿態；背光收弱，最後保留一個可讀輪廓。

## 坑

- 全部做成純黑剪影：檢查透光色、孔洞和疊層是否可見。
- 疊片越疊越亮：重新校準透射與遮光關係，不用加亮混合代替背光。
- 肢體像軟膠拉伸：保持分片剛性，動作從關節發生。
- 杆端與手脫開：操縱桿連線點隨關節一同求取。
- 鏤空過細，壓縮後只剩噪點：減少紋樣密度，優先保住輪廓。
- 遠離幕布只加模糊，尺度關係卻矛盾：按同一光源位置處理大小與虛實。
- 幕紋跟人物一起移動：把幕、皮料、燈光分開處理。
- 傳統符號與故事無關：從當前主題設計主體，不用戲曲服飾替代角色塑造。
