# 國潮紋樣（guochao）

> 傳統紋樣、器物和色彩，用現代的版式和節奏重新排一遍：祥雲、回紋、描金、硃紅，既有年味和古意，又像一張潮牌海報。
> 參照（只學語法）：中國傳統紋樣（雲紋、回紋、海水江崖、纏枝）、傳統色體系、年畫和門神的造型、近年國貨品牌和節慶營銷的視覺。不照搬具體品牌的設計、文物的高畫質原圖和受版權保護的插畫。

## 本質 / 不是什麼
- 本質：**傳統的「料」，現代的「做法」**。紋樣、器物、色彩來自傳統，但構圖、字型、節奏和動效是當代的：大面積色塊、強對比、網格排版、利落的轉場。
- 不是：水墨寫意（那是 `ink-wash`，講留白和墨的行為）；也不是把龍鳳、燈籠、中國結堆滿畫面的春晚背景板。

## 辨識訊號：每支片子挑 2–3 個
| 訊號 | 長什麼樣 | 適合的主題 |
|---|---|---|
| 祥雲 | 捲曲的雲紋，線條圓潤，成組出現 | 吉祥、天空、開場 |
| 回紋 / 萬字紋 | 方折連續的邊框紋 | 邊框、轉場、秩序 |
| 海水江崖 | 層層疊疊的弧形浪紋 | 底部裝飾、氣勢 |
| 描金線 | 細金線勾出的輪廓和邊框 | 高階、禮盒、節慶 |
| 傳統色大色塊 | 硃紅、黛藍、松綠、鵝黃的平塗大塊 | 品牌、海報 |
| 年畫造型 | 胖娃娃、門神、圓潤飽滿的人物 | 春節、喜慶 |
| 器物剪影 | 瓷瓶、鼎、扇面、燈籠的幾何化輪廓 | 文化、產品 |
| 印章與篆刻 | 方印、朱文白文 | 落款、認證 |
| 窗欞與月門 | 格子窗、圓形月亮門做畫框 | 轉場、框景 |
| 纏枝花紋 | 連續的藤蔓花卉紋樣 | 裝飾、生長 |
| 豎排書法標題 | 豎排的毛筆字或宋體大字 | 標題、文案 |
| 現代撞色 | 傳統紋樣配熒光色或高飽和撞色 | 潮流、年輕 |

規則：
- 每支挑 2–3 個，至少一個不在下面「最俗的版本」裡。
- 訊號從主題裡選，不按順序全上。
- 紋樣要畫對：回紋是方折連續的，祥雲有固定的捲曲結構。不確定的紋樣寧可不用，也不要畫成似是而非的花邊。

## 這個風格最俗的版本
- 畫面：大紅底、金色祥雲從兩邊飄進來、燈籠和中國結掛在角上、中間一個書法「福」字、結尾煙花。
- 聲音：鑼鼓嗩吶的喜慶曲加鞭炮聲。
- brief 的 style 一欄寫明這支片子翻掉了哪幾條，或者為什麼刻意保留（比如使用者要的就是經典版）。保留時，把力氣花在構圖、鏡頭、節奏或一個意外的記憶點上。

## 適配
- 用途：節慶營銷（春節、中秋、端午）、國貨和新消費品牌的宣傳片、Logo 演繹、文創產品、活動開幕。
- 內容：茶飲、食品、美妝、文旅、遊戲、傳統工藝的現代表達。
- 不適合：需要剋制理性的科技和資料主題；需要國際化、去地域化表達的品牌。

## 技術路線
Canvas 2D 或 SVG。紋樣做成可複用的路徑函式（一個雲紋單元、一個回紋單元），按網格或路徑平鋪；描金用細線加一道沿線移動的高光；需要紙本質感時，在底色上疊一層很淡的宣紙或絹的紋理。紋樣平鋪的取模週期必須等於單元的真實週期，否則滾動時會跳。

## 材質與渲染
- 紋樣單元：先畫一個標準單元，再旋轉、映象、平鋪；線寬統一，轉角處理一致。
- 描金：金不是黃色，是一組漸變（暗金 → 亮金 → 白高光），高光只沿線走，不鋪滿面。
- 色塊：平塗，邊緣乾淨；需要層次時用同色系深淺，不用漸變。
- 年畫人物：圓潤飽滿，輪廓線粗細一致，臉頰兩團腮紅。
- 質感：可選宣紙纖維、絹的細紋、漆器的光澤，三選一，全片統一。

## 配色
下面的色值是示例，看思路，不要原樣照抄。
- 硃紅金：硃紅 `#C8102E` / 暗金 `#B8860B` / 亮金 `#E9C46A` / 墨 `#1C1A17` / 宣紙 `#F3EBDD`
- 青綠山水：黛藍 `#1E3A5F` / 松綠 `#2E8B57` / 石青 `#5B9BD5` / 赭石 `#A0522D` / 米白 `#F5F0E6`
- 潮流撞色：鵝黃 `#F6C445` / 胭脂 `#E03C6E` / 孔雀藍 `#0F7C8C` / 黑
- 推導：從中國傳統色裡選 2–3 個做主色（硃紅、黛藍、松綠、鵝黃、藕荷、月白……），金只做線和點綴，不鋪大面。品牌色能對應到一個傳統色時，用傳統色的名字和它配。硃紅加金是最常見的那組。

## 字型
- 標題：書法字型（站酷小薇體、霞鶩文楷、思源宋體 Heavy；書法字型務必確認可商用），或者有設計感的宋體粗體；可以豎排。
- 英文和數字：襯線體（Cormorant、EB Garamond）或者窄體無襯線配合現代版式。
- 一屏最多兩種字型，豎排標題配橫排小字。

## 運動
- 節奏比水墨快，比合成波穩：紋樣展開、色塊切換用 `snap` 或彈簧 `{2.4, 0.85}`，幾乎不回彈。
- 紋樣「生長」：回紋沿路徑逐段畫出，祥雲從一個捲開始一圈圈展開。
- 描金高光沿線掃過，一次 0.8–1.5 秒。
- 年畫人物的動作可以 12fps 步進，像皮影或木偶。

## 畫面怎麼活
- 祥雲緩慢地橫向漂移；描金線上的高光隔幾秒掃一次；燈籠的穗子輕輕晃。
- 海水江崖的浪紋按週期起伏（取模週期 = 紋樣週期）。
- 大色塊和標題落定後不動，活的東西都在紋樣和裝飾上。

## 鏡頭語法
| 鏡頭運動 | 表達什麼 | 適合哪類內容 |
|---|---|---|
| 推門 / 穿過月亮門 | 進入一個世界 | 開場、轉場 |
| 長卷橫移 | 時間、旅程 | 敘事、產品線 |
| 俯視平鋪的紋樣，旋轉 | 秩序、圖案之美 | 片頭、Logo |
| 推近到一處描金細節 | 工藝、質感 | 高階產品 |
| 豎向卷軸展開 | 揭示 | 標題、落版 |

## 聲音調色盤
民樂音色：`pluck` 模擬古箏和琵琶（bright 偏高、短衰減）、帶滑音的 `lead` 模擬笛子、`mallet({ material: 'wood' })` 做木魚和梆子；節慶可以加大鼓（`tom` 低音、重混響）和鑔。第 1 檔即可，需要更真的絃樂時用第 2 檔。

律動與和聲（舉例，不止這些）：五聲調式（`scale(r, 'gong')`、`'zhi'`、`'yu'`），也可以把五聲旋律放在現代的電子鼓或 trap 節拍上（國潮最常見的做法之一）；慢板的古風鋪底；或者只用打擊樂的鼓點做開場。不一定每次都是鑼鼓喜慶。

## 原生手法
- 回紋沿畫面邊框逐段生長，合成一個方框後框住標題：適合片頭和落版。
- 推開兩扇門或穿過月亮門，進入下一個場景：適合轉場。
- 一個紋樣單元平鋪、旋轉、縮放成整個畫面的底紋，再收回成 logo：適合 Logo 演繹。
- 卷軸豎向展開，露出豎排標題：適合標題和落版。
- 祥雲從兩邊飄進來、中間一個「福」字：經典，春節片的第一個想法。

## 變化空間
- 結構：一件器物從泥坯到成品；一年二十四節氣；一個傳統紋樣被拆開、重組成現代 logo；一碗茶從採茶到入口。
- 開場：一扇門緩緩推開；一個紋樣單元在白紙上畫出來；一方印章落下。
- 結尾：卷軸合上，封籤是 logo；印章蓋下；紋樣收攏成品牌標識。

## 坑
- 元素堆砌，成了春晚背景板：一屏只放一兩種紋樣，留出大塊的色面。
- 金色用成了黃色：金要有暗部、亮部和高光，而且只用線上和點綴上。
- 紋樣畫錯：回紋畫成了隨意的折線、祥雲畫成了普通的雲。寧可少用，也要畫對。
- 繁簡字型混用、書法字型沒有授權：字型要統一，並確認可商用。
- 用文物高畫質圖或別人的插畫當素材：只用自己畫的紋樣，或者使用者提供的素材。
