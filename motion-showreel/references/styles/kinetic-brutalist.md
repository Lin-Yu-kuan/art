# 粗野動態排版（kinetic-brutalist）

> 字就是畫面：巨字出血、硬切、高對比、節奏狠，像一張不斷被撕掉重貼的海報。
> 參照（只學語法）：Bloomberg Businessweek 封面時期的編輯設計、新粗野主義網頁、音樂節海報的大字排版、Saul Bass 之後的強節奏片頭。不照搬具體封面和字型檔案。

## 本質 / 不是什麼
- 本質：**尺寸極端**（一個詞佔滿甚至溢位畫面）、**切換極快**（半拍一換）、**對比極高**（黑白加一個刺眼的色）；版式故意「不舒服」，但每一幀都是設計過的。
- 不是：雜亂無章的隨機排版；也不是到處彈跳的模板歌詞影片。

## 辨識訊號：每支片子挑 2–3 個
| 訊號 | 長什麼樣 | 適合的主題 |
|---|---|---|
| 出血巨字 | 一個詞大到被畫面邊緣裁掉 | 口號、態度 |
| 反色疊加 | 字掃過的地方顏色反轉（difference） | 對錯、前後、反差 |
| 描邊字和實心字交替 | 同一個詞空心、實心來回換 | 節奏、重複 |
| 粗結構條和粗框 | 黑條、粗下劃線、粗邊框切分畫面 | 編輯感、強調 |
| 字被切開錯位 | 一個詞被切成兩半，錯開再合上 | 打破、重塑 |
| 一詞一屏的硬切 | 半拍換一個詞，沒有過渡 | 快節奏卡點 |
| 重複鋪滿 | 同一個詞排滿一整屏 | 洗腦、強調、群體 |
| 拉伸變形的字 | 字被橫向拉寬或壓成一條 | 張力、速度 |
| 原始網頁元素 | 系統字型、連結藍、遊標、未加樣式的按鈕 | 網際網路、開發者、反設計 |
| 警示條紋和封條 | 黃黑斜紋、封箱膠帶橫過畫面 | 警告、施工、禁止 |

規則：
- 每支挑 2–3 個，至少一個不在下面「最俗的版本」裡。
- 訊號從主題裡選，不按順序全上。

## 這個風格最俗的版本
- 畫面：黑底白字或熒光黃，Anton / Bebas 全大寫，每拍一個詞，每個重拍反色閃一下，結尾一個巨大的句號。
- 聲音：每個詞落地一記 hit，trap 滾奏的 hi-hat。
- brief 的 style 一欄寫明這支片子翻掉了哪幾條，或者為什麼刻意保留（比如使用者要的就是經典版）。保留時，把力氣花在構圖、鏡頭、節奏或一個意外的記憶點上。

## 適配
- 用途：金句卡點、作品集、宣傳片的開場和高潮、活動預告。
- 內容：態度鮮明、需要能量的主題；音樂、潮流、口號、反差。

## 技術路線
Canvas 2D（`fillText` + 變換 + 合成模式）或 DOM。動作快，建議 60fps；硬切本身不需要運動模糊，快速滑移用 `--subframes 2`。

## 材質與渲染
- 字壓到畫面邊緣以外（出血），行距壓到 0.8–0.9，字可以被色塊切掉一半。
- 用 `globalCompositeOperation = 'difference'` 做反色疊加：字掃過的地方顏色反轉。
- 粗黑條、粗邊框、粗下劃線這類「結構性」元素可以有，但不加裝飾性陰影。
- 偶爾用描邊字（空心）和實心字交替。

## 配色
下面的色值是示例，看思路，不要原樣照抄。
- 白 `#FFFFFF` / 黑 `#000000` / 熒光黃 `#E8FF00`
- 黑 `#0A0A0A` / 白 `#F4F4F4` / 警示紅 `#FF2A1F`
- 粉 `#FF4FD8` 底 / 黑字 / 白字（只在 drop 時反過來）
- 規則：每一屏最多兩種顏色；反色可以當作節拍，每個重拍翻一次。
- 推導：黑白之外最多一個刺眼的顏色，從主題來（品牌色能刺眼就用品牌色）；熒光黃是最常見的。也可以整片只用兩種非黑白的顏色。

## 字型
- 超粗或超窄的展示字型：Anton、Archivo Black、Bebas Neue、Big Shoulders Display、Unbounded（OFL）。中文用思源黑體 Heavy 或站酷高階黑。
- 全大寫，字距可以收緊到 −4%；一個詞一屏，或者一個詞鋪滿整屏。

## 運動
- 節奏驅動：詞在拍點上硬切出現，最多一個 2–4 幀的預備（比如從 110% 縮到 100%）。
- 大位移用 `whip` 緩動，3–6 幀完成；停住時可以加 1–2 幀的震屏。
- 偶爾用一次慢動作或靜止，形成反差，讓下一次衝擊更狠。

## 畫面怎麼活
- 詞落定後不留空：可變字型的字重或字寬踩八分音符微抖；背景色塊按拍輪換；描邊字背後的實心字錯開一兩幀再對齊。
- 刻意的停住是反差手段時，就真的停住，寫進 `HOLDS`，不要再加小動作。

## 鏡頭語法
| 鏡頭運動 | 表達什麼 | 適合哪類內容 |
|---|---|---|
| 急推進一個字母 | 衝擊、進入 | 段落切換、drop |
| 甩鏡到下一個詞 | 速度 | 連續口號 |
| 90° / 180° 硬轉 | 翻轉觀點 | 反差、反問 |
| 固定 + 反色閃 | 敲打 | 重拍、強調 |

## 聲音調色盤
重鼓組（kick、clap、snare 的 drive 加大）、短促的 glitch、hit，每個詞落地一下。BPM 120–150。使用者給了曲子就嚴格卡點。

律動與和聲（舉例，不止這些）：breakbeat、half-time、trap 滾奏，也可以 7/8 的不穩；Phrygian、音簇，或只有根音 + 五度；也可以用抽空製造反差（滿屏轟炸後只剩一個詞、一個聲音）。鼓 bus 可以 `crush: 10` 並加大 `drive`。

## 原生手法
- 一個詞放大到出畫，它的筆畫內部就是下一個詞：適合口號連發。
- 反色擦除：適合「對 / 錯」「之前 / 之後」。
- 字被切成兩半、錯位、再合上：適合「打破」「重塑」類主題。

## 變化空間
- 結構：一句話拆成 16 個半拍；一組反義詞對撞；同一個詞換 8 種排法。
- 開場：黑屏上第一個字砸下來；一個字母放大到滿屏後才露出整個詞。
- 結尾：最後一個詞停住 2 秒，周圍全部清空；畫面被一個巨大的句號蓋住。

## 坑
- 字切得太快，讀不完：節奏快要靠減少字數，每個詞至少停 0.4–0.5 秒，關鍵句要停到讀得完。
- 每一屏都一樣狠，就沒有狠了：一定要有慢下來的地方。
- 中文字型沒做子集，渲染時出現方塊。
