# 液態著色器（liquid-shader）

> 由片元著色器逐像素算出來的流體：融球相吸相融、液態金屬反光、噪聲場緩緩流動，一個形狀像液體一樣流進下一個形狀。
> 參照（只學語法）：Shadertoy 上的 SDF 和噪聲作品、液態金屬的品牌動效、熔岩燈。只學技法，不復制具體著色器程式碼。

## 本質 / 不是什麼
- 本質：**形狀由距離場（SDF）定義**，用平滑並集（smooth min）讓它們像液體一樣融合；表面用法線 + 環境反射做出金屬或玻璃感；或者用域扭曲噪聲（domain warping）做流動的顏色場。
- 不是：隨便疊幾個漸變圓；也不是一直在晃、沒有結構的屏保。

## 辨識訊號：每支片子挑 2–3 個
| 訊號 | 長什麼樣 | 適合的主題 |
|---|---|---|
| 融球 | 幾個球靠近、拉絲、融成一體 | 合作、融合 |
| 液態金屬 | 鉻銀表面映著環境，像水銀 | 高階、科技 |
| 熔岩燈 | 慢慢上浮又下沉的暖色團塊 | 放鬆、復古 |
| 墨水入水 | 顏料在水裡捲曲擴散 | 藝術、起源 |
| 域扭曲色場 | 顏色像油彩一樣緩緩流動 | 情緒、背景 |
| 表面漣漪 | 一個點擾動，漣漪擴散 | 影響、觸發 |
| 液滴和飛濺 | 一滴落下，濺起後回落 | 衝擊、飲品 |
| 玻璃液體 | 透明的液體，折射後面的東西 | 清新、純淨 |
| 凝固成形 | 流動的液體最後定成一個形狀 | 落版、成型 |
| 等高線 | 液體高度畫成一圈圈等高線 | 資料、地形 |

規則：
- 每支挑 2–3 個，至少一個不在下面「最俗的版本」裡。
- 訊號從主題裡選，不按順序全上。

## 這個風格最俗的版本
- 畫面：近黑底上一團鉻銀融球慢慢轉、反射一圈彩虹、兩滴液體融成 logo。
- 聲音：低頻 drone、水滴聲、大混響的鋪底。
- brief 的 style 一欄寫明這支片子翻掉了哪幾條，或者為什麼刻意保留（比如使用者要的就是經典版）。保留時，把力氣花在構圖、鏡頭、節奏或一個意外的記憶點上。

## 適配
- 用途：片頭、轉場、Logo 演繹（logo 從液體中凝固出來）、作品集的簽名時刻。
- 內容：AI、音樂、美妝、飲料、抽象概念、品牌情緒片。

## 技術路線
全屏 WebGL2 片元著色器（recipes.md 第 12 節的模板，把內容紋理換成純計算）。uniform 傳 `t`、解析度、節拍脈衝。文字或 logo 可以先畫到 Canvas，生成 SDF 紋理（或者直接用模糊後的 alpha 當近似距離場），在著色器裡和其他形狀融合。先渲一幀確認生效；軟體渲染很慢。

## 材質與渲染
- 融球：`smin(a, b, k)` 合併多個圓或球的 SDF，k 控制「黏稠度」。
- 2D 液態金屬：從 SDF 求法線（有限差分）→ 用法線去取樣一張程式碼生成的「環境」漸變 → 加菲涅爾邊緣高光。
- 流動場：`fbm(p + fbm(p + t))` 域扭曲，對映到一條 3–4 色的調色盤。
- 邊緣抗鋸齒：用 `smoothstep(-px, px, d)`，px = 一個像素的距離。

## 配色
下面的色值是示例，看思路，不要原樣照抄。
- 鉻銀 `#E6E8EB` 在近黑 `#08090B` 上，只用一個色相的環境反射（比如冰藍 `#9FD8FF`）
- 熔岩：深紅 `#3A0A0A` → 橙 `#FF5A1F` → 奶油 `#FFE7C2`
- 柔霧：薰衣草 `#CBB8FF` / 蜜桃 `#FFC9B5` / 奶白 `#FFF7F0`（低對比、霧面）
- 規則：調色盤用 OKLab 插值，3–4 個色標，不要彩虹。
- 推導：3–4 個色標，用 OKLab 插值，不要彩虹。從品牌或主題推：金屬的單色反射、熔岩的暖色階、霧面的低對比柔色、高對比的雙色都可以。鉻銀配冰藍是最常見的那組。

## 字型
logo / 標題本身參與液態變形；靜態說明文字用乾淨的無襯線體，放在液體之外。

## 運動
- 流動緩慢（週期 4–12 秒），節拍到來時 k 值或尺寸脈衝一次。
- 形狀之間的轉換：兩個 SDF 用 `mix(d1, d2, ease(p))` 插值，配合 smooth min，過程中自然出現「拉絲」。
- 循環片用週期函式（`sin(TAU * t / DUR)`），首尾天然銜接。

## 畫面怎麼活
- 這種風格本來就一直在流，要防的是加太多：液麵上一點高光緩慢遊走、表面細小的漣漪就夠了。
- 節拍上的 k 值或尺寸脈衝已經是「活」，不必再疊別的循環。

## 鏡頭語法
| 鏡頭運動 | 表達什麼 | 適合哪類內容 |
|---|---|---|
| 固定，形狀自己變化 | 流動本身就是主角 | 大多數場景 |
| 緩慢推近到表面 | 沉浸 | 記憶點 |
| 旋轉座標系 | 漩渦 | 轉場 |

## 聲音調色盤
流體感：慢速濾波掃頻的鋪底（`pad` 的 cutoff 隨時間變化）、顆粒 shimmer、低沉的 sub、融合時的「水滴」聲（快速下滑的 `pop`）。第 2 檔的混響和合唱效果會更好。

律動與和聲（舉例，不止這些）：慢 half-time 或無拍；Dorian、Lydian、四度疊置、持續低音；波浪曲線。`vox` 做流動的人聲鋪底，music bus 加一點 `wow`，讓音高也像液體。

## 原生手法
- 兩滴液體靠近、拉絲、融合成 logo：適合品牌出場。
- 整個畫面像液體一樣流進下一鏡：適合轉場。
- 液態金屬表面映出下一個場景：適合揭示。

## 變化空間
- 結構：一滴液體的旅程；三個形狀融合成一個；從混沌流動到凝固成形。
- 開場：一滴液體落在平面上散開；畫面中央一個呼吸的融球。
- 結尾：液體凝固成 logo，表面最後一道反光掃過。

## 坑
- 每像素計算太重，渲染極慢：先在 960×540 測時間，循環次數（raymarch 步數）要有上限。
- 沒有抗鋸齒的硬邊在編碼後鋸齒明顯：用 smoothstep 做像素級抗鋸齒，或 `--dpr 2`。
- 顏色太多、太飽和，變成迷幻屏保：嚴格控制調色盤。
