# 浮世繪木版（ukiyo-e）

> 主版墨線框住平塗色面，水、雲、衣褶各有概括方式，留白與斜向構圖把觀看順序連起來。
> 參照（只學語法）：浮世繪錦繪的主版與套色、名所繪的空間組織、木版漸層與紙墨工藝。不照搬具體名作構圖、人物、題簽和印章。

## 本質 / 不是什麼

- 本質：**主版線條與分版套色共同構成畫面**。輪廓有選擇，色面相對平整，遠近主要靠遮擋、大小和構圖表達；紙、墨和區域性漸層讓平面有印出來的觸感。
- 不是：`ink-wash` 的自由暈染，也不是 `risograph-print` 的網點疊印。浮世繪有清楚的主版輪廓和按形體組織的套色，少量對版差不能代替繪畫結構。

## 辨識訊號：每支片子挑 2–3 個

| 訊號 | 長什麼樣 | 適合的主題 |
|---|---|---|
| 主版墨線 | 深色線概括形體，內部線有取捨 | 人物、器物、風景 |
| 大塊套色 | 少數平塗色面被輪廓組織起來 | 品牌、文化、敘事 |
| 木版漸層 | 天空、水或色帶區域性由深到淺 | 時間、天氣、情緒 |
| 斜向擷取 | 橋、坡、屋簷或岸線從畫邊切入 | 行進、城市、空間 |
| 近大遠小 | 前景形體被大膽截斷，遠處留小景 | 尺度、觀察、旅程 |
| 程式化水紋 | 波、渦或細流用重複而有方向的線表達 | 水、流動、力量 |
| 紋樣隨形 | 衣紋或器物紋樣順著色面和褶皺排布 | 工藝、身份、材料 |
| 紙墨咬合 | 色面有輕微纖維和印色差，邊界仍清楚 | 手作、出版、文化 |
| 豎向題簽 | 少量文字在獨立窄區，參與畫面平衡 | 命名、章節、地點 |
| 分版顯現 | 墨線、色組、漸層分別疊入同一畫面 | 製作、組成、解釋 |

規則：

- 每支挑 2–3 個，至少一個不在下面「最俗的版本」裡；訊號從主題裡選。
- 海浪、富士山、紅日和印章均非必選。現代器物也能按木版邏輯處理，題材與工藝分開選擇。

## 這個風格最俗的版本

- 畫面：巨浪、遠山、紅日擠在一起，紙面泛黃，角落蓋一個意義不明的紅印。
- 聲音：尺八與鼓點輪流響，所有運動都配風聲或水聲。
- brief 的 style 一欄寫明翻掉了哪幾條，或者為什麼保留經典版。可從城市截景、室內器物或安靜天氣入手。

## 適配

- 用途：文化與工藝宣傳、旅行片頭、品牌故事、Logo 演繹、圖解式章節。
- 內容：日常生活、地點、自然力量、材料與勞動，也適合現代主題的平面重述。
- 不適合：密集 UI 教程、連續自由旋轉的三維鏡頭，或需要照片級材質與深度的展示。

## 技術路線

- **輪廓與色版**：Canvas、SVG 都可處理主版線、獨立色面和遮擋。Paper.js 可輔助路徑整理與裁切，圖形仍需按主題重新設計。
- **紙墨與漸層**：可探索 PixiJS 或 WebGL 的區域性紋理與遮罩；漸層限制在對應色版區域，主版線單獨保持清楚。
- **分層運動**：前景、主體、遠景分開組織，用輕微視差或區域性形變表現運動。簡單場景可全程二維，不需要為攝影效果搭完整三維世界。
- 同一時刻獨立恢復套色、區域性動作與鏡頭；紙紋、色版邊緣和輕微對版偏差固定種子。`--dpr` 檢查細紋樣，`--subframes` 從輕，`--grain` 避免與已有紙紋重複。

以上是可選方向，不規定版面生成演算法、著色器和素材庫。

## 材質與渲染

- 工藝依據：主版承載輪廓，各色版分別上色，紙張對位後用工具壓印；區域性漸層來自版上的上色方式。先有輪廓和色版，再有印刷痕跡。
- 主版線有粗細與轉折的力度，細節沿形體走。不能把所有邊緣等粗描黑，變成現代卡通貼紙。
- 色面可有輕微不均，但保持整體平整；紙纖維固定在紙上，不變成水墨擴散或滿屏動態顆粒。
- 漸層在天空、水面或特定色帶裡有方向，不能給每個物體套一層立體光照。明暗更多靠色組與構圖處理。
- 對版偏差很輕，按整張色版或區域性工藝一致地表現，不每幀亂抖。主體也用同樣的墨線與套色，官方標誌可單獨留在清楚的題簽區。

## 配色

下面的色值是示例，看思路，不要原樣照抄。

- 藍與暖紙：紙 `#EEE3C6` / 墨 `#253D4B` / 藍 `#4C7B96` / 少量硃色 `#B45B44`。
- 城市黃昏：紙 `#E5D4B3` / 墨 `#383C39` / 主色 `#8C7762` / 暖色 `#C98662`。
- 青綠初夏：紙 `#EAE2C8` / 墨 `#2E4545` / 綠 `#6F9183` / 強調 `#C6A35D`。
- 推導：從主題選少數墨色和套色，保留紙色參與亮部；品牌色可成為一塊色版。顏色無需全部褪舊，關鍵是色組關係與平面層次。

## 字型

中文與日文可選相應語言版本的思源宋體，英文用 EB Garamond 或 Libre Baskerville，自託管 OFL 字型。豎排只在文字和佈局適合時使用，長說明橫排更易讀。不要用偽日文筆畫或無意義印章裝飾；標題區的字比畫內小注明顯大。

## 運動

- 讓主輪廓穩定，水紋、衣褶、雲帶按各自形態變化。動作可用少量關鍵形狀，避免整張畫連續軟化。
- 分層平移比大幅三維旋轉更貼合版畫；鏡頭可以穿過橫向長圖，空間靠遮擋與尺度自然交接。
- 進場可分版套印，也可以從完整畫面中發生一個動作；離場順著岸線、屋簷或雲帶切到下一構圖。

## 畫面怎麼活

- 水紋沿已有流向緩慢更替，主浪形或岸線保持穩定。
- 衣角、幡布或枝梢小幅擺動，印花與墨線跟著表面，不能在裡面滑動。
- 安靜場景以靜為主，可讓一條薄雲或遠處小船緩慢經過，紙紋不閃爍。

## 鏡頭語法

| 鏡頭運動 | 表達什麼 | 適合哪類內容 |
|---|---|---|
| 沿橫向畫面平移 | 經過地點與日常事件 | 旅程、城市、敘事 |
| 從前景擷取拉到全幅 | 區域性與遠景的關係 | 尺度、構圖、揭示 |
| 固定機位，區域性形狀變化 | 平靜中發生的事 | 天氣、情緒、循環 |
| 沿斜向主線輕推 | 動勢與方向 | 行進、水流、力量 |

## 聲音調色盤

第 1 檔可用乾淨撥絃、輕手鼓、低密度環境噪聲與短敲擊。需要真實三味線、笛或木版製作擬音時，用第 2 檔 Tone.js 配合授權取樣，不把普通合成音冒稱傳統樂器。套印聲按一組色版組織，避免每條線刮響；口播下收掉持續高頻風聲。

律動與和聲（舉例，不止這些）：自由留白的短句、輕快的行進節奏，或現代極簡的重複音型。音樂從主題情緒來，傳統配器和固定五聲音階都不必強制。

## 原生手法

- 主版先立住輪廓，各組套色隨後疊入：適合製作過程與組成（經典）。
- 前景的大形沿畫邊經過，露出新的遠景：適合旅程和地點交接。
- 同一水紋或雲帶在不同場景中延續：適合自然關係和時間跨度。
- 保留墨線，只改變一組色版與區域性漸層：適合天氣、季節和版本對比。
- 圖中一個紋樣擴大，成為下一張畫面的構圖骨架：適合工藝細節與主題轉場。

## 變化空間

- 結構：沿一處地點觀察日常；同一構圖經歷幾種天氣；由器物細節展開製作與使用。
- 開場：完整畫面中一處開始動；從被截斷的近景拉遠；只見一組套色，隨後墨線補出形體。
- 結尾：停在完整而可讀的版面；收去題簽保留風景；區域性動勢延續到下一幅畫。

## 坑

- 紅日與巨浪代替風格規則：去掉地標後檢查墨線、套色和構圖是否成立。
- 所有色邊嚴重錯位：控制對版差，別做成孔版印刷或數字故障。
- 水彩暈染吞掉輪廓：保住主版線與明確色面。
- 給色塊加三維高光與軟陰影：回到平面色組與遮擋關係。
- 紙紋持續抖動：固定紙面紋理，只有畫內物件運動。
- 直接復刻熟悉名作的構圖：從主題重新安排前景擷取與遠近層次。
- 使用無意義題簽或假印章：文字有內容，語言和名稱據實填寫。
