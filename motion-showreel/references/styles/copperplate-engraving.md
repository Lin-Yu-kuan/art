# 銅版雕刻（copperplate-engraving）

> 細密的刻線沿著形體轉折，疏密之間顯出明暗；紙上的圖譜可以被放大、標註，也可以一層層印出來。
> 參照（只學語法）：銅版雕刻的排線與刻刀線、古典博物圖譜、手工設色版畫。不照搬具體圖版、構圖、標本姿態和裝飾邊框。

## 本質 / 不是什麼

- 本質：**用刻線的疏密和粗細表現明暗**。線條順著物體表面彎曲，暗部增加交叉排線，亮部露出紙色；刻刀入版、加深、抬起，留下兩端細、中間較厚的線。畫面的體積從這些線裡長出來。
- 不是：黑底白刀痕的木刻、鬆散的鋼筆速寫，也不是照片套棕褐色濾鏡。紙張做舊和古典邊框只是可選裝飾，不能替代隨形排線。

## 辨識訊號：每支片子挑 2–3 個

| 訊號 | 長什麼樣 | 適合的主題 |
|---|---|---|
| 隨形排線 | 線條沿著葉面、器物或地勢彎曲，疏處亮、密處暗 | 形體、工藝、自然 |
| 交叉排線 | 暗部疊入另一組方向不同的細線，逐漸顯出體積 | 深度、揭示、變化 |
| 刻刀線 | 一條線由細變粗再收尖，轉折處有力度變化 | 精密、手藝、力量 |
| 印版壓痕 | 圖版邊緣留下壓入紙面的淺痕，斜光下才明顯 | 出版、收藏、製作過程 |
| 放大細節圈 | 區域性被放大到旁邊的圓框裡，引線仍指向原位置 | 微觀、結構、產品細節 |
| 編號與引線 | 小編號、細引線和短註釋圍繞主體排列 | 講解、分類、組成 |
| 透明手工淡彩 | 少量顏色鋪線上刻圖上，底下的刻線仍然清楚 | 重點、狀態、季節 |
| 試印層次 | 同一形體從輪廓、淺排線到完整暗部逐次顯現 | 過程、積累、完善 |
| 區域性修版 | 一小塊舊線被磨去，再刻出新的結構 | 修訂、前後對比、演變 |
| 圖譜題簽 | 襯線標題、斜體名稱和留白邊注組成清楚的閱讀順序 | 博物、文化、知識 |

規則：

- 每支挑 2–3 個，至少一個不在下面「最俗的版本」裡。
- 訊號從主題裡選，不按順序全上。
- 隨形排線和刻線的粗細變化始終成立；放大圈、題簽、壓痕和淡彩按內容取捨，不必把每支片子都做成舊書圖版。

## 這個風格最俗的版本

- 畫面：泛黃紙面正中一隻昆蟲，周圍一圈拉丁標籤，羽毛筆劃過，最後套上繁複花邊。
- 聲音：羽管鍵琴從頭彈到尾，每根線出現都配一下刮擦聲。
- brief 的 style 一欄寫明這支片子翻掉了哪幾條，或者為什麼刻意保留（比如使用者要的就是經典版）。保留時，把變化放在觀察角度、細節選擇或線條形成的過程上。

## 適配

- 用途：工藝與文化宣傳片、博物講解、產品細節展示、片頭、Logo 演繹。
- 內容：自然、建築、地理、精密器物、知識出版；現代產品和虛構世界也可以用這種畫法。
- 不適合：密集 UI 操作演示、連續高速卡點，或小螢幕上需要同時閱讀大量標籤的內容。

## 技術路線

- **平面線刻**：Canvas 2D 或 SVG 都可以作為起點。可以從主題的向量輪廓出發，探索按區域安排排線方向、隨明暗改變線距和粗細，再用遮罩控制顯現的辦法。
- **路徑處理**：曲線整理、求交和形狀裁切可考慮 Paper.js；偏生成式繪圖也可用 p5.js。它們提供繪圖能力，刻線的組織方式仍需按本片的形體設計。
- **大面積排線與紙墨質感**：需要處理很多線或複雜遮罩時，可探索 WebGL，或藉助 PixiJS 組織紋理、遮罩與自定義濾鏡。紙、刻線、可選淡彩分層處理，先確認線刻本身成立，再加材質。
- **銅版特寫**：只有內容確實需要展示印版、壓痕或斜光時，再考慮 Three.js 的材質與燈光；以平面圖譜為主的片子可以全程使用 2D。
- 遵守現有的確定性渲染約定：同一時刻能獨立還原線條的顯現程度，紙紋和刻線擾動固定種子。先檢查最終尺寸下的細線，再決定是否提高取樣解析度；運動模糊與額外顆粒從輕，避免抹掉排線。

以上是候選方向，按主題和複雜度選用；具體的排線演算法、圖層組織和動畫實現由 Agent 探索。

## 材質與渲染

- 工藝依據：刻刀在銅版上留下凹槽，凹槽存墨，壓印後成為紙上的線。畫面重點是線的力度和排布；銅的金屬反光只屬於印版，不能帶到印好的紙上。
- 排線貼著形體走：圓面有弧度，平面有方向，前後遮擋處線條自然截止。整屏覆蓋同一角度的斜線會抹平結構。
- 暗部逐步加密或交叉，亮部保留紙色。細節多的主體要留出明暗層次，別把所有區域都填滿。
- 紙面乾淨、略有纖維和淺壓痕；紙紋隨紙移動，刻線隨物體移動。前景主體與背景遵守同樣的線刻規則。
- 淡彩可輕微越過輪廓，邊緣偶有水痕，但保持透明，讓刻線承擔結構和明暗。

## 配色

下面的色值是示例，看思路，不要原樣照抄。

- 暖紙黑墨：紙 `#F2EBDD` / 墨 `#27231F` / 少量赭色淡彩 `#B88952`。
- 冷白藍墨：紙 `#F3F5F2` / 墨 `#293D4D` / 少量灰綠淡彩 `#91A996`。
- 中性紙與品牌色：紙 `#EEECE5` / 墨 `#30302E` / 一處硃紅淡彩 `#B85D51`。
- 推導：先選能襯清細線的紙色，再從主題或品牌色裡取足夠深的單一墨色；強調色用於正在講的區域性。明暗主要靠線條，淡彩保持透明，純單色也成立。

## 字型

英文標題可選 EB Garamond、Libre Baskerville，短名稱可用同家族斜體；中文可選思源宋體。優先使用 OFL 字型並自託管。標題比標籤明顯大一檔，引線與註釋分開留空，不為了仿古把字號壓小。文字較多時保持字面清晰，把線刻質感留給插圖。

## 運動

- 可以按輪廓、淺排線、交叉暗部逐層顯現，也可以直接從完整影像開始，逐個放大重點。順序服務於講述，不必每次重演製版過程。
- 線條顯現有穩定的推進感，區域性收筆略慢；大幅彈性回彈會破壞刻刀的力度感。
- 主體要運動時，排線跟隨形體變化，避免像一張固定網紋蓋在動圖上。選擇細小、清楚的動作，複雜動作先簡化。

## 畫面怎麼活

- 圖譜本身以靜為主，鏡頭停住時留給觀眾閱讀；刻線和紙紋不持續抖動。
- 需要生命感時，讓一小片葉面舒展、一個輪軸緩慢轉過，線條跟著表面走；其餘部分保持安靜。
- 製版場景可以讓斜光緩慢經過壓痕，或讓剛鋪下的淡彩邊緣漸漸穩定；紙上的墨線不隨燈光閃爍。

## 鏡頭語法

| 鏡頭運動 | 表達什麼 | 適合哪類內容 |
|---|---|---|
| 從刻線區域性拉遠到全貌 | 細節與整體的關係 | 工藝、開場、尺度揭示 |
| 沿紙面緩慢平移 | 有順序地觀察 | 分類、地理、連續講解 |
| 從主體推近到一個區域性 | 集中注意力 | 結構、產品細節、微觀 |
| 固定機位，區域性排線或淡彩變化 | 讓變化本身清楚 | 前後對比、狀態、閱讀 |

## 聲音調色盤

第 1 檔可用短撥絃、輕敲擊、低密度鋪底，配少量乾燥的刻劃與紙張擬音；需要真實樂器質感時，再用第 2 檔 Tone.js 配合授權明確的取樣。聲音按一組刻線或一個動作組織，避免每根細線都發聲。有口播時，刮擦聲尤其要輕，給子音和句首留空間。

律動與和聲（舉例，不止這些）：剋制的室內樂式分句、慢速分解和絃，或稀疏的現代電子脈衝。自然題材可以溫和，機械題材可以精確，懸疑題材可以用持續低音；不用把仿古樂器當成必選項。

## 原生手法

- 排線逐層加深，讓輪廓成為有體積的物件：適合工藝過程、知識逐步展開（經典）。
- 放大區域性並移到頁邊，留下指回原位置的引線：適合解釋結構，保留細節與整體的關係。
- 磨去區域性舊線，再刻入新線：適合方案修訂、結構變化和歷史演變。
- 在單色圖中只給正在講的部分鋪上淡彩：適合定位重點、說明狀態。
- 同一組曲線從一種表面的排線延續成另一種形體：適合有關聯的主題之間轉場，先保證兩邊形體都清楚。

## 變化空間

- 結構：圍繞一個物件逐層解釋；沿一幅長圖巡視；比較同一物件的不同版本。
- 開場：已完成的圖版裡先動一個細節；從極近的排線拉遠；從一個需要解釋的區域性開始。
- 結尾：完整圖版留給觀眾閱讀；收掉輔助標註，只留主體；讓最後一個細節連線到下一張圖。

## 坑

- 排線方向與形體無關：先明確表面朝向與光向，讓線條解釋體積。
- 所有線等粗、等長、等距：加入有依據的粗細與疏密變化，但保持整片一致。
- 縮小後變灰、移動時出現摩爾紋：減少線的密度，拉開間距，必要時提高取樣解析度；以最終編碼影片和手機尺寸檢查為準。
- 線條穿過前景物體：遮擋關係隨形體一起處理，別隻疊一層通用紋理。
- 把泛黃、汙漬和花邊當成風格本身：先去掉裝飾檢查線刻是否成立，再按主題決定紙面的年代感。
- 銅色高光留在紙上：區分製版場景與印刷成品，紙上的明暗由墨線表現。
- 小字、引線與細排線擠在一起：留出註釋區，分批講解，鏡頭不要在註釋讀完前移走。
- 為了像圖譜而編造學名、比例尺或結構：事實來自使用者或可靠資料，虛構內容明確標為示意。
