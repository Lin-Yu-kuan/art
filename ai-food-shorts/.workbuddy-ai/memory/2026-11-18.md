# 2026-11-18

## 對 ai-food-shorts skill 做了一次完整技術審查（含實測）

方法：用 ffmpeg 合成 3 支 720x1280 測試片段（第 3 支刻意無音軌）＋自製 subtitles.srt，實際跑 scripts/assemble_shorts.py 驗證。

### 實測確認可用的部分
- filter_complex 架構正確：每段 trim → setpts/speed → scale/crop 1080x1920 → setsar=1 → fps=30 → yuv420p，再 concat。
- 無音軌片段以 anullsrc 補軌可正常 concat，不會報錯。
- loudnorm 單趟實測 Input Integrated -16.3 LUFS，接近目標 -16。
- 3 段輸出 6.90s（1.8+2.5+2.5），符合預期。

### 已驗證的 Bug（重要）
1. **字幕位置錯**：force_style 的 MarginV=180 被 libass 當成 PlayRes 單位（預設 PlayResY=288）而非像素，實際位移 = 180×1920/288 = 1200px，字幕落在畫面 37% 高度（正中間，會壓到食物）。實測抽格確認。
   - 修正：MarginV 改約 27（已實測可回到畫面下方 ~88% 位置），或改用 ASS 並顯式寫 PlayResX/PlayResY=1080/1920。
   - FontSize=14 能看是巧合（14×1920/288≈93px），與 MarginV 同源脆弱。
2. 安裝腳本只下載 SKILL.md，但 skill 依賴 references/style_guide.md 與 scripts/assemble_shorts.py → 全新安裝即壞。
3. repository / update_url 指向 github.com/user/art 佔位符，且 repo 無 .skillkit/skills.json → 自動更新章節完全無法運作。
4. SKILL.md 硬編碼 `C:\Users\cree5\.gemini\antigravity\scratch\...` 與 `D:\develop\AI\art\ai-food-shorts\scripts\...`，不可移植。
5. 引用 `image-generator`（Antigravity 工具名），WorkBuddy 端是 ImageGen。
6. sorted() 對 clips 做字典序排序，1.mp4/10.mp4/2.mp4 會亂序。
7. `-y` 無條件覆寫 final_short.mp4，與同檔「先確認再破壞」契約衝突。

### 架構層面
- 三階段中最關鍵的中段（Google Flow 圖生影）是純人工，10 張圖 × 上傳/貼 prompt/下載，約 30–60 分鐘/支。「全 AI」宣稱不實。
- SRT 時軸與 retiming（1.25x、trim）解耦，無校驗，容易漂移。
