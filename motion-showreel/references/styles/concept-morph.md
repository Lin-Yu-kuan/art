# 數學／概念形變（concept-morph）

> 同一個物件經過可追蹤的變換，讓抽象關係在運動中顯出來。
> 參照（只學語法）：3Blue1Brown 的數學視覺化、動態幾何證明、Manim 的物件對應思想。

## 本質 / 不是什麼

- 本質：形變承擔推理。觀眾既看到前後形狀，也知道哪些點、長度、面積、數值或關係在變化中保留。
- 與資料動效的區別：重點是概念之間的對應，而非一組數字的展示；任意輪廓變形如果不能說明關係，只能算抽象圖形。

## 辨識訊號：每支片子挑 2–3 個

| 訊號 | 長什麼樣 | 適合的主題 |
|---|---|---|
| 對應點不丟失 | 同一組點在變換前後保留顏色和身份 | 對映、座標轉換 |
| 不變數 | 一條高度、面積或距離保持明確 | 幾何、守恆 |
| 公式連到圖 | 符號與圖中的物件共用語義色 | 數學、物理 |
| 輔助線先解釋 | 投影、垂線、軌跡解釋下一步形變 | 推導、測量 |
| 重排而不增減 | 小塊移動但數量與面積可核對 | 組合、面積證明 |
| 單引數控制 | 角度或比例連續變化，結果跟隨 | 函式、系統響應 |
| 區域性高亮 | 只突出正在理解的一項 | 多變數問題 |
| 反向演示 | 變換可逆地回到起點 | 等價關係 |
| 極限過程 | 分塊逐漸細化，明確有限近似 | 微積分、近似 |
| 反例擾動 | 改變一個條件，讓規律失效 | 邊界、假設 |

規則：按主題挑 2–3 個，至少一個不在俗套裡。先說清要證明或解釋什麼，再選擇變換。

## 這個風格最俗的版本

- 畫面：黑底綵線、漂浮公式、圓變方，再加無關粒子和鏡頭旋轉。
- 聲音：空靈鋼琴伴隨每次顯現，所有變換都響同一個 whoosh。
- brief 寫清每次形變保留什麼、改變什麼。保留黑底綵線時，用內容準確性和可追蹤的對應關係讓它成立。

## 適配

- 用途：數學與科學講解、抽象機制說明、概念關係、演算法原理。
- 內容：物件之間存在明確對映，能用運動減少理解步驟的主題。
- 有單位、座標軸、機率或近似時，必須標清口徑；15 秒演示不能冒充完整證明。

## 技術路線

- 精確幾何可用 Canvas、SVG 或 Manim；先建立資料層中的數學物件，再生成圖形。排版較多時可考慮 KaTeX、MathJax 的自託管輸出。
- D3 的比例尺、d3-shape 可輔助座標和曲線；Three.js 適合確有三維關係的主題。
- Paper.js、Flubber 可幫助整理輪廓，但自動插值不保證語義正確。必須自己決定點對應、方向、閉合點和數量變化。
- 引數、相機與公式從同一時間軸求值，支援任意時刻重建。預先抽取特殊值和邊界值，檢查推導與繪圖一致。
- 細線優先提高 `--dpr`；`--subframes 1–2` 足夠。小點快速移動時檢查運動模糊是否淹沒對應關係。

## 材質與渲染

- 工藝依據：這是供人思考的圖，不需要假裝成物質。先建立準確幾何，再用線寬、層次與顏色區分主物件、輔助線和文字。
- 主物件輪廓清晰，輔助網格更淡；低對比背景線不能與零軸競爭。
- 對應點的直徑要在最終觀看尺寸下可辨認，細小標記可以用短暫放大替代常駐發光。
- 形變過程採用同一取樣集合。閉合曲線的接縫與重合點需要解釋，不能在拆開時憑空多出一個點。
- 關鍵讀數不要貼在移動曲線上。留出獨立標註區域，用短引線明確對應。

## 配色

示例只看思路，不照抄。

- 深墨板：底 `#17252D` / 主物件 `#73D0C3` / 引數 `#F2BB68`。
- 白紙幾何：底 `#F5F3ED` / 主物件 `#285D75` / 對照 `#B74A58`。
- 深紫藍：底 `#25273D` / 主物件 `#D6DFC2` / 特殊值 `#DE997D`。

按物件身份分配顏色。量值對映用有解釋的連續色階；角色對映用離散顏色，不能在中途為了好看換色。僅靠紅綠區分時補形狀或文字標記。

## 字型

公式可用 STIX Two Math、Latin Modern Math，正文可用思源黑體、DM Sans，均核對授權並自託管。公式正確排上下標、括號和分數；直接 Canvas 文字適合短公式，複雜公式應預排版。主要結論比座標小字更醒目，手機尺寸仍能讀懂。

## 運動

- 解釋關係時保持可追蹤的平滑變換；引數讀數必須跟真實引數一致。
- 幾何值變化不要用可能越界的彈簧，除非過沖本來就是系統內容。
- 先建立起始狀態，突出對應點，再變換，最後留讀圖時間。快慢由理解負擔決定。
- 改變維度、拓撲或物件數量時，必須顯示切分、複製、投影等步驟；不能把任意淡化稱為數學推導。

## 畫面怎麼活

- 需要觀察週期時，讓一個引數緩慢執行，其他背景保持穩定。
- 到特殊值時停一下，觀眾能比較點、公式和讀數。
- 結論以靜為主。輔助線若已完成任務可退場，不能讓多組掃描線繼續搶注意力。

## 鏡頭語法

| 鏡頭運動 | 表達什麼 | 適合哪類內容 |
|---|---|---|
| 固定座標系 | 觀察變數本身的變化 | 函式、對映 |
| 平移接續展開 | 同一物件延伸到新表示 | 展開、序列 |
| 對應處區域性放大 | 看清特殊值或誤差 | 極限、邊界 |
| 受控三維旋轉 | 顯示被遮住的結構 | 立體幾何 |
| 拉遠到共同座標 | 對比變換前後關係 | 歸納、總結 |

## 聲音調色盤

第 1 檔適合低密度電鋼琴、柔和木音、持續純音和引數變化音效；需要真實鋼琴可選第 2 檔。音高對映數值時明確對映規則，否則只把聲音用於分句和關鍵節點。

律動可選無拍分句、輕微的非對稱節拍或緩慢單和絃。變換開始與完成各留一個聲音提示即可；口播期間避免旋律與公式閱讀爭搶注意力。

## 原生手法

- 同一批點從一種座標表示移動到另一種：適合對映（經典）。
- 小塊不重疊地重排，顯出面積或數量等價：適合幾何與組合。
- 一條輔助線延長成下一幅圖的座標軸：適合把測量連線到函式。
- 固定一個不變數，只改變另一維：適合隔離影響因素。
- 演示完正例後輕改假設，讓反例可見：適合說明成立條件。

## 變化空間

- 結構：從直覺圖走到公式；從公式追溯幾何；比較兩個表示並尋找共同量。
- 開場：一個特殊值；看似不相干的兩幅圖；一個可直接觀察的變化。
- 結尾：把對應關係停在同一屏；反向回到起點；留出一個可驗證的新引數。

## 坑

- 輪廓很順但點配錯了：先檢查起點、方向、點數及對應規則，再做插值。
- 旋轉或縮放偷偷改變了比較口徑：統一座標與單位，或明確顯示換算。
- 取樣線段與數學連續曲線混用：寫明離散近似及誤差，不偽造極限已完成。
- 公式切換後顏色改義：物件、符號和圖例共用同一份語義對映。
- 開場還沒認清就開始變：為起止狀態留停頓，減少同時移動的物件。
- 只驗證三個靜幀：中途可能交叉、倒置、跑出邊界，必須看連續幀並核對特殊值。
- 閉合曲線的引數首尾重合，展開時卻被當成一個點：明確引數接縫，重合時合併顯示標註，拆開後分別跟隨各自端點。
- 中途對應點靠得很近，標註仍全部貼著走：保留點的顏色，在擁擠階段暫時收起文字，終態再落到穩定座標軸上。
