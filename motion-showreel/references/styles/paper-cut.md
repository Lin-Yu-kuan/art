# 紙藝分層（paper-cut）

> 一層層剪好的彩色卡紙，前後錯落，投下柔和的影子；畫面像一個紙雕燈箱，或者一本開啟的立體書。
> 參照（只學語法）：紙雕插畫、剪紙、立體書機關、紙雕燈箱。不照搬具體作品。

## 本質 / 不是什麼
- 本質：**分層**（4–8 層平面，每層是一張剪好的紙）、**層間投影**（柔和、方向一致）、**紙的質感**（細微紋理、切邊）；運動是層的升起、摺疊、翻開、滑動。
- 不是：扁平向量插畫；也不是寫實 3D。

## 辨識訊號：每支片子挑 2–3 個
| 訊號 | 長什麼樣 | 適合的主題 |
|---|---|---|
| 層疊紙雕 | 4–8 層紙前後錯落，層間有投影 | 場景、深度 |
| 立體書機關 | 翻開書頁，場景立起來 | 開場、故事 |
| 窗花剪紙 | 一色剪紙的鏤空圖案 | 節日、傳統 |
| 燈箱 | 紙層後面有光透過來 | 夜晚、溫馨 |
| 摺紙 | 紙沿折線折成形狀 | 變化、精巧 |
| 紙條捲曲 | 衍紙一樣捲起的紙條 | 裝飾、細節 |
| 拉條機關 | 一拉紙條，畫面裡的東西動起來 | 互動、揭示 |
| 紙紋和切邊 | 紙的纖維紋理、切口的白邊 | 質感 |
| 鏤空透景 | 前層的洞裡看到後層的世界 | 穿越、轉場 |
| 紙片飄落 | 剪下來的紙片像落葉一樣飄 | 季節、結尾 |

規則：
- 每支挑 2–3 個，至少一個不在下面「最俗的版本」裡。
- 訊號從主題裡選，不按順序全上。

## 這個風格最俗的版本
- 畫面：藍綠色的海浪紙層或暮色山巒一層層疊起，立體書翻開，結尾書合上。
- 聲音：鋼片琴、撥絃、紙張翻動聲。
- brief 的 style 一欄寫明這支片子翻掉了哪幾條，或者為什麼刻意保留（比如使用者要的就是經典版）。保留時，把力氣花在構圖、鏡頭、節奏或一個意外的記憶點上。

## 適配
- 用途：宣傳短片、節日問候、講解短片、Logo 演繹。
- 內容：生活方式、節日、教育、旅遊、環保、溫暖的品牌。

## 技術路線
- 2.5D：Canvas 2D，每層一個 Path2D，按層畫投影（模糊 + 偏移的深色副本）再畫紙面；視差平移讓層有深度。
- 立體書 / 摺疊：Three.js，每層是一個平面網格，繞折線旋轉；紙面用帶紋理的 `MeshStandardMaterial`，柔和的方向光 + 陰影。
- 紙紋是一張程式碼生成的噪聲紋理，疊在每層紙面上（很淡）。

## 材質與渲染
- 層間距決定投影的大小和模糊度：遠的層投影大而虛，近的層小而實。
- 切邊：邊緣可以有一圈很細的亮邊（紙的厚度）。
- 形狀：剪紙感的輪廓（雲、山、樹、窗花），邊緣是平滑曲線或者故意的折線。
- 光：從一個方向來，整片一致；可以有一個「燈箱」效果（背後透光，層邊緣發亮）。

## 配色
下面的色值是示例，看思路，不要原樣照抄。
- 由遠到近的明度漸變：遠層淺、近層深（或反過來）。
  - 海：`#E8F3F1` `#BFE3DE` `#7CC6C0` `#3F9A9A` `#1F5F6B`
  - 暮：`#FFE3C2` `#F7B48A` `#E07A5F` `#8C4B5A` `#3D2C4D`
  - 窗花：紅 `#C8102E` 一色剪紙在米白 `#F6EFE2` 上
- 規則：同一場景用一個色相的明度階梯，再加一個強調色。
- 推導：同一場景用一個色相的明度階梯（遠淺近深或反過來），再加一個強調色。色相從主題來；海藍綠和暮色橙紫是最常見的兩組，一色紅窗花、黑白剪影、品牌色階梯也都成立。

## 字型
圓潤或者剪紙感的字型：Fraunces Soft、Recoleta 風格的替代（Young Serif）、Nunito；中文用思源宋體 Heavy 或站酷慶科黃油體。字本身也可以是一層剪紙。

## 運動
- 層從下方或後方「立起來」：彈簧 `{2.2, 0.8}`，錯峰 60–100 毫秒，由遠到近或由近到遠。
- 翻開：繞折線旋轉 90°，`inOutCubic`，0.6–0.9 秒。
- 可以用步進（12fps）做成定格動畫的質感，但鏡頭平滑。

## 畫面怎麼活
- 紙層之間的投影隨一盞看不見的燈緩慢擺動；釘著的紙片被風吹得繞釘點輕晃；立體書裡的一頁輕輕顫。
- 小動作可以 12fps 步進，像定格動畫；鏡頭保持平滑。

## 鏡頭語法
| 鏡頭運動 | 表達什麼 | 適合哪類內容 |
|---|---|---|
| 視差橫移 | 深度、旅程 | 場景移動 |
| 推近穿過一層（進入下一層的世界） | 深入 | 轉場 |
| 俯視翻開的書 | 開始一個故事 | 開場 |

## 聲音調色盤
紙張擬音（翻頁、摺疊：帶通噪聲 `swipe`、輕 `click`）、木琴 / 馬林巴 / 卡林巴（`mallet`）、溫暖的 keys、輕柔的鋪底。第 2 檔的鋼琴取樣合適。

律動與和聲（舉例，不止這些）：3/4、6/8 或輕 swing；大調、Mixolydian、加六度和絃；音畫同形（翻頁、摺疊各對應一個樂音）。小房間，不側鏈。

## 原生手法
- 立體書翻開，場景從書頁裡立起來：適合開場（經典）。
- 拉動一根紙條，畫面裡的機關動起來：適合「一個動作帶來變化」。
- 鏡頭穿過前層的一個洞，進入後面的世界：適合轉場。
- 層層收攏合成一個 logo 形狀：適合結尾。

## 變化空間
- 結構：一本立體書的四頁；一個視窗裡四季更替；從地面到天空一層層升起。
- 開場：一張平鋪的紙慢慢立起來；一把剪刀的剪影剪開紙。
- 結尾：書合上，封面是 logo；燈箱的燈熄滅。

## 坑
- 投影方向不一致，層次就亂了。
- 層太多、顏色太多，畫面花：4–8 層、一個色相的明度階梯。
- 剪紙形狀太細碎，手機上看不清。
