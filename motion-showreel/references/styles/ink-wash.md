# 水墨（ink-wash）

> 墨在宣紙上暈開，濃淡乾溼，飛白和留白；一筆落下，山水自現。
> 參照（只學語法）：中國水墨畫的筆墨語言（濃淡、乾溼、皴擦、留白）、水墨動畫的暈染轉場。不照搬具體畫作。

## 本質 / 不是什麼
- 本質：**墨的擴散**（溼邊、暈開、漸淡）、**筆觸的飛白**（幹筆的斷續）、**大面積留白**；只用墨色的濃淡，偶爾一點硃紅（印章、點睛）。
- 不是：灰度漸變的向量圖形；也不是加了毛筆字型的普通 PPT。

## 辨識訊號：每支片子挑 2–3 個
| 訊號 | 長什麼樣 | 適合的主題 |
|---|---|---|
| 墨的暈開 | 溼邊、擴散、漸淡 | 起源、情緒 |
| 飛白 | 幹筆的斷續 | 力量、速度 |
| 大面積留白 | 畫面一半以上是紙 | 意境、剋制 |
| 山水長卷 | 橫向展開的遠山近水 | 旅程、時間 |
| 書法 | 一筆一畫寫出的字 | 標題、文化 |
| 硃紅印章 | 小方印，邊緣不規則 | 落款、認可 |
| 工筆線描 | 細而勻的線勾出輪廓 | 精細、器物 |
| 潑墨 | 大塊的墨潑開，形狀不可控 | 爆發、自由 |
| 水墨動物 | 幾筆畫出的蝦、魚、馬、鳥 | 生命、靈動 |
| 霧和煙 | 淡墨的霧帶橫過畫面 | 空間、神秘 |
| 墨在水裡 | 一滴墨落入清水裡捲曲 | 現代、實驗 |

規則：
- 每支挑 2–3 個，至少一個不在下面「最俗的版本」裡。
- 訊號從主題裡選，不按順序全上。
- 墨的行為（擴散、濃淡、溼邊）是這種媒介的材質，始終都在；訊號挑的是突出什麼、畫什麼。

## 這個風格最俗的版本
- 畫面：一滴墨落下暈開成遠山、古琴聲起、一筆寫出標題、最後蓋一個硃紅印章。
- 聲音：古琴撥絃、簫、水滴聲、大混響。
- brief 的 style 一欄寫明這支片子翻掉了哪幾條，或者為什麼刻意保留（比如使用者要的就是經典版）。保留時，把力氣花在構圖、鏡頭、節奏或一個意外的記憶點上。

## 適配
- 用途：片頭、Logo 演繹、東方題材的宣傳片、節日、品牌情緒片。
- 內容：文化、茶、詩詞、傳統工藝、東方美學品牌、武俠。

## 技術路線
Canvas 2D 自寫筆觸 + WebGL 後期做擴散和紙紋；或者全部在著色器裡做（墨跡 = 隨時間擴張的 SDF + 域扭曲噪聲做毛邊，濃度隨距離衰減）。筆觸：沿路徑畫大量帶噪聲半徑的圓，速度快的地方飛白（隨機跳過），慢的地方墨重。暈染用 t 控制擴散半徑，不要逐幀累積模擬。

## 材質與渲染
- 宣紙：暖白，纖維紋理，墨在纖維方向上滲得更快（用各向異性噪聲擾動邊緣）。
- 墨：五色（焦、濃、重、淡、清），用同一色相的 5 個明度。溼邊更深。
- 飛白：幹筆的斷續，用噪聲閾值把筆觸挖出空隙。
- 硃紅印章：小方塊，邊緣不規則，像真的蓋上去的。

## 配色
下面的色值是示例，看思路，不要原樣照抄。
- 宣紙 `#F3EEE2` / 焦墨 `#151412` / 淡墨 `#8A857B` / 清墨 `#C9C3B6` / 硃紅 `#B8262A`
- 暗版：深墨 `#16161A` 底 / 白墨 `#E8E2D4`（反轉，用於夜景）
- 規則：一屏之內硃紅最多一處；留白至少佔畫面一半。
- 推導：墨的五色（同一色相的幾個明度）加紙色，硃紅最多一處。也可以試反轉的暗版、淡彩（花青、赭石）、只用焦墨和紙的高對比；宣紙加硃紅印章是最常見的那組。

## 字型
書法字型（站酷小薇、霞鶩文楷、思源宋體用於小字；可商用的書法字型要確認授權）；英文用優雅的襯線體（Cormorant、EB Garamond）。標題可以用筆觸「寫」出來。

## 運動
- 慢：暈開 1–3 秒；一筆 0.3–0.8 秒；整體節奏像呼吸。
- 運筆有提按：起筆重、行筆快而細、收筆回鋒。
- 轉場：墨滴落下暈開鋪滿畫面，再從中心淡開露出下一鏡。

## 畫面怎麼活
- 墨暈的邊緣還在極慢地洇開；一縷煙或一條霧帶橫著飄過；水面上一圈漣漪。
- 大面積留白始終不動，活的東西只佔畫面一小塊。

## 鏡頭語法
| 鏡頭運動 | 表達什麼 | 適合哪類內容 |
|---|---|---|
| 長卷橫移 | 時間、旅程（手卷的觀看方式） | 敘事、風景 |
| 緩慢推近到一筆 | 意境、細節 | 記憶點 |
| 俯視一滴墨 | 開始 | 開場 |

## 聲音調色盤
古琴、琵琶、簫的音色感：`pluck`（bright 低、damp 高接近古琴）、帶滑音的 `lead`（sine，glide）模擬簫；空靈的鋪底、水滴聲、風聲（`ambience({ kind: 'wind' })`）。大量留白和靜音。混響要大（0.4–0.5）。

律動與和聲（舉例，不止這些）：無拍或很慢的自由節奏；五聲調式（`scale(r, 'shang')`、`'zhi'`、`'yu'` 等）、持續低音；單線條或擬音主導。水滴可以用高音 `mallet({ material: 'glock' })` 或快速下滑的 `pop`。不側鏈。

## 原生手法
- 一滴墨落下，暈開成山：適合開場和「起源」（經典，人人都會想到）。
- 墨暈染轉場：適合段落切換。
- 一筆寫出 logo / 標題，最後蓋上硃紅印章：適合落版（經典）。
- 潑墨在重拍上炸開，墨點裡顯出下一個畫面：適合高潮。
- 墨滴落入清水，捲曲的墨形成字：適合現代品牌。

## 變化空間
- 結構：一幅長卷從頭看到尾；一筆一畫寫完一個字；春夏秋冬四段墨色變化。
- 開場：一滴墨落在白紙上；一支筆的影子。
- 結尾：印章落下；墨色淡去，只留白。

## 坑
- 用灰色漸變冒充墨色：要有擴散、溼邊、飛白這些「墨的行為」。
- 留白太少，畫面就滿了、俗了。
- 書法字型的授權：只用確認可商用的字型。
