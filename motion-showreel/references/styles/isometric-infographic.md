# 等距資訊圖（isometric-infographic）

> 等距視角下的小世界：方塊、管道、小人、資料塔，一層一層搭起來，把一件複雜的事講清楚。
> 參照（只學語法）：等距插畫、科技公司的架構插圖、城市模擬遊戲的視角。不照搬具體插畫師作品。

## 本質 / 不是什麼
- 本質：**固定的等距投影**（30° 軸線），沒有透視變形；元素是乾淨的幾何體，三個面用三個明度；資訊靠「搭建」「流動」「點亮」來講。
- 不是：隨意的 3D 透視；也不是堆滿元素的複雜插畫。

## 辨識訊號：每支片子挑 2–3 個
| 訊號 | 長什麼樣 | 適合的主題 |
|---|---|---|
| 搭建 | 方塊從上方落下，一層層搭成系統 | 從零到一、架構 |
| 管道和資料流 | 資料點沿管道勻速流過 | 流程、因果、傳輸 |
| 點亮 | 模組按順序亮起強調色 | 啟用、上線 |
| 剖開的方塊 | 一個方塊拆開露出內部結構 | 原理、內部機制 |
| 小人和小車 | 小世界裡的居民沿路徑走動 | 使用者、場景 |
| 資料塔 | 柱子從地面升起表示數量 | 規模、增長 |
| 地塊和道路 | 等距地面上劃出區塊和街道 | 城市、生態 |
| 浮空圖示 | 模組上方懸浮的圖示和標籤 | 功能說明 |
| 連線網路 | 模組之間亮起的連線 | 整合、網路 |
| 晝夜變化 | 同一個小世界的光照從白天變到夜晚 | 時間、執行 |

規則：
- 每支挑 2–3 個，至少一個不在下面「最俗的版本」裡。
- 訊號從主題裡選，不按順序全上。
- 等距投影本身是這種風格的約束，全片只用一種投影；訊號挑的是講什麼、怎麼講。

## 這個風格最俗的版本
- 畫面：淺灰底上一塊地面，藍色方塊和橙色資料流，伺服器、雲、手機三個圖示連成一條線，結尾拉遠出全景。
- 聲音：輕快的 marimba 加柔和的電子拍子。
- brief 的 style 一欄寫明這支片子翻掉了哪幾條，或者為什麼刻意保留（比如使用者要的就是經典版）。保留時，把力氣花在構圖、鏡頭、節奏或一個意外的記憶點上。

## 適配
- 用途：產品宣傳（講架構、流程、生態）、講解型短片、資料視覺化。
- 內容：SaaS 架構、物流、能源、城市、供應鏈、開發流程。

## 技術路線
Canvas 2D 或 SVG，自己寫等距投影函式 `iso(x, y, z) → [sx, sy]`（sx = (x − y)·cos30°，sy = (x + y)·sin30° − z）。也可以用 Three.js 的正交相機，但 2D 更可控、渲染更快。畫的順序按深度排序（x + y + z 從小到大）。

## 材質與渲染
- 每個方塊三個面：頂面最亮、左面中間、右面最暗（同一色相的三個明度）。
- 細描邊可選（同色更深一檔）；地面網格非常淡。
- 小人和圖示用最簡幾何（圓柱 + 球），不要畫五官。
- 資料流：沿管道移動的點或短線段，按時間偏移（`(t * speed + i * gap) % length`）。

## 配色
下面的色值是示例，看思路，不要原樣照抄。
- 底 `#F3F1EC` / 方塊 `#FFFFFF`·`#E4E1DA`·`#CFCAC0` / 強調 `#2F6BFF` / 資料流 `#FF7A1A`
- 底 `#0F1626` / 方塊 `#26324D`·`#1C2640`·`#141C30` / 強調 `#3EE6B0`
- 規則：結構用中性色，只有「正在發生的事」（流動、點亮、新增）用強調色。
- 推導：結構用三個明度的中性色（淺底或深底都可以），強調色只給正在發生的事，資料流可以用第二個顏色。強調色從品牌來；藍加橙是最常見的組合。

## 字型
標籤用乾淨的無襯線體（Manrope、DM Sans），字也可以貼在等距平面上（用等距變換矩陣 `ctx.setTransform` 斜切）。

## 運動
- 搭建：方塊從上方落下，彈簧 `{2.4, 0.7}` 落定，帶一點擠壓；按依賴關係錯峰。
- 點亮：面顏色漸變到強調色，加一次脈衝。
- 流動：持續勻速的資料點（勻速在這裡是對的，它表達的是「持續執行」）。

## 畫面怎麼活
- 管道和連線裡的資料點勻速流動；小機器、小屋的指示燈按拍閃；小人或小車沿路徑來回走，像這個小世界裡的居民。
- 活的東西都要跟資訊有關：流動的方向就是資料的方向。

## 鏡頭語法
| 鏡頭運動 | 表達什麼 | 適合哪類內容 |
|---|---|---|
| 正交相機平移 | 沿流程走 | 步驟、資料流 |
| 緩慢放大到一個模組 | 聚焦一個環節 | 功能細節 |
| 拉遠看全景 | 生態全貌 | 總結、結尾 |
| 繞 z 軸 90° 旋轉（重新排序深度） | 換個視角 | 對比、轉折 |

## 聲音調色盤
清脆的 pluck、木質感的 click（`rim`、`mallet({ material: 'wood' })`，或短 `tom` + 高通）、方塊落地的輕 `boom`、流動時的輕柔鋪底。第 1 檔合成即可。

律動與和聲（舉例，不止這些）：直拍或輕 swing，十六分音符的機械感；大調、Lydian；`mallet({ material: 'wood' | 'marimba' })` 就是木質積木的聲音。累加曲線（城市一塊塊長出來，聲部一個個進來）很合適。

## 原生手法
- 一塊地面上逐步長出整座城市（或整套系統）：適合「從零到一」。
- 資料點沿管道流過、點亮下一個模組：適合流程和因果。
- 一個方塊拆開露出內部結構：適合講原理。

## 變化空間
- 結構：一個請求的旅程；一天之內一座小城的變化；三個模組逐一點亮再連成一體。
- 開場：一個方塊從空中落下；一條資料流從畫外流進來。
- 結尾：拉遠露出全景，系統整體脈動一次；所有模組合併成一個 logo 方塊。

## 坑
- 深度排序錯了，前後遮擋穿幫：嚴格按 x + y + z 排序，跨格的大物體要拆開畫。
- 等距和透視混用：全片只用一種投影。
- 元素太多、太小：在手機上看不清，寧可少而大。
