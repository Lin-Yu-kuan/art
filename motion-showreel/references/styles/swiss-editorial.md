# 瑞士編輯（swiss-editorial）

> 國際主義排版風格動起來：模組網格、一種字型、一個訊號色，運動像印刷機一樣精確。
> 參照（只學語法）：1950–70 年代蘇黎世海報（Müller-Brockmann、Hofmann、Gerstner、Crouwel）的網格和尺寸對比；現代動態識別系統（Experimental Jetset、Pentagram）卡在拍上的版式跳變。不照搬具體海報的構圖，不用 Helvetica / Akzidenz 字型檔案。

## 本質 / 不是什麼
- 本質：紙面上的二維平面設計在網格上運動；**所有元素貼網格、所有動作落在拍上、什麼都不回彈**；整個畫面服從一套系統，唯一不服從的那個元素就是主角。
- 不是：釋出會 keynote（沒有漸變、發光、裝置渲染圖）；歌詞影片（字不飛、不轉、不彈）；包豪斯三原色拼貼。

## 辨識訊號：每支片子挑 2–3 個
| 訊號 | 長什麼樣 | 適合的主題 |
|---|---|---|
| 可見的模組網格 | 細線網格、欄號、基線本身出現在畫面裡 | 體系、方法論、工具 |
| 巨大的數字 | 一個數字佔半個畫面，視覺上左對齊 | 資料、年份、價格 |
| 唯一的訊號色塊 | 整個畫面只有一個元素帶顏色 | 主角、產品、結論 |
| 極端尺寸對比 | 巨字旁邊是 12–16px 的技術註釋 | 標題、品牌 |
| 左對齊的文字欄 | 右側不齊的小字說明，像說明書 | 說明、規格 |
| 幾何基本形 | 圓、方、條按網格排布、跳位 | 抽象、品牌識別 |
| 時刻表 / 表格 | 行列逐行填滿，數字等寬 | 流程、時間、清單 |
| 豎排或旋轉 90° 的字 | 標題或註釋換一個閱讀方向 | 轉折、節奏變化 |
| 對頁結構 | 左頁放規則，右頁放作品 | 作品集、案例 |
| 整塊色塊擦除 | 一整塊顏色掃過，版式換掉 | 章節切換 |

規則：
- 每支挑 2–3 個，至少一個不在下面「最俗的版本」裡。
- 訊號從主題裡選，不按順序全上。
- 網格可以只在骨子裡：元素都貼網格，網格線本身不一定要畫出來。

## 這個風格最俗的版本
- 畫面：白底黑字的新怪誕體大字 + 一個紅色方塊或圓 + 網格線全程可見 + 字從基線往上揭開 + 結尾居中的 logo。
- 聲音：只有 click 和 tick 的極簡電子節拍。
- brief 的 style 一欄寫明這支片子翻掉了哪幾條，或者為什麼刻意保留（比如使用者要的就是經典版）。保留時，把力氣花在構圖、鏡頭、節奏或一個意外的記憶點上。

## 適配
- 用途：作品集、Logo 演繹、資料爆點、排版卡點。宣傳片也可以，但需要截圖時要把截圖當作網格里的一塊。
- 內容：理性、專業、設計感強的主題；機構、工具、方法論。

## 技術路線
Canvas 2D（或者 DOM 排版）+ 一個二維相機矩陣。不加 WebGL 質感層，不加顆粒（`--grain 0`）。運動多為硬切和滑移，`--subframes 2` 足夠。

## 材質與渲染
- 畫面網格：1920 寬用 12 欄，左右邊距約 96px，欄間距 24px，基線 24px。畫面可以當作一個對頁：左頁放規則（數字、說明、註釋），右頁放作品。
- 網格的含義由內容決定（Gerstner 的「設計程式」）：欄和行代表什麼是設計決定。模組要大到讓元素有分量，欄太細會像圖表。
- 平面色塊和條：相鄰的同類單元合併成一根條，接縫處多畫 1px，避免抗鋸齒露出細縫。
- 第二個聲部用淺灰元素放在黑色元素下面，可以增加層次，不需要第二個顏色。

## 配色
下面的色值是示例，看思路，不要原樣照抄。
- 紙 `#EAE9E5` / 白 `#FFFFFF` / 墨 `#111111` / 訊號紅 `#E30613`
- 紙 `#F2F0EA` / 墨 `#141414` / 訊號橙 `#FF5A00`
- 紙 `#E9ECEF` / 墨 `#0B0B0B` / 訊號群青 `#1F3FFF`
- 規則：**只有一個東西帶訊號色**，它就是主角，也是唯一允許不精確的元素。墨可以疊印在訊號色上。
- 推導：紙色（暖白、冷白、淺灰，也可以是一個很淺的品牌色）+ 墨 + 一個訊號色。訊號色從品牌或主題裡來，紅色是最常見的那個，先想想別的。

## 字型
- 全片一個 OFL 新怪誕體家族，用多個字重：Archivo、Schibsted Grotesk、Instrument Sans、Inter Tight。字號 ≥ 90px 時字距約 −2%。
- 左對齊、右側不齊，所有東西落在網格線上；巨大的數字在視覺上左對齊（減掉字形的左側餘白）。
- 註釋用同一家族的小字號或等寬字型，像技術說明。

## 運動
- 緩動：`snap`（硬起步、長滑行）和 `whip`；彈簧只用阻尼 ≥ 0.9 的那檔。
- 元素按網格跳位，切換卡在重拍上；遮罩擦除（從基線往上揭開）比淡入好。
- 節奏：靜止和精確的跳變交替，安靜本身就是設計。

## 畫面怎麼活
- 以靜為主：版式落定後整塊不動，生命在跳變的那一下（這是這種風格的語法，落定段寫進 `HOLDS`）。
- 可以活的只放在角落：一根訊號色細線沿網格慢慢延伸；頁碼、座標註釋每拍跳一個數；遮罩邊緣一個小方塊踩拍閃一下。幅度小，不搶主字。

## 鏡頭語法
| 鏡頭運動 | 表達什麼 | 適合哪類內容 |
|---|---|---|
| 固定機位、版式自己變化 | 系統在運轉 | 規則、步驟、對比 |
| 網格對齊的平移 | 翻到下一頁 | 章節切換、列表 |
| 拉遠揭示 | 原來是一個細節 | 巨大數字其實是小版式裡的一部分 |
| 90° 旋轉 | 換一個閱讀方向 | 轉折、反轉 |

## 聲音調色盤
乾淨的電子鼓、精確的 tick 網格、短促的 pluck、click；混響少（≤ 0.15）。第 1 檔合成就夠用。可以留出很多靜音，讓每一次跳變都聽得見。

律動與和聲（舉例，不止這些）：直拍，或者 5/4、7/8 的精確不對稱；一個和絃、四度疊置、無調性的音高網格；`rim`、`tick`、`mallet({ material: 'wood' })` 做精確的打擊。幾乎不用混響。

## 原生手法
- 網格從一個點長出來：適合「從零開始」「體系」類主題。
- 巨大數字其實是一個小版式的區域性：適合資料、年份、價格。
- 色塊擦除換版：適合列表、對比、章節。
- 例外元素離開畫面，系統合攏：適合結尾和收束。

## 變化空間
- 結構：一張時刻表（24 行網格逐行填滿）；一份字母表（A 到 Z，每個字母一個模組）；左右兩套系統對比，直到一個元素越過欄間距。
- 開場：頁面上放下一個點，網格從它長出來；先給出完成的作品，再把它拆回規則；一個巨大數字鋪滿畫面。
- 結尾：所有元素被切走後的空網格；角落裡一個左對齊的詞；例外元素離場。

## 坑
- 欄太細，畫面像圖表；元素沒貼網格，就顯得隨意。
- 加了第二個強調色，系統就散了。
- 用了回彈彈簧或者到處淡入，會變成普通的 PPT 動畫。
