# 電影片頭（cinematic-title）

> 寬銀幕、膠片顆粒、緩慢的推鏡、襯線大字從黑暗中浮現，像一部電影的開場或預告片。
> 參照（只學語法）：電影片頭設計（Saul Bass 的圖形片頭、現代片頭工作室的排版片頭）、預告片的節奏（靜 → 撞擊 → 字卡）。不照搬具體電影的片名設計和畫面。

## 本質 / 不是什麼
- 本質：**一部電影開場的儀式感**。畫面像是被攝影機拍下、調過色的，不像螢幕上直接畫出來的；節奏慢而有重量，撞擊少而重；字和畫面之間留足呼吸。寬畫幅、膠片顆粒、字卡都是常用的手段，按主題從下面的訊號裡挑。
- 不是：隨便加黑邊的普通影片；也不是濫用鏡頭光暈的預告片模板。

## 辨識訊號：每支片子挑 2–3 個
| 訊號 | 長什麼樣 | 適合的主題 |
|---|---|---|
| 寬銀幕黑邊 | 2.39:1，或者黑邊在重拍時收緊 | 電影感、儀式 |
| 膠片質感 | 顆粒、輕微光暈、暗角 | 年代、質感 |
| 字卡節奏 | 黑場 → 一行字 → 黑場 | 預告、懸念 |
| 慢推 | 鏡頭持續很慢地推近 | 緊張、重量 |
| 襯線大字 | 寬字距的襯線體片名 | 史詩、經典 |
| Saul Bass 式圖形 | 剪紙般的平面圖形和線條 | 圖形片頭、懸疑 |
| 光與塵 | 光柱裡的浮塵、漏光 | 氛圍、揭示 |
| 物件微距 | 一個物件的極近特寫，淺景深 | 細節、線索 |
| 手寫或打字機字 | 打字機逐字打出的字幕 | 紀實、年代 |
| 片尾字幕滾動 | 演職員表式的滾動字 | 致謝、結尾 |
| 倒計時膠片頭 | 老膠片的數字倒計時 | 復古、開始 |

規則：
- 每支挑 2–3 個，至少一個不在下面「最俗的版本」裡。
- 訊號從主題裡選，不按順序全上。

## 這個風格最俗的版本
- 畫面：橙青調色、黑邊、鏡頭光暈、襯線片名從光裡顯影、一記 braam 之後黑場。
- 聲音：低頻 boom、braam、上升的絃樂 riser、鋼琴單音。
- brief 的 style 一欄寫明這支片子翻掉了哪幾條，或者為什麼刻意保留（比如使用者要的就是經典版）。保留時，把力氣花在構圖、鏡頭、節奏或一個意外的記憶點上。

## 適配
- 用途：片頭、預告片、品牌情緒片、Logo 落版、釋出倒計時。
- 內容：史詩、故事、歷史、重大發布、遊戲、紀念。

## 技術路線
Canvas / DOM 排版 + 畫面內容（圖形、粒子、3D，看主題）+ WebGL 後期（暗角、輕微光暈、輕微色差）+ `--grain 6–10`。畫幅：在 16:9 畫面里加 2.39:1 的黑邊（上下各約 12%），黑邊可以在關鍵時刻動畫（開啟 / 收緊）。

## 材質與渲染
- 色調：高光偏暖、陰影偏冷（橙青調色）或者單色調；對比度高，黑位壓低。
- 光：畫面裡的光有來源（窗、火、螢幕），可以有體積光（徑向模糊的光束）。
- 字卡：襯線大字，字距寬，居中或者偏左下（電影字幕位）；可以有極慢的放大（1.0 → 1.05，整個字卡持續時間）。
- 鏡頭光暈最多一次，只在真的有強光源時。

## 配色
下面的色值是示例，看思路，不要原樣照抄。
- 橙青：陰影 `#0E1A22` / 中間調 `#3A4A50` / 高光 `#F2C48D` / 字 `#F4EEE4`
- 單色暖：`#0B0806` / `#5A4632` / `#E9D8BC`
- 冷峻：`#05080C` / `#2B3A48` / `#C9D6E3` / 一點紅 `#B3261E`
- 推導：電影調色從主題來：橙青、單色暖、冷峻加一點紅、黑白、褪色的柯達暖調都可以；字的顏色全片統一。橙青是最常見的那組。

## 字型
襯線或寬字距的展示體：Cormorant Garamond、Cinzel（謹慎）、Playfair Display、Bodoni Moda、Big Shoulders（工業感）；中文用思源宋體 Heavy、方正類可商用宋體。

## 運動
- 慢：字卡的淡入 0.6–1.2 秒（這裡允許淡入，但要配合緩慢的放大和光的變化）；鏡頭推進持續整段。
- 撞擊：一次大的 `impact` 配合黑場切換或者字卡砸出，全片 2–3 次。
- 節奏：靜（長鏡頭）→ 加速（切點變密）→ 撞擊 → 字卡 → 黑場。

## 畫面怎麼活
- 以靜為主：長鏡頭的慢推本身就是運動。
- 可以活的：光柱裡的浮塵、霧的流動、片名上一道很慢的掃光、鏡頭光暈隨推進緩慢變化。

## 鏡頭語法
| 鏡頭運動 | 表達什麼 | 適合哪類內容 |
|---|---|---|
| 極慢的推進 | 莊重、期待 | 開場、字卡 |
| 從黑暗中拉焦出來 | 揭示 | 主體登場 |
| 快速剪輯蒙太奇 | 能量上升 | 預告高潮 |
| 黑邊收緊 / 開啟 | 情緒轉折 | 高潮、結尾 |

## 聲音調色盤
預告片聲音：sub drone、低沉的 `boom`、braam（低音銅管感：多個低八度鋸齒疊加 + 強濾波開合，可以用 `pad` 低音區 + `drive` 近似）、上升的 riser、撞擊前的完全靜音、鋼琴單音（第 2 檔 Salamander 取樣效果最好）。

律動與和聲（舉例，不止這些）：half-time 或無拍；小調、和聲小調、三度關係的大三和絃（宏大揭示）、持續低音。曲線可以是吸氣 → 爆發，也可以是累加（一路變厚直到片名出現）或抽空（全編制驟停，只剩一個鋼琴音）。大空間（`S.space({ room: 0.9 })`），不側鏈。

## 原生手法
- 黑場 → 一個聲音 → 一行字：適合開場。
- 撞擊時黑邊猛地收緊，畫面切到下一鏡：適合高潮。
- 片名從光裡顯影：適合落版（經典）。
- Saul Bass 式的平面圖形切開畫面，片名卡在圖形之間：適合圖形片頭。

## 變化空間
- 結構：三幕字卡（過去 / 現在 / 未來）；一個問題貫穿全片，最後一行回答；倒計時到釋出日期。
- 開場：全黑中的一個聲音；一束光掃過塵埃。
- 結尾：片名定格，下面一行日期；黑場後一個尾音。

## 坑
- 每一屏都在「史詩」，就沒有史詩：要有靜的段落。
- 顆粒太重、畫面太暗，手機上什麼都看不清：在手機尺寸抽幀圖裡檢查。
- 濫用鏡頭光暈和慢動作。
