# 年代媒介混搭（mixed-media-era）

> 每個年代、每個階段換一種媒介來畫：像素、向量、著色器、3D、手繪……再用一根線把它們串成一部片子。
> 參照（只學語法）：公開傳播的程式碼版「電子遊戲發展史」短片（Canvas 像素 + CRT 著色器 + Three.js 3D + 合成配樂）、媒介史題材的紀錄片片頭。不照搬具體作品。

## 本質 / 不是什麼
- 本質：**媒介本身就是內容**：講哪個年代就用哪個年代的視覺技術；段落之間的切換是一次「媒介升級」；**有一根貫穿全片的線**（同一個主角、同一種轉場、同一首配樂的發展）。
- 不是：隨機拼幾種風格的模板合集。沒有那根線，它就散了。

## 辨識訊號：每支片子挑 2–3 個
| 訊號 | 長什麼樣 | 適合的主題 |
|---|---|---|
| 巖畫、壁畫 | 赭石色的手印、線刻、剝落的牆面 | 起源、遠古 |
| 印刷品 | 活字、報紙半調、孔版套色 | 出版、資訊、19–20 世紀 |
| 膠片 | 顆粒、劃痕、閃爍、黑白或褪色彩色 | 電影、記憶 |
| 手繪賽璐珞 | 12fps 的線稿和平塗 | 動畫、童年 |
| 映象管和錄影帶 | 掃描線、跟蹤噪聲、OSD 字 | 80–90 年代、電視 |
| 像素 | 小畫布、固定調色盤、步進 | 遊戲、早期電腦 |
| 終端字元 | 等寬字元、綠色或琥珀色屏 | 計算機、網際網路早期 |
| 向量扁平 | 乾淨的幾何和平塗 | 移動網際網路、現代 |
| 3D 渲染 | 光影、材質、空間鏡頭 | 近年、未來 |
| 著色器 / 生成 | 噪聲場、粒子、液態 | 演算法、AI、未來 |
| 紙藝和實物 | 剪紙、黏土、手工的質感 | 手作、個人史 |

規則：
- 每支挑 2–3 個，至少一個不在下面「最俗的版本」裡。
- 訊號從主題裡選，不按順序全上。
- 媒介從主題的真實歷史裡選：講出版史可以從活字走到螢幕，講音樂可以從唱片封套走到流媒體介面，講一個人可以從兒童塗鴉走到工作裡的螢幕。
- 貫穿的線也要選，至少一根：同一個主角、同一個構圖骨架、同一種轉場語法、同一首配器逐段升級的配樂。

## 這個風格最俗的版本
- 畫面：遊戲史式的路線：像素 → 16-bit → 低多邊形 3D → 現代渲染，嚴格按時間順序，結尾所有年代的畫面拼成一面牆再收成 logo。
- 聲音：晶片音樂 → 合成器 → 管絃樂，一段一段升級。
- brief 的 style 一欄寫明這支片子翻掉了哪幾條，或者為什麼刻意保留（比如使用者要的就是經典版）。保留時，把力氣花在構圖、鏡頭、節奏或一個意外的記憶點上。

## 適配
- 用途：歷史回顧、作品集、產品進化史、品牌週年。時長常常比較長（60 秒–2 分鐘）；超過 60 秒時要分段製作並分段檢查。
- 內容：遊戲史、網際網路史、技術演進、品牌歷史、個人成長。

## 技術路線
一個頁面，多個段落渲染器（每段一個函式，各自用 Canvas / WebGL / Three.js），由 `timeline.js` 裡的段落時間排程；共享一個相機抽象和一套轉場函式。渲染慢的段落（3D、著色器）單獨用 `--start --duration` 測試和重渲。每段的技術要點參照對應的風格檔案（`pixel-game.md`、`crt-vhs.md`、`glass-material.md` 等），但配色和字型要服從全片的主線。

## 材質與渲染
- 每段遵守那個年代媒介的真實限制（像素段真的只用 16 色，CRT 段真的有掃描線），這是可信度的來源。
- 主線元素（比如一個主角符號、一個光點、一個標題字）在每個媒介裡都以那個媒介的方式重繪：像素版、向量版、3D 版……觀眾一眼就知道「還是它」。**主線元素也要過這個媒介的材料處理**（像素化、掃描線、紙紋、筆觸），只把背景換成新媒介、主角還是原來的向量圖形，它看起來就像貼上去的。
- **構圖骨架固定**：主角、地平線、標題、計數器的位置在每一段都對齊同一組座標（在程式碼裡寫成一份常量，每段從這裡取）。骨架不動，觀眾才看得清變的是媒介；轉場也可以從這些固定的物體上長出來。要換構圖的段落是刻意的例外，寫進分鏡。
- 年份 / 標籤字卡用統一的排版（全片一致），這是另一根線。

## 配色
下面的色值是示例，看思路，不要原樣照抄。
- 每段用那個媒介的典型配色，但全片有一個固定的強調色貫穿（比如主線元素永遠是同一個顏色）。
- 字卡的顏色全片統一。
- 推導：每段用那個媒介的典型配色，全片一個固定的強調色貫穿（主線元素永遠是這個顏色），從品牌來；字卡顏色全片統一。

## 字型
- 字卡：全片一種（比如等寬字型寫年份）。
- 段落內：可以用那個年代的字型（像素字型、80 年代粗斜體、現代無襯線）。

## 運動
- 每段遵守媒介的運動規則（像素段步進、3D 段平滑、手繪段 12fps），這就是媒介的「聲音」。
- **貫穿的東西按全片時間走**：主角的動作、計數器（年份）的值只由全片的 t 決定，換段不重來。這樣轉場兩側的姿勢是接上的，觀眾看到的是同一個瞬間換了一種媒介；如果每段都按段內時間把動作從頭演一遍，看到的就是同一個動作被重複了五次。只有某一段專屬的表演才用段內時間。計數器跨轉場時，新舊兩層顯示同一個正在滾動的數字，各用各的字型，在轉場中點切換，不疊在一起。
- 轉場就是「升級」：畫面解析度突然提高；2D 平面向後倒下變成 3D 地面；像素塊細化成向量。轉場的樣子由**下一個**媒介怎麼出現來定（craft.md 第 5 節），揭開那一幀對在小節線上；全片的轉場語法要統一。
- 節奏可以一路加速：BPM 不變，每段的拍數越來越少，最後一段放長（craft.md 第 2 節「加速」）。

## 畫面怎麼活
- 每段停留時，主線元素一個連續動作，再加 2–3 個那個年代媒介自己的小循環：像素段的 HUD 閃爍、問號塊彈一下；CRT 段的滾動幹擾條；膠片段的劃痕和閃爍；3D 段的環境光慢慢轉。
- 第一段前面沒有轉場可借時，讓畫面「自己畫出來」：像素一行行點亮、向量線一筆筆描出、套色一版版落下。

## 鏡頭語法
| 鏡頭運動 | 表達什麼 | 適合哪類內容 |
|---|---|---|
| 推近一塊螢幕進入下一個年代 | 穿越時間 | 段落切換 |
| 2D → 3D 鏡頭升起 | 維度升級 | 重大的技術躍遷 |
| 拉遠看到所有年代並排 | 回顧 | 結尾 |

## 聲音調色盤
**配樂也跟著年代升級**：開頭是晶片音樂（方波、噪聲），中段加入合成器鋪底和鼓機，後段加入取樣樂器和大混響（第 2 檔：鋼琴、寬闊的空間），高潮時所有元素合在一起。一首曲子貫穿全片、配器逐段升級，這是最強的那根線。BPM 全片固定或緩慢上升。

律動與和聲（舉例，不止這些）：BPM 全片固定，律動隨年代變（晶片直拍 → 80 年代門控軍鼓 → breakbeat → 現代 half-time）；媒介感靠 bus 的 `crush`（晶片）和 `wow`（磁帶）逐段去掉，最後一段乾淨、寬。一個三四個音的短動機貫穿全片，每段換成那個年代的代表音色、跟著和絃移調，比每段寫一首新曲子更像「一部片」。畫面先定、段長不規則時，逐段微調速度讓邊界落在小節第一拍（sound.md 第 8 節）。

## 原生手法
- 解析度躍遷：像素畫突然變成高畫質，同一個構圖。適合技術進步。
- 同一個主角在每個媒介裡重生：適合進化、成長。
- 最後所有年代的畫面拼成一面牆，再收成一個 logo：適合回顧和結尾。

## 變化空間
- 結構：按年代順序；倒敘（從今天回到最初）；同一個動作在 6 個年代裡各做一次；同一個房間或街角不動，只有媒介在變；主角從左走到右，跨過一條邊界就換一個年代（長卷）。
- 年代數沒有下限：3 個年代也成立，要守住的是骨架不變、媒介在變。
- 開場：一個像素點；一臺舊機器開機的聲音；第一幅畫自己畫出來。
- 結尾：給主線元素留一個小小的梗或表演，前面是「看」，最後幾秒讓人笑或者愣一下，再落版。
- 結尾：回到最初的那個像素點（首尾呼應）；今天的畫面拉遠，原來也只是未來某塊螢幕裡的一幀。

## 坑
- 沒有貫穿的線，就成了風格拼盤。
- 每段按段內時間重演動作：轉場兩側姿勢對不上，觀眾數得出主角把同一件事做了幾遍。
- 只換背景，主線元素沒過新媒介的材料處理，像貼紙。
- 簽名轉場太短：複雜的形狀 0.3 秒裡讀不出來，至少給 0.45 秒，用 `strip --at` 看。
- 每段都做得很滿，時長和渲染時間失控：每段 8–20 秒，先做低清小樣確認整體節奏。
- 史實錯誤：年份、名稱、首創者都要核實，不確定的就不寫，列給使用者確認。
