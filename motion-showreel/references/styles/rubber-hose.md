# 橡皮管動畫（rubber-hose）

> 四肢像柔軟的管子一樣彎曲，角色先蓄力再彈出去，連身邊的器物也會跟著節奏做出反應。
> 參照（只學語法）：早期橡皮管動畫、無明顯肘膝的曲線角色、音樂驅動的擬人表演。不照搬經典卡通角色、輪廓組合、標誌性道具或旋律。

## 本質 / 不是什麼

- 本質：**用連續曲線和誇張的蓄力、擠壓、伸展完成表演**。角色可以暫時違背解剖，但重心、接觸點與動作因果仍然清楚；肢體彎得越自由，落點越要準確。
- 不是：`comic-pop` 的靜態分格衝擊，也不是 `soft-3d-toy` 的柔軟三維材質。這裡的彈性來自二維輪廓與姿態設計，舊膠片噪點只是可選表面。

## 辨識訊號：每支片子挑 2–3 個

| 訊號 | 長什麼樣 | 適合的主題 |
|---|---|---|
| 無肘膝曲肢 | 手臂與腿像彎管，轉彎連續順滑 | 角色、輕喜劇、動作 |
| 擠壓與伸展 | 身體壓低再拉長，重量感仍在 | 蓄力、跳躍、反應 |
| 提前反向動作 | 往右走前先往左壓，觀眾預感下一步 | 期待、驚喜、因果 |
| 圓弧運動 | 手腳沿大而清楚的弧線移動 | 舞蹈、工作、表演 |
| 器物擬人 | 水壺、工具或字母臨時長出表情和動作 | 品牌、功能、故事 |
| 節奏性步態 | 走路的落腳、擺臂和身體起伏互相配合 | 旅程、循環、行進 |
| 延遲跟隨 | 手套、耳朵或配件在主體停住後再落位 | 重量、餘韻、幽默 |
| 簡潔面部形變 | 眼口的大小和位置表達明確情緒 | 反應、情感、短敘事 |
| 彎管傳力 | 一個動作沿身體或連線物傳到另一端 | 協作、連鎖、功能 |
| 舞臺式留白 | 單純背景襯托清楚的動作剪影 | 角色介紹、Logo、表演 |

規則：

- 每支挑 2–3 個，至少一個不在下面「最俗的版本」裡；訊號從主題裡選。
- 白手套、缺角眼和黑白畫面都不是必選項。先把角色輪廓與動作做成自己的，再考慮時代裝飾。

## 這個風格最俗的版本

- 畫面：黑白圓頭角色戴白手套，在膠片劃痕裡左右搖擺，最後跳進圓形收幕。
- 聲音：舊爵士樂從頭到底，腳步、眨眼、揮手都緊貼一個樂器音符。
- brief 的 style 一欄寫明翻掉了哪幾條，或者為什麼保留經典版。可以用現代配色、器物主角或剋制的單次反應。

## 適配

- 用途：吉祥物與品牌宣傳、輕喜劇功能講解、Logo 演繹、音樂卡點、循環。
- 內容：有明確慾望或任務的角色、能看見原因和結果的小動作、器物之間的合作。
- 不適合：嚴肅事故復盤、真實人體運動教學，或全靠複雜對白和微妙面部表演推進的內容。

## 技術路線

- **輪廓與肢體**：SVG 或 Canvas 適合連續曲線、封閉形狀與粗細統一的描邊。Paper.js 可輔助曲線變形和形狀處理，肢體的彎曲方向仍按姿態設計。
- **角色組織**：可以探索簡單骨架、控制曲線或關鍵輪廓插值；PixiJS 適合多層角色與紋理。不要讓預設骨骼硬折角破壞橡皮管輪廓。
- **表演與同步**：動作關鍵點從本片時間表取值，聲音也讀同一組動作落點；曲線插值庫只是輔助，不採用無法亂序還原的即時彈簧狀態。
- 任意時刻能獨立還原擠壓、伸展、接觸與配件滯後。舊片紋理若使用則固定種子；`--subframes` 從輕，先檢查快速姿態是否糊掉；`--dpr` 保描邊，`--grain` 可關閉。

以上是候選方向，不規定角色骨架、彈性公式和動畫引擎。

## 材質與渲染

- 製作依據：二維墨線包住平整色塊，形體能伸縮，但輪廓始終簡明。先看黑色剪影能否說明動作，再加五官與裝飾。
- 擠壓時身體變寬，伸展時適當變窄，保留近似體量；不能只拉長一根軸，讓角色像被縮放工具扯壞。
- 手腳接觸地面或物件時短暫鎖住，身體繼續蓄力；離開接觸點後再恢復自由曲線。
- 四肢交叉時明確遮擋，手套、鞋或其他端部形狀幫助認清方向；這些端部可以原創，不必復刻經典組合。
- 背景也可擬人，但線條、填色和陰影層級與角色相容。膠片顆粒若存在，強度不能遮住表情，劃痕不能每幀換位置搶戲。

## 配色

下面的色值是示例，看思路，不要原樣照抄。

- 墨色與暖紙：底 `#EDE3CF` / 主體 `#292725` / 強調 `#BE684E`。
- 奶油與深綠：底 `#F0DFC0` / 主體 `#42685B` / 配件 `#CE8B45` / 線 `#2B3530`。
- 淡藍與磚紅：底 `#CEDFE1` / 主體 `#AA554B` / 輔助 `#E9C87D` / 線 `#303039`。
- 推導：角色用少數大色塊，深色輪廓與背景分離；品牌色可以落在身體或道具上。黑白成立，有限彩色也成立，不能靠棕黃濾鏡決定年代感。

## 字型

英文展示可選 Archivo Black、Bowlby One SC，輔助用 DM Sans；中文用思源黑體，自託管 OFL 字型。展示字可隨情緒輕微彎曲，但長句保持正常字形。文字擬人時先保證讀得出，再做四肢與表情。

## 運動

- 動作通常先有準備，再快速發力，最後帶少量過沖和跟隨；停頓是喜劇節奏的一部分。
- 身體走圓弧，四肢呈連續彎曲；允許極端伸展作為瞬間強調，但必須落回可辨認的姿態。
- 一組動作圍繞一個明確目的展開。進場可探頭、被拉入或大步跨入；離場也需要原因，不能所有物件無緣無故彈走。

## 畫面怎麼活

- 角色等待時輕輕換重心、腳尖敲一下或看向目標，動作之間有安靜間隔。
- 配件在主體停下後做一次小幅餘擺，逐漸停穩，不永遠振盪。
- 擬人器物可偶爾回應主角，例如蓋子抬一下；背景不與主角一起全屏律動。

## 鏡頭語法

| 鏡頭運動 | 表達什麼 | 適合哪類內容 |
|---|---|---|
| 固定舞臺式全身景 | 看清準備、動作與結果 | 喜劇、功能、循環 |
| 隨角色橫移 | 持續的任務或行進 | 旅程、品牌故事 |
| 動作停下後小幅推近 | 強調反應 | 表情、驚喜、結論 |
| 拉遠露出牽動角色的另一端 | 補出動作原因 | 連鎖、協作、反轉 |

## 聲音調色盤

第 1 檔可用撥絃、木質打擊、圓潤貝斯、短滑音和噪聲動作音。需要真實簧管、銅管、班卓或刷鼓時，用第 2 檔 Tone.js 配合授權取樣。音樂可回應關鍵動作，但只挑準備、觸地和意外等少數點，留出無聲反應；有口播時避免密集滑音搶字頭。

律動與和聲（舉例，不止這些）：輕快搖擺、帶空拍的切分，或現代簡潔的彈性節奏。慢動作喜劇也可用稀疏低音，不把擬人動畫統一寫成忙碌爵士。

## 原生手法

- 先壓低身體，再拉成長弧跳向目標：適合蓄力與行動（經典）。
- 手臂伸長牽動遠處物體，拉遠才看見另一端：適合連線、服務和喜劇揭示。
- 一個碰撞沿身體傳到配件，再引起下一件器物反應：適合連鎖與協作。
- 字母暫時彎曲參與動作，落位後恢復可讀標題：適合 Logo 和短標題。
- 角色身體短暫成為門、橋或工具，完成任務再恢復：適合功能隱喻，先確保用途容易理解。

## 變化空間

- 結構：圍繞一個小任務反覆嘗試；動作在幾個器物間傳遞；一個角色與同一物件產生不同反應。
- 開場：角色已被某物牽住；先見一個誇張準備姿態；普通器物突然做出很小的回應。
- 結尾：任務完成後停一下再給反應；道具恢復原狀、角色離開；動作自然返回最初的準備姿態。

## 坑

- 只有彈簧縮放，沒有表演：補上目的、準備、接觸和結果。
- 管狀四肢出現硬折角：調整曲線連續性，讓肢體從肩胯自然接出。
- 腳底一直滑：落腳階段鎖住接觸，身體重心從上方經過。
- 所有東西不停上下彈：一次突出一個動作，其餘物件保持參照。
- 極端伸展後體積暴漲：同時調整寬度與輪廓，檢查剪影。
- 音樂逐幀打點讓人疲勞：只保留有因果作用的聲畫同步。
- 用熟悉的眼睛、手套、頭形拼出近似經典角色：重做輪廓與配件組合，建立原創主體。
- 蓄力切到騰空時突然變形：銜接處同時檢查身體寬高、旋轉與手腳位置，不能只讓重心軌跡連續。
- 手明明抓住器物，縮小後卻看成身體的一部分：拉開接觸手、配件與主體的輪廓，近景和手機尺寸都要能認出接觸關係。
