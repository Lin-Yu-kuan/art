# 生成幾何（generative-geometry）

> 由規則生成的圖形：陣列、波、旋轉的環、對稱的花紋，每個元素只差一個相位，合起來就是湧動和秩序。
> 參照（只學語法）：生成藝術（Vera Molnár、Manfred Mohr）、bees & bombs 式的循環 GIF、包豪斯幾何、示波器圖形。只學規則的思路，不復制具體作品。

## 本質 / 不是什麼
- 本質：**少量簡單元素 × 一條規則 × 相位錯開**；大部分畫面由週期函式驅動；結構清晰、可以說出它的規則。
- 不是：隨機散佈的形狀；也不是裝飾性的科技背景。

## 辨識訊號：每支片子挑 2–3 個
| 訊號 | 長什麼樣 | 適合的主題 |
|---|---|---|
| 網格陣列 | 規則排布的點、線、方塊，按相位錯開 | 秩序、系統 |
| 同心環 | 一圈圈旋轉的環，轉速不同 | 節奏、循環 |
| 波的傳播 | 一道波穿過陣列 | 傳播、影響 |
| 對稱花紋 | 映象、旋轉對稱，像萬花筒 | 裝飾、儀式 |
| 示波器圖形 | 利薩如曲線、正弦線 | 聲音、訊號 |
| 線的編織 | 很多線交錯形成摩爾紋 | 複雜、連線 |
| 遞迴細分 | 一個方塊不斷分成更小的方塊 | 生長、分形 |
| 單筆連續線 | 一條線不斷畫出圖形 | 連續、過程 |
| 真實度量 | 規則來自資料：時間、頻率、人數 | 資料藝術 |
| 極簡位移 | 一個方塊在網格里一步一步走 | 剋制、詩意 |

規則：
- 每支挑 2–3 個，至少一個不在下面「最俗的版本」裡。
- 訊號從主題裡選，不按順序全上。

## 這個風格最俗的版本
- 畫面：黑底白線的旋轉同心圓或點陣波浪，全程勻速，結尾點陣排成 logo。
- 聲音：持續的琶音器加一個長鋪底，沒有起伏。
- brief 的 style 一欄寫明這支片子翻掉了哪幾條，或者為什麼刻意保留（比如使用者要的就是經典版）。保留時，把力氣花在構圖、鏡頭、節奏或一個意外的記憶點上。

## 適配
- 用途：循環動圖、作品集、片頭、Logo 演繹（logo 由陣列組成或從陣列中浮現）、音樂視覺化。
- 內容：設計、數學、演算法、音樂、品牌情緒。

## 技術路線
Canvas 2D 足夠（幾千個元素以內）；元素很多或需要逐像素計算時用 WebGL 著色器。所有運動都寫成 `θ = TAU * t / DUR` 的整數倍頻率函式，循環天然無縫。驗收加 `--loop`。

## 材質與渲染
- 元素：點、線段、圓環、方塊、三角，統一線寬或統一尺寸。
- 陣列：網格、極座標、六邊形、斐波那契螺旋；每個元素的相位 = f(序號, 位置)，比如 `phase = dist(center) * k`（波紋）、`phase = angle * n`（旋轉）。
- 疊加：同一陣列畫兩次，第二次偏一個相位或換一個顏色，`difference` / `multiply` 合成。
- 抗鋸齒：細線用 `--dpr 2`。

## 配色
下面的色值是示例，看思路，不要原樣照抄。
- 單色：黑底白線，或白底黑線
- 雙色：`#111` / `#F2EEE6` + 一個強調（`#FF4D2E`）
- 漸近：一組同色相的明度漸變，按相位上色
- 規則：顏色本身也可以是相位的函式，但要有明確的明度結構。
- 推導：先定明度結構，再定顏色：單色、雙色加一個強調、同一色相的明度漸變都可以；顏色可以是相位的函式。黑底白線是最常見的那種，淺底深線、品牌色底也可以試。

## 字型
常常沒有文字；需要時用一個極簡的幾何無襯線體（Space Grotesk、Outfit），字小，放在角落或結尾。

## 運動
- 週期運動，勻速旋轉和正弦振盪在這裡是正確的。
- 節奏：每 2 或 4 拍完成一次完整的變換（展開 → 收攏），重拍上翻轉或反相。
- 「呼吸」：整體縮放 1.0 ↔ 1.04 的慢週期。

## 畫面怎麼活
- 週期運動本來就是本色。停留時可以只讓一層的相位慢慢錯開（陣列從整齊同步走向錯落），看得出在變，又不累。
- 重拍上讓一個格子或一圈反相，作為小的強調。

## 鏡頭語法
| 鏡頭運動 | 表達什麼 | 適合哪類內容 |
|---|---|---|
| 固定 | 規則本身 | 循環 |
| 極慢的旋轉 | 催眠 | 背景、片頭 |
| 拉遠發現陣列是更大圖形的一部分 | 尺度 | 記憶點 |

## 聲音調色盤
與節拍嚴格同步的電子音：tick 網格、方波琶音、帶濾波掃頻的鋪底；或者完全無聲（GIF 用）。第 1 檔合成即可；聲音也要循環。

律動與和聲（舉例，不止這些）：復節奏（3 : 4、5 : 4 疊在一起）、相位錯開的重複（Reich 式）；全音階、四度疊置，或者只有一個和絃。累加或波浪曲線往往比 drop 更合適。

## 原生手法
- 陣列整體在一拍內翻轉 / 反相：適合卡點。
- 相位錯開形成波浪穿過陣列：適合「傳播」「影響」。
- 點陣逐漸排成 logo 的形狀（每個點的目標位置由 logo 取樣）：適合落版。

## 變化空間
- 結構：一個規則逐步加一個引數；同一陣列換 4 種相位函式；一次完整的展開與收攏。
- 開場：一個點分裂成一圈；一條線複製出整個陣列。
- 結尾：所有元素回到一個點（循環回開頭）；陣列定格成 logo。

## 坑
- 用了逐幀累積的模擬，循環接不上：改用週期函式。
- 元素太多，幀時間暴漲：先測單幀，必要時改 WebGL。
- 沒有規則、看起來像隨機：每一個變化都要說得出規則。
