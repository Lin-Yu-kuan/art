# 漫畫分格（comic-pop）

> 畫面是一頁會動的漫畫：分格、粗墨線、網點、速度線和擬聲大字，節奏像翻頁，衝擊像一記重拳。
> 參照（只學語法）：美式漫畫的分格和四色印刷、波普藝術對漫畫網點的放大、日本漫畫的速度線和集中線、日式作畫的拖影和定格。不照搬具體漫畫的角色、分鏡和擬聲字設計。

## 本質 / 不是什麼
- 本質：**用漫畫的敘事語法講一件事**。時間被切成格子，讀者的眼睛按格子的順序走；動作靠線條和定格表達，不靠連續的平滑運動；衝擊靠擬聲字、集中線和一格放大來放大。
- 不是：在普通畫面上貼幾個「BOOM」；也不是把照片加個漫畫濾鏡。

## 辨識訊號：每支片子挑 2–3 個
| 訊號 | 長什麼樣 | 適合的主題 |
|---|---|---|
| 分格版面 | 畫面切成幾格，格子之間有白色溝槽，鏡頭在格子間移動 | 敘事、步驟、對比 |
| 粗墨線 | 外輪廓粗、內部線細，線有起筆收筆 | 角色、物件、產品 |
| 網點 | 大圓點網點做明暗，或者一整塊網點紙 | 復古、波普 |
| 速度線 | 平行的直線拖在運動物體後面 | 速度、衝刺 |
| 集中線 | 從四周射向中心的線，把視線壓到一點 | 震驚、揭示、強調 |
| 擬聲大字 | 帶描邊和透視的手寫感大字，跟著動作炸開 | 衝擊、笑點 |
| 對白氣泡 | 圓泡、鋸齒泡、思考泡，字一個個蹦出來 | 對話、內心獨白 |
| 定格加拖影 | 動作到最高點定住一兩幀，前面拖幾層殘影 | 動作、發力 |
| 四色錯版 | 青、品、黃、黑四個色版輕微錯開 | 復古印刷、波普 |
| 格子破框 | 角色或物體衝出格子的邊框 | 高潮、突破 |
| 黑白日漫 | 只有黑白和灰網，大量留白和細線 | 情緒、懸疑 |

規則：
- 每支挑 2–3 個，至少一個不在下面「最俗的版本」裡。
- 訊號從主題裡選，不按順序全上。
- 格子順序就是閱讀順序：橫排從左到右、從上到下；日漫風格從右到左時，要在 brief 裡寫明。

## 這個風格最俗的版本
- 畫面：黃底紅網點、一個「POW!」炸開、波普風的眼淚女孩或拳頭、四格同時換色。
- 聲音：卡通音效包（boing、拳擊聲）加輕快的爵士。
- brief 的 style 一欄寫明這支片子翻掉了哪幾條，或者為什麼刻意保留（比如使用者要的就是經典版）。保留時，把力氣花在構圖、鏡頭、節奏或一個意外的記憶點上。

## 適配
- 用途：金句卡點、產品功能的「超能力」演示、遊戲預告、反轉劇情、動效作品集的一段。
- 內容：遊戲、潮流、年輕品牌、幽默、衝突和反轉、開發者的「翻車到修好」。
- 不適合：需要可信和剋制的主題（金融資料、醫療）；人物需要寫實表演的。

## 技術路線
Canvas 2D 就夠：分格用 clip 分別畫每一格，網點用小 tile 的 `createPattern`（比逐點畫快得多），墨線用可變線寬的路徑（沿點列兩側偏移成多邊形）。每一格是一個獨立的「小舞臺」，各有自己的相機。擬聲字先用字型排好，再轉成路徑加描邊、透視和抖動。不加 `--grain`；需要老漫畫紙感時，在紙色上疊一層很淡的纖維紋理。

## 材質與渲染
- 墨線：外輪廓 1.5–2 倍於內部線；線的兩端收尖。墨是近黑，不用純黑。
- 網點：45° 網格，點徑隨明暗變；網點只畫在暗部和背景，不蓋住角色的臉。
- 上色：平塗，不做漸變；需要明暗時用網點或者第二個平塗色。
- 擬聲字：粗體大字，白色或亮色填充 + 粗黑描邊 + 一個錯開的陰影色；字的透視順著動作方向。
- 氣泡：白底黑邊，尾巴指向說話的人；字用手寫感字型，字號統一。
- 格子溝槽：白色，寬度統一（約畫面短邊的 1.5%）；破框的東西壓在溝槽上面。

## 配色
下面的色值是示例，看思路，不要原樣照抄。
- 四色印刷：紙 `#F4ECD8` / 青 `#1FA2D8` / 品紅 `#E53A6E` / 黃 `#F7D23E` / 墨 `#16130F`
- 日漫黑白：紙 `#FAFAF7` / 墨 `#111111` / 灰網 `#9A9A9A`，加一個只在高潮出現的紅 `#D62828`
- 現代美漫：深底 `#14161F` / 電光藍 `#3D7BFF` / 橙 `#FF7A1A` / 白
- 推導：平塗色最多 4 個加墨和紙，從主題或品牌來；高潮的那一格可以反色或換一個刺眼的顏色。黃底紅網點是最常見的那組。

## 字型
- 擬聲字：Bangers、Luckiest Guy、Titan One（OFL），中文用站酷快樂體、站酷高階黑，或者直接用路徑手寫。
- 對白：Comic Neue、Patrick Hand、Kalam（OFL）；中文用霞鶩文楷或站酷小薇體。
- 對白字號統一，一個氣泡最多兩行。

## 運動
- 格子裡的動作按 12fps 甚至 8fps 步進，像一張張作畫；鏡頭在格子之間的移動保持平滑。
- 動作的節奏：預備 → 一兩幀拖影 → 定格在最高點 → 擬聲字炸開（彈簧 `{3.2, 0.5}`，從 140% 落到 100%）。
- 換格可以硬切，也可以讓鏡頭沿閱讀順序滑到下一格（`glide`，0.3–0.5 秒）。
- 速度線和集中線本身不移動，只是每兩三幀換一組線（種子固定），產生抖動感。

## 畫面怎麼活
- 速度線、集中線每 2–3 幀換一組（固定種子），一直在微微閃動。
- 氣泡裡的字一個個蹦出來；角色眨一下眼；背景網點輕輕漂移。
- 定格的那一格以靜為主，只讓擬聲字和集中線在動。

## 鏡頭語法
| 鏡頭運動 | 表達什麼 | 適合哪類內容 |
|---|---|---|
| 沿閱讀順序從一格滑到下一格 | 時間推進 | 敘事、步驟 |
| 推進一格直到它佔滿畫面 | 進入這個瞬間 | 高潮、細節 |
| 拉遠露出整頁 | 原來這是一整頁漫畫 | 結尾、回顧 |
| 格子內急推加集中線 | 震驚 | 反轉、揭示 |
| 一格里的角色衝破邊框跳進下一格 | 突破、連續 | 轉場 |

## 聲音調色盤
乾脆的打擊樂和擬聲：`impact`、`pop`、`whoosh` 跟著擬聲字的時機，拳風用很短的 `noise` 掃頻；音樂用有彈性的鼓和貝斯。第 1 檔合成即可。

律動與和聲（舉例，不止這些）：breakbeat 或者 funk 的切分；也可以學日式動畫的「靜 → 一記重音 → 靜」，大量留白，衝擊處才有聲音；大調或 Mixolydian 做輕快，Phrygian 做對決。每一格換一次配器也很適合翻頁的節奏。

## 原生手法
- 一格推滿畫面，裡面的細節就是下一格：適合層層深入。
- 角色衝破格子邊框跳進下一格：適合轉場和「突破」類主題。
- 拉遠露出整頁，所有格子連起來講完一個故事：適合結尾。
- 擬聲字本身變成下一鏡的畫面（字的筆畫裡是下一格）：適合卡點轉場。
- 一個「POW」炸開配四格換色：經典，使用者要波普經典版時用。

## 變化空間
- 結構：一頁四格講完一個梗；一個產品功能的「起承轉合」；左右兩格對比「之前 / 之後」；一格一格倒著讀回去揭開真相。
- 開場：空白的漫畫頁，第一格的墨線自己畫出來；一個對白氣泡先出現，再露出說話的人。
- 結尾：拉遠成整頁、翻到封底是 logo；最後一格破框，角色把 logo 推進畫面。

## 坑
- 格子太多，手機上每格都太小：一屏最多 4 格，關鍵格要佔畫面一半以上。
- 動作做成平滑補間，就不像漫畫了：動作步進、關鍵幀定格。
- 擬聲字滿屏都是，衝擊就沒了：全片 2–3 個，只放在最重的幾個拍子上。
- 網點太細，編碼後出現摩爾紋：網點直徑 ≥ 6px（1080p）。
- 照搬知名漫畫角色和擬聲字設計：只學語法。
