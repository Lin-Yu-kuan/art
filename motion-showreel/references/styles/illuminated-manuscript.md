# 泥金手抄本（illuminated-manuscript）

> 墨字、礦物色、泥金或金箔留在羊皮紙上，首字母和頁邊裝飾帶著故事緩緩活起來。
> 參照（只學語法）：歐洲彩飾手抄本、哥特式裝飾首字母、頁邊細密畫。

## 本質 / 不是什麼

- 本質：以書頁為構圖單位，把文字、插圖和貴重金飾組織成同一件手工作品。金色的材料變化與紙頁的安靜共同構成質感。
- 泥金繪飾與貼金箔的表面不同，按選定工藝處理；不要把所有金色都畫成鏡面。彩色玻璃依賴透光，這裡依賴紙上顏料與金屬的反射。

## 辨識訊號：每支片子挑 2–3 個

| 訊號 | 長什麼樣 | 適合的主題 |
|---|---|---|
| 裝飾首字母 | 大字母與植物或細密畫巢狀 | 文學、開篇、品牌首字母 |
| 有起伏的金地 | 金飾有細紋、接縫或壓印 | 工藝、珍藏 |
| 區域性反射 | 光走過時，只有金屬區域明顯變亮 | 發現、喚醒 |
| 羊皮紙頁面 | 溫潤纖維、邊緣色差、淺褶皺 | 書籍、記憶 |
| 紅藍礦物色 | 平塗顏料厚實，墨線精細 | 歷史、寓言 |
| 頁邊藤蔓 | 莖葉圍繞版心，不覆蓋正文 | 生長、時間 |
| 硃紅引題 | 短題或首句用紅色標明層級 | 章節、命名 |
| 頁邊小生靈 | 鳥獸在書頁邊界裡作有限表演 | 輕寓言、文化 |
| 雙欄或整齊書寫行 | 文字行距穩定，插圖打破區域性秩序 | 閱讀、檔案 |
| 手工壓印 | 金地上的點紋和刻線隨光顯隱 | 細節、材質 |

規則：每支挑 2–3 個，至少一個不在俗套裡。具體地域、年代和書體要有依據；幻想創作明確標為當代演繹。

## 這個風格最俗的版本

- 畫面：黃紙、黑體哥特字、滿屏金色漸變、對稱藤蔓、漂浮星光。
- 聲音：莊嚴合唱加鐘聲，每次金色發亮都響魔法鈴。
- brief 寫明保留哪些古典訊號、如何從主題重新安排書頁。可以小而幽默，也可以嚴肅，不預設宗教故事。

## 適配

- 用途：文化藝術片頭、書籍宣傳、文學主題、珍藏工藝、短寓言。
- 內容：值得慢讀的文字、書頁裡發生的動作、裝飾與意義相互關聯的題材。
- 精確復原須註明時代和來源；沒有史料依據的細節作為幻想設計，不宣稱文物復刻。

## 技術路線

- Canvas 或 SVG 分開紙面、顏料、墨線、金飾和動態插圖。靜態複雜裝飾可以快取，只有光與動作按時間更新。
- 金飾單獨建立幾何遮罩與材質層，不用按畫面黃色閾值誤選紙面和皮膚。WebGL 可處理細法線、粗糙度和方向光反射；Canvas 可用固定紋理加受控光帶近似。
- 有翻頁或明顯側視時考慮 Three.js 的薄頁網格、雙面材質與區域性彎曲。正面書頁不必為技術複雜度強加三維。
- SVG 路徑適合藤蔓展開和有限關節動畫；Paper.js 可輔助曲線整理。插畫仍須人工檢查結構和遮擋。
- `--subframes 1–2` 適合慢動作；細裝飾可提高 `--dpr`。紋理在紙面座標中固定，不靠逐幀全屏噪點。

## 材質與渲染

- 工藝依據：書頁先留出版心與插圖位置，再畫墨線、填顏料，區域性施金並磨光或壓飾。讓各材料佔據不同的反射範圍。
- 羊皮紙以低對比纖維、區域性色差和邊緣暗化組成。汙點不能蓋過字，紋理縮小後應仍是一張紙。
- 礦物色以飽滿平塗為主，輕微不勻來自顏料厚薄；主體、葉片和首字母一起處理，避免光滑角色貼在舊紙上。
- 貼金可有細碎褶紋、微小接片和明暗突變；泥金筆繪則更細啞、更均勻。壓印暗緣與亮緣要服從同一入射方向。
- 金屬高光由光源或觀察方向變化產生，限制在金飾遮罩內。寬光帶負責材料感，少量細亮點只作點綴，不能全靠星星代替金屬。

## 配色

示例只看思路，不照抄。

- 朱藍金：紙 `#EDE0BF` / 藍 `#294A79` / 朱 `#A93F35` / 金 `#B58A39`。
- 植物手稿：紙 `#EAE3CA` / 綠 `#415F46` / 墨 `#45372D` / 金 `#C3A458`。
- 暮色書頁：紙 `#DCCCAE` / 紫 `#63516D` / 紅 `#9A414C` / 金 `#AA7D34`。

先確定紙、墨、主顏料和金屬，金屬亮處可以接近淡奶白，暗處仍要保留棕黃；避免把它做成普通黃填色。正文以深墨保證對比。

## 字型

拉丁短題可用自託管 OFL 的 UnifrakturMaguntia、Cormorant Garamond；中文可用思源宋體。黑體哥特書體只用於能讀清的短內容，不能讓長段正文靠裝飾字型硬撐。歷史原文須查證；當代創作可用明確可讀的中文，不編偽拉丁語。

## 運動

- 以書頁為穩定舞臺，藤蔓、鳥獸、字母按內容作區域性動作；動作幅度受插畫比例和頁邊空間約束。
- 葉子依莖的順序展開，動作可以稍有延遲，但不能所有裝飾一起呼吸。
- 光的移動連續、方向一致；鏡頭停下後保留一次緩慢反射，再給安靜落版。
- 翻頁時處理正反面、陰影和遮擋。沒有翻頁需求就保持紙頁穩定，不用萬能書本轉場。

## 畫面怎麼活

- 一片葉子在動作發生處微微彎動，遠處葉片安靜。
- 金地隨一束移動的光改變明暗，紙與顏料保持啞光。
- 頁邊生靈短暫回頭、探身或沿墨線走動，完成後回到可閱讀的姿態。

## 鏡頭語法

| 鏡頭運動 | 表達什麼 | 適合哪類內容 |
|---|---|---|
| 金飾微距拉遠 | 從工藝細節看見書頁 | 珍藏、開篇 |
| 沿版心緩慢移動 | 跟隨文字或邊飾 | 閱讀、旅程 |
| 固定整頁區域性表演 | 裝飾內發生故事 | 寓言、角色 |
| 輕微斜視或掠光 | 讓壓印和金屬可見 | 材質、工藝 |
| 有依據的翻頁 | 時間或章節推進 | 文學、歷史 |

## 聲音調色盤

第 1 檔可用稀疏撥絃、柔和風琴、低強度摩擦與翻紙合成；想要具體古樂器時用第 2 檔加可授權取樣，並如實標註音源。不要把合成撥絃稱為真實魯特琴錄音。

律動可選自由拍的開放五度、輕緩三拍、細密的撥絃問答。小幅光澤變化不必觸發聲音；大空間混響要給紙頁擬音留下近距離感。

## 原生手法

- 首字母裡的枝葉延伸到頁邊：適合故事從文字裡展開（經典）。
- 一次掠光顯出原先不明顯的壓印：適合發現與珍藏。
- 頁邊生靈走入插圖，再返回文字旁邊：適合書內世界與閱讀的關係。
- 墨線先留下形狀，顏料和金飾分層顯出：適合工藝過程。
- 紙頁輕彎，金飾亮起而顏料保持不變：適合材料對比。

## 變化空間

- 結構：從金飾細節看見全頁；全頁裡的區域性小故事；按書寫與施金過程逐層完成。
- 開場：一塊尚未辨認的壓印；已經開啟的書頁；版心旁一處異常活動。
- 結尾：回到能靜讀的整頁；一個動作藏進頁邊；留下明確的下一頁入口。

## 坑

- 黃褐紙和金色一起掃亮：用專用金飾遮罩，分別檢查紙、顏料和金屬區域的亮度變化。
- 只有漸變沒有微結構：補固定褶紋、接片或壓飾；泥金與貼金不要混成同一種表面。
- 星光太多、整頁在發光：減少閃點，用反射方向和粗糙度說明材料。
- 文字被藤蔓圍得太緊：先留版心，再鋪裝飾。鏡頭拉遠後複查中文和短題。
- 背景舊、主體像向量貼紙：共享墨線與顏料紋理，保持邊緣處理一致。
- 全頁裝飾持續搖晃：只動故事發生處，其他區域為閱讀留靜。
- 近景拉遠時正文在畫框邊緣露半截：正文在可完整閱讀的取景下再出現，或提前調整版心與鏡頭。
- 角色起點和終點避開了文字，中途卻飛過標題：給整段軌跡留禁入區，檢查翅膀、尾羽等超出重心的部位。
