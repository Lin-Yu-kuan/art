# 蠟筆繪本（crayon-storybook）

> 蠟筆、彩鉛和水彩畫在紙上，每秒只換十來張，線條微微抖動，像一本會動的童書。
> 參照（只學語法）：手繪繪本插畫、彩鉛動畫短片、p5.brush 的筆刷能力。不照搬具體繪本的角色和畫面。

## 本質 / 不是什麼
- 本質：**筆觸有方向、粗細、顆粒和紙紋**；顏色不完全填滿輪廓；畫面按 12fps 步進，每一張都有細微的不同（boiling line），鏡頭仍然平滑。
- 不是：向量扁平插畫加一層紙紋濾鏡；也不是用 SVG 畫寫實人臉。

## 辨識訊號：每支片子挑 2–3 個
| 訊號 | 長什麼樣 | 適合的主題 |
|---|---|---|
| 沸騰線 | 線稿按 12fps 輕輕抖動 | 手繪、童趣 |
| 蠟筆塗色 | 顏色不填滿輪廓，露出紙色和筆觸方向 | 溫暖、天真 |
| 水彩暈染 | 顏色在紙上暈開，邊緣有水痕 | 柔和、情緒 |
| 彩鉛排線 | 細密的斜線疊出明暗 | 細膩、安靜 |
| 剪貼紙片 | 手繪的紙片被剪下來移動 | 遊戲感、手工 |
| 小角色 | 簡單的豆子形或火柴人角色 | 故事、吉祥物 |
| 書頁 | 頁邊、頁碼、翻頁的動作 | 敘事、章節 |
| 擦除重畫 | 橡皮擦掉一塊，重新畫上 | 修改、改變 |
| 手寫字 | 歪歪扭扭的手寫標題和對白 | 文案、對話 |
| 畫筆入畫 | 一支筆從畫外伸進來畫下一鏡 | 創作、開始 |
| 塗鴉本格子 | 方格本或橫線本做底 | 學習、記錄 |

規則：
- 每支挑 2–3 個，至少一個不在下面「最俗的版本」裡。
- 訊號從主題裡選，不按順序全上。

## 這個風格最俗的版本
- 畫面：米黃紙上番茄紅和天藍的蠟筆小人，一個太陽在角落笑，結尾書合上，封面是 logo。
- 聲音：木琴、尤克里裡、口哨，輕快的大調。
- brief 的 style 一欄寫明這支片子翻掉了哪幾條，或者為什麼刻意保留（比如使用者要的就是經典版）。保留時，把力氣花在構圖、鏡頭、節奏或一個意外的記憶點上。

## 適配
- 用途：故事向的宣傳短片、講解短片、節日問候、品牌情緒片。
- 內容：教育、兒童、生活方式、公益、個人故事、溫暖的品牌。

## 技術路線
p5.js（例項模式 + `noLoop()`，`render(t)` 裡設定時間後 `redraw()`）+ p5.brush（彩鉛、蠟筆、水彩筆刷），或者用 Canvas 自己寫筆觸（沿路徑畫很多半透明、帶抖動的小線段）。**筆刷很慢**：先測單幀耗時，決定時長和幀率（24fps 輸出，畫面 12fps 步進，可以每兩幀複用同一張）。紙紋是預先生成的一張噪聲紋理，每幀疊在最上層。

## 材質與渲染
- 筆觸的隨機種子用 `floor(t * 12)`：每秒變 12 次，形成手繪的「沸騰」感。
- 輪廓線：深色彩鉛，略微不閉合；填色：蠟筆或水彩，留出紙色的邊。
- 水彩：多層半透明的不規則形狀疊加，邊緣更深（顏料堆積）。
- 紙：暖白，有纖維紋理和輕微的不均勻。

## 配色
下面的色值是示例，看思路，不要原樣照抄。
- 紙 `#F7F1E3` / 線 `#3B2F2A` / 番茄 `#E8664A` / 天藍 `#6FA8DC` / 草綠 `#8CBF6B` / 鵝黃 `#F4C95D`
- 夜晚：紙 `#E9E4F2` / 深藍 `#2E3A66` / 月黃 `#F2D77B` / 粉 `#E89BB5`
- 規則：顏料感的有限調色盤，留出紙色，不用純黑。
- 推導：顏料感的有限調色盤，留出紙色，不用純黑。紙色和顏料從主題來：夜晚、秋天、單色鉛筆、只有兩支蠟筆都可以；米黃紙加番茄紅天藍是最常見的那組。

## 字型
手寫體或手作感的字型：Patrick Hand、Gaegu、Caveat；中文用站酷快樂體、霞鶩文楷（OFL）。字也可以用筆刷一筆一筆「寫」出來。

## 運動
- 12fps 步進，動作誇張但慢；角色用簡單的 2.5D 骨骼（軀幹、頭、四肢），關鍵姿勢之間緩動。
- 轉場常用「重畫」：新畫面一筆一筆畫出來，舊畫面被擦掉。

## 畫面怎麼活
- 線稿「沸騰」：線條按 8–12fps 換種子輕輕抖。只給線稿和小區域，整屏的色塊每隔幾幀重畫一遍，讀起來就是閃爍。
- 雲、草、樹葉 12fps 步進地晃；角色眨眼、呼吸。

## 鏡頭語法
| 鏡頭運動 | 表達什麼 | 適合哪類內容 |
|---|---|---|
| 緩慢推近 | 進入故事 | 開場、情緒點 |
| 分層視差橫移（紙片前後景） | 深度、旅程 | 場景移動 |
| 翻頁 | 下一章 | 段落切換 |

## 聲音調色盤
原聲感：撥絃（`pluck`）、鋼片琴感的 `bell`、軟 `keys`；紙張和鉛筆的擬音（帶通噪聲）。第 2 檔的鋼琴取樣（Salamander）很適合這種溫暖的風格。

律動與和聲（舉例，不止這些）：3/4 或 6/8 的搖盪、輕 swing；大調、Lydian、加六度 / 加九度和絃。音畫同形（每畫一筆一個音）很合適；`mallet`（glock、marimba）、`pluck`、柔和拉桿的 `organ` 都可以當主奏。小房間，不側鏈。

## 原生手法
- 一筆畫出下一鏡：適合「想法變成現實」。
- 水彩暈開鋪滿畫面成為下一鏡的底色：適合轉場。
- 擦掉重畫：適合「改變」「修正」。

## 變化空間
- 結構：一個小角色的一次冒險；一年四季在同一張紙上更替；一封信從寫下到送達。
- 開場：一張白紙，第一筆落下；一支筆從畫外伸進來。
- 結尾：畫面縮小成書裡的一頁，書合上，封面是 logo（經典結尾，也可以停在最後一筆、紙被拿走露出桌面）。

## 坑
- 每幀都重新隨機筆觸（而不是按 12fps 固定種子），畫面會劇烈閃爍。
- 筆刷太慢導致渲染時間爆炸：先測，再決定。
- 畫寫實人物或五官：保持極簡和風格化。
