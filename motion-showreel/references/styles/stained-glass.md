# 彩色玻璃鑲嵌（stained-glass）

> 彩色玻璃被深色金屬條分隔，背後的光穿過色片，把圖案投到周圍空間。
> 參照（只學語法）：鉛條鑲嵌彩窗、幾何玻璃屏風、彩色玻璃上的燒繪工藝。不照搬具體宗教影像、建築彩窗和現代藝術作品。

## 本質 / 不是什麼

- 本質：**分片的玻璃過濾光，金屬骨架組織影像**。玻璃片有邊界、厚度和不同透光程度；亮度來自背光，金屬條依然暗實，投出的彩光與片的位置相互對應。
- 不是：`glass-material` 的透明產品陳列，也不是把平面插畫切成多邊形。前者重摺射與反射，這裡重色片、接縫和透光形成的圖案。

## 辨識訊號：每支片子挑 2–3 個

| 訊號 | 長什麼樣 | 適合的主題 |
|---|---|---|
| 鉛條骨架 | 深色條帶包住每塊玻璃，交匯處有節點 | 連線、結構、工藝 |
| 透光色片 | 相鄰色片亮度與透光程度不同 | 多樣性、情緒、品牌 |
| 波紋玻璃 | 片內有固定的細波紋，透光略不均勻 | 手工、自然、質感 |
| 彩光落地 | 窗面圖案化成拉長或柔化的地面色斑 | 空間、時間、氛圍 |
| 幾何花窗 | 圓、瓣或重複單元圍繞結構排列 | 匯聚、循環、儀式 |
| 不規則拼片 | 形狀順著人物、植物或抽象輪廓分塊 | 敘事、生命、變化 |
| 燒繪暗線 | 玻璃表面有少量深色細節與遮光筆觸 | 表情、區域性紋理、文化 |
| 側光金屬邊 | 窄小高光顯出接縫的厚度 | 工藝、區域性特寫 |
| 單片補位 | 缺口中的色片歸位，圖案與投影同時補全 | 修復、協作、完成 |
| 背光換時 | 光源角度緩變，色片亮暗和落地光一起變化 | 時間、季節、情緒 |

規則：

- 每支挑 2–3 個，至少一個不在下面「最俗的版本」裡；訊號從主題裡選。
- 分片沿內容結構設計，主輪廓可以由多片組成。圓形花窗、宗教場景和寶石色都只是選擇。

## 這個風格最俗的版本

- 畫面：教堂玫瑰窗居中，彩虹色鋪滿每片玻璃，金光從後射出，碎片旋轉拼成 Logo。
- 聲音：管風琴加合唱，拼一片就響一聲玻璃鈴，最後長混響收尾。
- brief 的 style 一欄寫明翻掉了哪幾條，或者為什麼保留經典版。可用橫向屏風、少色植物圖案或區域性修補，讓主題決定空間。

## 適配

- 用途：文化與工藝宣傳、品牌情緒片、Logo 演繹、片頭、空間氛圍循環。
- 內容：光、時間、修復、共同組成整體，也適合現代幾何品牌。
- 不適合：密集圖表、快速介面演示，或需要色彩精確不受照明影響的產品展示。

## 技術路線

- **平面彩窗**：SVG、Canvas 可處理分片、接縫和透光層；Paper.js 可輔助裁切與共享邊界，避免相鄰片留出不受控的縫。
- **空間彩窗**：需要側視厚度、背光和地面時，可探索 Three.js 的透射材質、燈光與投影。真實彩色透射和焦散成本較高，可按鏡頭需要選擇自定義著色或經過校準的投影近似。
- **光與紋理**：PixiJS 或 WebGL 適合片內波紋、區域性亮度和遮罩。投到地面的圖案應由同一組色片與光向推導，不能另畫一團無關的彩色光。
- 固定玻璃紋理種子，任意時刻獨立恢復光源與片的位置。`--dpr` 先保證接縫平順；`--subframes` 用於緩慢光影和移動片，`--grain` 保持輕或關閉。

以上是實現方向，不要求物理級焦散，也不指定材質引數和渲染引擎組合。

## 材質與渲染

- 工藝依據：玻璃按圖案切割，邊緣嵌進金屬槽，接點焊接，形成能透光的面。分片應有可拼合的邊界，金屬條有連續的支撐關係。
- 玻璃片是剛體。片內波紋跟著片走，形狀不會像液體呼吸；變形轉場應明確借用切割或重組的圖形手法。
- 背光越強，透光片越亮，但燒繪暗線與金屬仍壓住光。深色玻璃不會在所有光向下都自動變成霓虹。
- 邊緣可有輕微厚度與反光，金屬接縫比玻璃更實、更暗；不能把每片做成鼓起的寶石。
- 彩光隨光向改變位置、拉伸和柔軟程度，被金屬條擋住的地方留下較暗分隔。主體同樣由色片和接縫組成，不能另貼一張平滑 Logo。

## 配色

下面的色值是示例，看思路，不要原樣照抄。

- 深藍與琥珀：環境 `#18262D` / 玻璃 `#326E9C`、`#D99A43` / 鉛條 `#252629`。
- 植物屏風：環境 `#E9E1CC` / 玻璃 `#6B8A69`、`#B9634F` / 鉛條 `#393B35`。
- 煙粉與冷白：環境 `#262C37` / 玻璃 `#BC8796`、`#B8D3DC` / 鉛條 `#25252D`。
- 推導：從主題取兩三組玻璃色，拉開透光後的明度，而非給每片換一種色相。底色承擔室內環境，金屬保留深度；強調片在數量和麵積上都要剋制。

## 字型

英文可選 Cormorant Garamond、Marcellus，現代幾何主題可用 Jost；中文用思源宋體或思源黑體，自託管 OFL 字型。標題放在相對完整的暗區或淺區，輔助字不跨越多塊明暗差大的玻璃。複雜字形不強行切成鑲嵌片。

## 運動

- 玻璃片移動時保持硬質重量，圍繞明確邊緣翻轉或沿槽位歸位，輕微減速後停穩；不做軟彈簧擠壓。
- 以光變化為主的鏡頭讓窗體保持穩定，亮度與投影共同緩慢移動。避免玻璃自己發光、地面卻沒有響應。
- 進場可由遮光撤去、缺片補齊或視角轉正完成；退場可轉向投影、閉合光源或移到相鄰窗格。

## 畫面怎麼活

- 固定窗體前，彩光在地面緩慢挪動，移動量只夠讓觀眾感到光向變化。
- 片內紋理不遊動，允許環境中的柔暗影從背後經過，引起區域性亮度變化。
- 工藝特寫裡，一段金屬接縫隨觀察角度出現窄反光；閱讀落版時以靜為主。

## 鏡頭語法

| 鏡頭運動 | 表達什麼 | 適合哪類內容 |
|---|---|---|
| 正面固定，背光變化 | 圖案與時間 | 品牌、氛圍、循環 |
| 小角度側移到正面 | 厚度與透光 | 工藝、材質 |
| 從窗面移到落地彩光 | 對空間的影響 | 建築、情緒、時間 |
| 從接縫區域性拉遠 | 多片如何成為整體 | 協作、修復、Logo |

## 聲音調色盤

第 1 檔可用柔和風琴鋪底、少量鋼片或卡林巴音、低密度敲擊。需要真實玻璃觸碰、室內混響或絃樂時，用第 2 檔 Tone.js 配合授權取樣。玻璃接合只給輕而短的硬質聲，別把每次運動都做成破碎聲；有口播時收短混響尾音。

律動與和聲（舉例，不止這些）：緩慢的持續和聲、溫柔的分解音型，或清晰輕巧的幾何節奏。神聖感適合部分主題，現代空間也可乾淨、明亮而世俗。

## 原生手法

- 色片沿接縫拼合，完整圖案透出光：適合共同組成整體（經典）。
- 缺片歸位，窗面與地面投影同時補全：適合修復、協作和完成。
- 鏡頭落到彩光上，讓投影的輪廓成為下一段圖形：適合空間和主題之間轉場。
- 保留金屬骨架，只替換其中一組玻璃色：適合季節、版本和狀態對比。
- 背光掠過燒繪細節，先前藏在暗處的線條出現：適合發現、文化和區域性揭示。

## 變化空間

- 結構：追隨一束光觀察同一面窗；圍繞缺片講修復；按窗格展開幾個相關主題。
- 開場：先看地面彩光；近看一處金屬接點；完整彩窗在暗處逐漸透亮。
- 結尾：停在可讀的整面圖案；只留一塊有意義的色片發亮；投影延伸出畫框接下一章。

## 坑

- 玻璃像軟糖：減少鼓包和彈性，先保持平面與剛性邊界。
- 線條只是覆蓋在多邊形上：建立共享接縫與節點，避免雙邊線和斷口。
- 一直髮光卻沒有背光方向：確定光源位置，讓窗與環境共同響應。
- 投影和色片不對應：共用圖案與運動來源，檢查缺片、遮擋和光向變化。
- 彩虹色和高飽和鋪滿全屏：限制色組，保留深片與安靜區域。
- 宗教母題與內容無關：從主題設計分片形狀，不把教堂當必選背景。
- 小字跨過高反差接縫：另留題簽區，或在正文出現時降低背後細節。
- 金屬條在尖角處偏離色片：不能把直線切割邊統一平滑成曲線；玻璃輪廓、接縫和投影遮光邊應沿同一邊界。
- 彩光像貼在地上的硬質插畫：保留色片對應關係，再按投射距離控制軟邊與亮度；先抽看背光開啟前後的幀，確認光源變化確實傳到地面。
