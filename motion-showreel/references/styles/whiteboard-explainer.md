# 白板手繪解說（whiteboard-explainer）

> 圖在觀眾眼前畫出來，箭頭與標註把一句解釋變成看得懂的關係。
> 參照（只學語法）：RSA Animate 的全域白板、MinutePhysics 的分段手繪講解。

## 本質 / 不是什麼

- 本質：繪製順序就是解釋順序。筆先畫什麼、在哪裡停、何時連線舊圖，都應該幫助觀眾理解內容。
- 與一筆線描的區別：允許抬筆和多個獨立圖形，重點在解釋關係；與黑板外觀的區別：光有紙紋和手寫字型還不夠，必須讓關係隨繪製逐步成立。

## 辨識訊號：每支片子挑 2–3 個

| 訊號 | 長什麼樣 | 適合的主題 |
|---|---|---|
| 跟得上的筆尖 | 筆尖停在當前筆跡末端，轉場時抬起 | 工序、概念介紹 |
| 分筆畫圖 | 輪廓、細節、標註依解釋順序出現 | 原理、流程 |
| 因果箭頭 | 箭桿先到物件，箭頭最後確定方向 | 因果、決策 |
| 一張關係地圖 | 前面的圖留在板上，最終能看出全域 | 系統、知識網路 |
| 區域性圈注 | 圈出已存在的細節，再新增解釋 | 糾錯、重點 |
| 擦改痕跡 | 只擦掉需要修訂的地方，保留上下文 | 迭代、方案對比 |
| 少量語義色 | 一種色持續指代同一角色或狀態 | 分類、責任關係 |
| 畫外空間 | 鏡頭跟隨講解移到板上另一處 | 長流程、發現 |
| 手繪比喻 | 簡單物體承擔一個明確的概念 | 面向新手的解釋 |
| 總覽停留 | 拉遠後給觀眾時間複述關係 | 總結、回顧 |

規則：每支挑 2–3 個，至少一個不在俗套裡。圖形服務主題；一隻手並不能自動讓內容變成白板解說。

## 這個風格最俗的版本

- 畫面：白底、庫存手掌、燈泡和齒輪，所有字由同一個橫掃遮罩揭開；畫完就清屏。
- 聲音：輕快尤克里裡一直循環，筆聲從頭響到尾。
- brief 寫明保留哪些經典訊號、改變哪些預設做法。可以從已有圖上的矛盾開始，也可以邊回顧邊修訂。

## 適配

- 用途：原理講解、操作說明、方案介紹、課程片段和過程回顧。
- 內容：需要建立關係或解釋變化，能夠刪成少量圖形與短標註的主題。
- 密集逐字字幕、精確產品截圖和純材質宣傳應選擇其他主風格。口播長片須按真實音訊規劃，而非按固定畫圖速度湊時長。

## 技術路線

- SVG 或 Canvas 組織有明確順序的獨立路徑。SVG 的路徑長度介面、Paper.js 的曲線工具可輔助測長；筆跡與筆尖必須查詢同一份弧長進度。
- Rough.js 可探索穩定的手繪邊緣，但其雙線效果需要控制；不能每幀重新隨機生成一遍。
- 有真實書寫需求時，使用可核對的字形筆畫資料或手工整理的中心線。字型輪廓、橫掃遮罩、鋸齒遮罩均不能當成真實筆順。
- 大白板在世界座標中完整排好，鏡頭只改變觀察位置。分紙頁則明確切頁，不混成空間跳變。
- 通常 `--subframes 1–2`；過多采樣會把快速筆尖抹成灰影。背景紋理固定，通常不用額外 `--grain`。

## 材質與渲染

- 工藝依據：記號筆接觸白板、沿路徑移動、抬起後換位置。依次處理筆跡、筆身、接觸陰影和抬筆動作。
- 線寬隨壓力緩慢變化，已經畫出的線保持不動。回描只用於強調，不給每一根線都套雙描邊。
- 記號筆的端點飽滿，轉角略圓；鉛筆變體可以更細、更灰，整片的主體和箭頭採用同一工具。
- 白板保留輕微灰暖色，字與線要有充足對比。紙面變體可加固定紙紋，避免用重汙漬削弱閱讀。
- 手或筆應從真實的連線位置出發，不能突然換手；閒置時抬起退場，不懸在結論上方擋字。

## 配色

示例只看思路，不照抄。

- 清爽白板：底 `#FAFAF5` / 墨 `#26343A` / 重點 `#D66B42`。
- 冷白教學：底 `#F4F8F7` / 墨 `#203E4A` / 關係色 `#2C807E`。
- 紙上筆記：底 `#F1E9D8` / 墨 `#343435` / 圈注 `#B64844`。

從主題選一兩種語義色，先固定含義再分配圖形；不要按鏡頭更換含義。大片填色應給輪廓和箭頭留出空間。

## 字型

英文短標註可用自託管 OFL 的 Caveat、Patrick Hand；中文可用有清楚授權的手寫字型，或思源黑體作為排好的旁註。後者整詞出現，不偽裝成筆寫。字形必須正常；圖比正文多，最終總覽也要能讀到主要結論。

## 運動

- 繪製速度按路徑長度和理解難度安排；新概念的識別部位稍慢，重複細節更快。
- 每個筆畫結束後留出抬筆和轉移時間。箭頭的繪製方向與語義方向一致。
- 講解中的停留用於閱讀、比較和回想。鏡頭在畫筆工作時少動，移動後再畫下一組，減少雙重追蹤負擔。
- 擦除要留下明確的區域性變化依據；不要在同一鏡頭憑空替換整幅圖。

## 畫面怎麼活

- 以靜為主：已畫內容是觀眾的記憶支點。
- 講到某處時，可補一根下劃線或一個小圈；強調結束後也靜止。
- 只有內容需要時，讓圖中的活動物件沿已經畫好的關係移動。不能用全板線條抖動冒充手繪感。

## 鏡頭語法

| 鏡頭運動 | 表達什麼 | 適合哪類內容 |
|---|---|---|
| 固定近景畫一組 | 集中理解一個物件 | 原理、定義 |
| 短平移到鄰近圖 | 從原因走到結果 | 流程、因果 |
| 沿連線線回訪 | 新證據改變舊理解 | 反饋、修訂 |
| 拉遠後停住 | 看見完整關係 | 系統、總結 |
| 明確換紙頁 | 開始新的論點 | 章節式講解 |

## 聲音調色盤

第 1 檔可用輕木音、稀疏撥絃、短促的記號筆摩擦；擬音只在接觸時出現，停筆必須停止。真實筆聲可用第 2 檔配授權取樣。人聲是解說版的主角，配樂降低旋律密度，筆聲避開關鍵詞。

律動可選輕切分、一問一答或自由分句；不必用持續四拍推進。有口播時，筆跡進度、鏡頭與聲音事件按真實語音時間安排，並通過帶聲預覽核對。

## 原生手法

- 一筆畫到舊圖，把前後概念連成因果鏈：適合過程講解（經典）。
- 擦掉區域性假設，其餘關係保留，讓新結果自然成立：適合糾錯。
- 先畫區域性，拉遠後看見它在更大關係中的位置：適合系統認知。
- 用第二種顏色回到舊圖，只補上缺少的連線：適合反饋和協作。

## 變化空間

- 結構：從問題逐步搭圖；從全圖定位誤解；對照兩種方案並修訂其中一處。
- 開場：先畫關鍵矛盾；圈出已畫圖裡的異常；從一個未完成的連接出發。
- 結尾：保留可複述的總覽；回到開頭補上答案；留下與後續章節相連的空位。

## 坑

- 筆尖和筆跡各自緩動，出現“畫在前面、筆追在後面”：兩者查詢同一條路徑和同一個進度。
- 筆尖在長距離換筆處瞬移：明確劃分接觸、抬筆、移動，不能把轉移也畫成線。
- 漢字由掃光出現卻標為手寫：改用真實筆畫資料，或明確作為排版旁註。
- 全域圖沒有提前排好：先驗證總覽，再決定區域性鏡頭；避免末尾拉遠後主文字太小。
- 只畫圖示，沒有發生關係變化：把箭頭、比較、修訂納入敘事，而非最後一次性補齊。
- 鏡頭和筆同時快跑：分配注意力，關鍵繪製期間固定鏡頭。
- 一個 SVG 路徑包含多個移動命令，取樣後卻連成一條折線：按獨立子路徑分筆；每個移動命令都要重新判斷是否接觸紙面。
- 快速抬筆被多子幀取樣合成兩隻半透明的手：先檢查轉移時間，再降低子幀數；筆跡邊緣與手部拖影應分別取捨。
- 用整段畫圖時間播放筆聲：從實際接觸區間生成聲音事件，短暫停筆與換位置時也要留空。
