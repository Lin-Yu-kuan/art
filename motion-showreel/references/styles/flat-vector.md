# 扁平插畫（flat-vector）

> 用無描邊的色塊畫出一個可以無限縮放的世界：小人、機器、星球都是簡單的幾何，鏡頭在尺度之間穿行，把複雜的事講成一個故事。
> 參照（只學語法）：扁平風格的科普動畫頻道、當代扁平商業插畫、Material 時代的插畫系統。不照搬具體頻道的角色、配色體系和畫面。

## 本質 / 不是什麼
- 本質：**把一個概念畫成一個能走進去的小世界**。形狀簡單到小孩都能畫，但光影、層次、比例是精心設計的；資訊靠「縮放」「拆開」「變形」講清楚，畫面一直在輕輕動。
- 不是：圖示堆砌的 PPT；也不是等距視角的工程架構圖（那是 `isometric-infographic`）。

## 辨識訊號：每支片子挑 2–3 個
| 訊號 | 長什麼樣 | 適合的主題 |
|---|---|---|
| 無描邊色塊 | 形狀只靠色塊分開，沒有黑色輪廓線 | 一切 |
| 同色相陰影 | 陰影是本色深一檔，不是灰色 | 立體感、溫度 |
| 豆子小人 | 圓頭、無五官或兩個點、肢體是圓角條 | 使用者、人群、角色 |
| 尺度穿行 | 鏡頭從細胞推到城市、從星球推到人 | 規模、原理 |
| 剖面圖 | 一個東西切開，看到裡面的層 | 內部機制 |
| 發光的點 | 暗背景裡少量發光的小東西 | 能量、資料、夜景 |
| 層層視差 | 前中後景按不同速度移動 | 空間、旅程 |
| 圓角幾何機器 | 齒輪、管道、按鈕組成的可愛機器 | 流程、系統 |
| 弧線運動路徑 | 物體沿圓弧軌跡飛行，不走直線 | 傳遞、流動 |
| 一個顏色一個概念 | 每個概念固定一個顏色，全片不變 | 解釋、對比 |
| 紙質顆粒 | 平塗上疊一層極淡的顆粒 | 溫暖、手作感 |

規則：
- 每支挑 2–3 個，至少一個不在下面「最俗的版本」裡。
- 訊號從主題裡選，不按順序全上。
- 顏色就是語義：一個顏色代表一個概念，全片不換；超過 4 種語義色觀眾就記不住了。

## 這個風格最俗的版本
- 畫面：深藍紫的太空背景、發光的星球和小行星、豆子小人在地球上揮手、鏡頭從宇宙推到地球。
- 聲音：鋼片琴加絃樂鋪底，溫柔的科普腔。
- brief 的 style 一欄寫明這支片子翻掉了哪幾條，或者為什麼刻意保留（比如使用者要的就是經典版）。保留時，把力氣花在構圖、鏡頭、節奏或一個意外的記憶點上。

## 適配
- 用途：講原理的產品宣傳、功能講解、品牌故事、資料背後的故事、Logo 演繹。
- 內容：科技原理、健康、金融概念、環保、教育、「它是怎麼工作的」。
- 不適合：需要展示真實產品介面的（用 `minimal-ui`，介面用真實截圖）；需要可信資料圖表的（用 `data-motion`）。

## 技術路線
Canvas 2D 或 SVG。整個場景建成一個比畫面大得多的世界座標系，鏡頭是視口（中心、縮放、旋轉），縮放用對數插值（每幀放大同樣的倍數），推近時所有形狀按向量重畫，放大 50 倍也不糊。形狀用圓角矩形、圓、貝塞爾曲線；陰影是同一形狀偏移後用深一檔的顏色 clip 在本體裡。顆粒用 `--grain 2–3`。

## 材質與渲染
- 形狀：圓角為主，避免銳角；同類物體用同一套幾何零件拼。
- 光影：一個固定的光源方向；受光面淺一檔、背光面深一檔，都是同色相，不用灰。
- 發光：只給少數「能量」類元素，用 2–3 層越來越大越來越淡的同色圓。
- 層次：遠景飽和度和對比低，近景高；最前景可以有一層虛化的大形狀做框。
- 小人：豆子形身體、圓頭，沒有嘴或只有一條弧線；靠姿勢和動作表達情緒，不靠表情。

## 配色
下面的色值是示例，看思路，不要原樣照抄。
- 暗夜：底 `#14213D` / 中景 `#2A3B6B` / 暖光 `#FCA311` / 青 `#4CC9F0` / 皮膚 `#F4A261`
- 明亮：底 `#FDF6EC` / 綠 `#2A9D8F` / 黃 `#E9C46A` / 珊瑚 `#E76F51` / 深藍 `#264653`
- 單色系：一個色相的 5 個明度 + 一個對比色只給主角
- 推導：先定背景是暗還是亮，再給每個概念分配一個顏色（從品牌色出發，在 OKLab 裡推相鄰色）；陰影一律是本色深一檔。深藍紫太空加暖黃髮光是最常見的那組。

## 字型
圓潤的無襯線：Nunito、Poppins、Baloo 2、Quicksand（OFL）；中文用思源黑體 Bold 或站酷快樂體。標籤字小而少，靠畫面講，字只做補充。

## 運動
- 主緩動是對稱的 ease-in-out（`bezier(0.75, 0, 0.25, 1)` 一類），鏡頭和大物體都用它。
- 物體沿弧線運動；出現時從 0 彈出（彈簧 `{2.6, 0.6}`），消失時縮小得更快。
- 小人的動作 pose-to-pose：關鍵姿勢之間快速過渡，然後停住。
- 畫面從不完全靜止：總有東西在緩慢漂浮、旋轉或閃爍。

## 畫面怎麼活
- 遠處的小東西緩慢漂浮（週期 3–6 秒）；發光點輕輕呼吸；小人眨眼或者晃一下。
- 機器的齒輪、管道里的小球一直在慢慢轉、慢慢流。
- 漂浮的幅度比主動作小一檔，不搶焦點。

## 鏡頭語法
| 鏡頭運動 | 表達什麼 | 適合哪類內容 |
|---|---|---|
| 對數推近穿過尺度 | 從宏觀到微觀 | 原理、規模 |
| 拉遠揭示全貌 | 原來是更大東西的一部分 | 轉折、結尾 |
| 橫移跟著一個小人走 | 旅程 | 流程、故事 |
| 剖開一個物體，鏡頭鑽進去 | 內部 | 機制 |
| 推進一個圓形物體，裡面就是下一鏡 | 進入 | 轉場 |

## 聲音調色盤
溫柔的 `mallet({ material: 'glock' })`、`pluck`、`pad` 鋪底；物體出現配 `pop`，移動配輕 `whoosh`。第 1 檔即可，需要更像紀錄片的空間感時用第 2 檔加鋼琴取樣。

律動與和聲（舉例，不止這些）：不用鼓或只用很輕的 shaker，靠鋪底和旋律推進；也可以用輕快的撥絃配 4/4 小鼓做更活潑的版本；大調、Lydian（好奇、驚奇）、Dorian（略帶憂思）。累加曲線（每多一個概念多一個聲部）很適合。

## 原生手法
- 推進一個圓形物體（一個細胞、一個按鈕、一個星球），裡面是下一個場景：適合層層深入。
- 一個物體切開，露出內部的齒輪在轉：適合講原理。
- 同一個形狀變形成下一個概念（圓變成硬幣變成地球）：適合比喻和轉場。
- 無數小人匯聚成一個形狀或數字：適合「使用者」「人群」。
- 從宇宙推到地球：經典，人人都會想到。

## 變化空間
- 結構：一個概念從最小的單位講到最大；一次「如果……會怎樣」的思想實驗；一個小人走完一個流程；三個比喻依次變形。
- 開場：一個點放大成一個世界；一個小人抬頭看見一個問題。
- 結尾：拉遠，所有場景原來都在一個 logo 的形狀裡；小人把最後一塊拼上。

## 坑
- 顏色太多、語義亂：一個概念一個顏色，全片不換。
- 加了黑色描邊，就成了另一種風格（漫畫或卡通）。
- 畫面一直在動但沒有焦點：同一時刻只有一個主運動。
- 線性縮放：推近時前慢後猛，最後一幀會跳，用對數插值。
- 照搬知名科普頻道的配色和角色：只學語法。
