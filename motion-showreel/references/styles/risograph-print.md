# 孔版印刷（risograph-print）

> Risograph 孔版印刷的質感：有限的專色、套色錯位、半調網點、顆粒和紙紋，像獨立出版物在動。
> 參照（只學語法）：獨立雜誌和 zine 的孔版印刷、日本和歐洲的 riso 工作室作品、波普半調網點。不照搬具體作品。

## 本質 / 不是什麼
- 本質：**2–3 個專色疊印**（重疊處混出第三色），**每個色版有輕微錯位**，暗部是半調網點，邊緣有顆粒和不均勻的油墨。
- 不是：乾淨的向量扁平插畫；也不是濾鏡一鍵加噪點。

## 辨識訊號：每支片子挑 2–3 個
| 訊號 | 長什麼樣 | 適合的主題 |
|---|---|---|
| 疊印混色 | 兩個專色重疊的地方混出第三種顏色 | 組合、合作、混合 |
| 套色錯位 | 色版之間錯開 1–3px，邊上露出另一種顏色 | 手作、獨立 |
| 半調網點 | 暗部變成旋轉網格上的圓點 | 印刷感、復古 |
| 油墨不均和顆粒 | 色塊裡濃淡不勻，邊緣毛糙 | 質感、溫度 |
| 熒光專色 | 熒光粉、熒光橙這類螢幕上也很跳的油墨色 | 潮流、活動 |
| 雙色調照片 | 一張照片只用兩個專色印出來 | 人物、產品 |
| 手繪線稿插圖 | 粗細不勻的墨線，像鋼筆畫 | 故事、出版 |
| zine 版式 | 訂書釘、頁碼、裁切線、手寫目錄 | 出版、獨立品牌 |
| 印刷標記 | 套準十字、色標條、出血線留在畫面裡 | 製作過程、設計 |
| 漏印和墨點 | 偶爾一塊沒印上、一個多餘的墨點 | 不完美、真實 |

規則：
- 每支挑 2–3 個，至少一個不在下面「最俗的版本」裡。
- 訊號從主題裡選，不按順序全上。
- 疊印、錯位、網點是這種媒介的物理約束，作為材質始終都在；區別在於突出哪個。挑出來的 2–3 個訊號放大做主角，其餘的壓到很輕，只當底色。

## 這個風格最俗的版本
- 畫面：熒光粉加藍兩色、滿屏大網點、錯位一直在抖、版面是一張居中的海報。
- 聲音：lo-fi hip-hop 的鼓加黑膠底噪。
- brief 的 style 一欄寫明這支片子翻掉了哪幾條，或者為什麼刻意保留（比如使用者要的就是經典版）。保留時，把力氣花在構圖、鏡頭、節奏或一個意外的記憶點上。

## 適配
- 用途：宣傳短片、Logo 演繹、排版卡點、活動海報動起來。
- 內容：文化、創意、獨立品牌、出版、音樂、活動。

## 技術路線
Canvas 畫出每個色版（灰度遮罩）→ WebGL 後期合成：每個色版用對應的專色以 multiply 疊印，加錯位、半調和顆粒。也可以只用 Canvas（`multiply` 合成 + 預先生成的網點紋理），但 WebGL 更快。顆粒放在著色器裡按幀固定種子，或者用 `--grain`。

## 材質與渲染
- 色版：每個元素指定屬於哪個色版；色版之間做 1–3px 的錯位（可以隨時間輕微漂移，但要確定性）。
- 半調：在著色器裡按亮度畫旋轉網格上的圓點（不同色版用不同角度，比如 15° / 45° / 75°）。
- 油墨不均：用低頻噪聲調變每個色版的濃度；邊緣用高頻噪聲做毛邊。
- 紙：暖白底，加一層非常淡的纖維紋理。

## 配色
下面的色值是示例，看思路，不要原樣照抄。
- 熒光粉 `#FF48B0` + 藍 `#0078BF` + 紙 `#F6F1E7`（重疊處是紫）
- 黃 `#FFE800` + 青 `#00A95C`（Riso 綠）+ 紙 `#F4EFE4`
- 紅 `#FF665E` + 中藍 `#3255A4` + 黑 `#2B2B2B` + 紙 `#F7F3EA`
- 規則：只用專色和它們的疊印色，不加別的顏色；不用漸變，漸變一律變成網點。
- 推導：從真實的 Riso 油墨色裡選 2–3 個（熒光粉、藍、黃、Riso 綠、橙、紫、金屬金……），重疊色由 multiply 自然產生，不要另外加。熒光粉加藍是最常見的組合。

## 字型
有性格的怪誕體或寬襯線體：Space Grotesk、Syne、Bricolage Grotesque、Fraunces 以外的襯線體（如 Young Serif、DM Serif Display）。字也走色版，可以有錯位。

## 運動
- 適中的速度，彈簧 `{2.4, 0.75}`；元素像被「印」上來：先出一個色版，再出第二個色版（錯開 2–4 幀）。
- 可以用步進（12fps）增加印刷品的手作感，但鏡頭保持平滑。

## 畫面怎麼活
- 兩個色版之間的對版誤差隨時間輕輕漂移（0.5–2px，幾秒一個週期），這就是孔版機器的呼吸。
- 半調網點的點徑或網角緩慢變化；紙紋固定不動，紙本身不會動。

## 鏡頭語法
| 鏡頭運動 | 表達什麼 | 適合哪類內容 |
|---|---|---|
| 平移過一張長版面 | 翻閱 | 列表、時間線 |
| 推近到網點 | 質感、細節 | 記憶點、轉場 |
| 色版分離再合上 | 組成 | Logo、標題 |

## 聲音調色盤
lo-fi 鼓（kick decay 短一點、hat 加 `lowpass`）、溫暖的 keys、pluck；可以疊一層很輕的黑膠底噪（`ambience({ kind: 'vinyl' })`）。第 1 檔合成即可。

律動與和聲（舉例，不止這些）：lo-fi hip-hop 的 swing（`S.swing(n, 0.3, 0.25)`）、boom-bap；Dorian、m9 / maj7 這類柔和的七和絃；鼓 bus `crush: 10–12` + `lowpass`，music `wow: 0.3`。

## 原生手法
- 色版分離：一個畫面拆成兩三個專色層錯開，再合上變成下一個畫面。適合「組成」「拼合」。
- 推近到半調網點，網點變成下一鏡的粒子或圖案。適合轉場和記憶點。
- 套色錯位隨節拍跳一下。適合卡點。

## 變化空間
- 結構：一本 zine 翻頁；一張海報從單色印到三色；同一個圖形換三種專色組合。
- 開場：紙面上第一個色版印下來；推近網點然後拉遠露出全貌。
- 結尾：所有色版對齊、錯位歸零，變成一張乾淨的海報。

## 坑
- 錯位太大會像出錯；1–3px 就夠。
- 每幀都隨機變化的噪點會閃：所有噪聲都要固定種子，按 t 或按步進幀取值。
- 網點太細時會在影片編碼後出現摩爾紋：網點直徑 ≥ 6px（1080p），渲染後檢查。
