# 暗色釋出會（dark-keynote）

> 深色舞臺、一束聚光、巨大的數字和一句話、產品像英雄一樣登場。深色在這裡是設計出來的，不是 AI 的預設。
> 參照（只學語法）：科技公司釋出會的主視覺和影片、Apple 風格的產品敘事片。不照搬任何品牌的裝置外形、字型和配色模板。

## 本質 / 不是什麼
- 本質：**深色但有層次**（近黑的底 + 一個緩慢移動的柔光源，不是死黑）；一屏只說一件事；大數字、大短句；產品或介面在光裡慢慢轉出來；節奏是「靜 → 揭示 → 靜」。
- 不是：深色 + 居中大字 + 紫藍漸變 + 到處發光的 AI 預設風格。區別在於：光有方向、有來源；只有一個強調色；字有設計好的排版位置；揭示是有節奏的。

## 辨識訊號：每支片子挑 2–3 個
| 訊號 | 長什麼樣 | 適合的主題 |
|---|---|---|
| 移動的柔光源 | 近黑的底上一團緩慢移動的光，不是死黑 | 高階、情緒 |
| 巨大的數字 | 一個引數佔滿畫面，再縮回一句話裡 | 效能、成績 |
| 一屏一句話 | 大號短句居中或左對齊，前後都是暗場 | 口號、承諾 |
| 光掃出輪廓 | 一道光沿產品邊緣掃過，輪廓先於實體出現 | 產品首次亮相 |
| 產品英雄鏡頭 | 產品或介面在光裡慢慢轉出來 | 硬體、App |
| 玻璃卡片 | 半透明的磨砂卡片裝著截圖或引數 | 功能介紹 |
| 倒數和揭曉 | 3、2、1 之後畫面亮起 | 釋出、上線 |
| 引數列 | 一列對齊的規格數字逐行亮起 | 對比、規格 |
| 反射地面 | 產品下方一片微弱的倒影 | 硬體、高階 |
| 字從模糊裡浮出 | 標題從虛焦到清晰，伴隨很輕的放大 | 標題、章節 |

規則：
- 每支挑 2–3 個，至少一個不在下面「最俗的版本」裡。
- 訊號從主題裡選，不按順序全上。

## 這個風格最俗的版本
- 畫面：黑底 + 一道藍色光掃過 + 居中的巨大數字 + 產品慢慢旋轉 + 結尾 logo 在光裡定格。
- 聲音：低頻 boom、上升的 riser、鋼琴單音加大混響的鋪底。
- brief 的 style 一欄寫明這支片子翻掉了哪幾條，或者為什麼刻意保留（比如使用者要的就是經典版）。保留時，把力氣花在構圖、鏡頭、節奏或一個意外的記憶點上。

## 適配
- 用途：產品宣傳短片、資料爆點、Logo 落版、釋出倒計時。
- 內容：硬體、AI 產品、平台、重大更新。

## 技術路線
DOM / Canvas 排版 + 一層光：徑向漸變光斑隨時間緩慢移動；產品圖用使用者提供的真實圖片或截圖，也可以用 Three.js 做 3D 呈現（見 `glass-material.md`）。`--dpr 2` 保證細字乾淨；`--grain 2–3` 去掉深色背景的色帶。

## 材質與渲染
- 背景：`#050506`–`#0B0B0E`，疊一個大而軟的光斑（`radial-gradient`，亮度很低），隨鏡頭緩慢漂移。
- 文字的高光：一道斜向的光掃過大字（mask + 漸變，0.6–1 秒）。
- 裝置 / 截圖：輕微反光的邊框，下面一道很淡的倒影；只在關鍵時刻給一點邊緣光。
- 數字：超大字號，等寬數字，變化時用滾動或者逐位翻轉。

## 配色
下面的色值是示例，看思路，不要原樣照抄。
- 近黑 `#07070A` / 白 `#F5F5F7` / 灰 `#86868B` / 強調（一個：冰藍 `#5AC8FA` 或品牌色）
- 近黑 `#0A0A0A` / 暖白 `#F2EDE4` / 金 `#C9A96E`
- 規則：一屏最多一個強調色；漸變只能是「光」，不能是「裝飾色塊」。
- 推導：近黑的底（偏冷、偏暖、偏品牌色都行）+ 白或暖白的字 + 一個強調色。強調色從品牌或產品材質來（金屬色、產品配色），冰藍是最常見的那個。

## 字型
超細到中等字重的無襯線體，大字號、寬字距的小標題：Inter Tight（200–600）、Manrope、Space Grotesk；數字用 tabular。中文用思源黑體 Light / Medium。

## 運動
- 慢而精確：大標題用 `{1.6, 0.95}`，揭示用 `glide`（0.8–1.2 秒）；離場比進場快。
- 揭示的套路：先暗場 → 光掃出輪廓 → 主體完全亮起 → 文字跟上。
- 數字滾動用 `outExpo`，落定時一次很輕的縮放脈衝。

## 畫面怎麼活
- 主體表面一道高光緩慢掃過（一次 2–4 秒）；背景的光斑極慢地漂移；鏡頭持續很慢地推進，這本身就是活。
- 文字落定後不動，留給觀眾讀。

## 鏡頭語法
| 鏡頭運動 | 表達什麼 | 適合哪類內容 |
|---|---|---|
| 暗場中緩慢推近 | 期待 | 開場、揭示前 |
| 環繞主體 | 完整、精緻 | 產品亮相 |
| 正面 + 輕推 | 宣告 | 一個數字、一個名字 |
| 拉遠進入大面積負空間 | 留出給字的位置 | slogan、結尾 |

## 聲音調色盤
sub drone、柔和的 kick、FM 鐘聲 / 玻璃音色、寬鋪底、精確的 tick；揭示前留一小段完全的靜音。產品亮相時可以用第 2 檔（Tone.js 的卷積混響、鋼琴取樣）讓空間感更好。

律動與和聲（舉例，不止這些）：慢 half-time，或者只有心跳般的 sub；Lydian（產品亮相的「驚奇」）、四度疊置，或者全片一個和絃只靠密度變化。曲線常用抽空（滿編 → 只剩一個鐘聲），不一定要 drop。乾淨、寬，側鏈很輕或不用。

## 原生手法
- 光掃出輪廓：適合產品首次亮相。
- 一個數字佔滿畫面，再縮小成一句話裡的一個詞：適合資料。
- 截圖裡的一個元素「浮出」截圖變成大字：適合功能點。

## 變化空間
- 結構：三個數字講完一個產品；一個問題 → 一個答案；倒數 3、2、1 後揭曉。
- 開場：全黑中一道光；一個聲音先於畫面出現。
- 結尾：logo 在光裡定格；光慢慢熄滅，只剩名字。

## 坑
- 退化成 AI 預設風格：每屏都有漸變和發光、所有元素同時淡入。回到「光有來源、一個強調色、節奏揭示」三條規則。
- 背景太黑出現色帶：加輕微顆粒。
- 編造引數和數字：只用使用者給的。
