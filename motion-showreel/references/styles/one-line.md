# 一筆線描（one-line）

> 一條線在畫面裡延伸、轉彎、回看，物體和關係沿著它逐漸被看見。
> 參照（只學語法）：連續輪廓繪畫、極簡線描動畫、以路徑組織敘事的動態圖形。不照搬具體肖像、線稿和標誌。

## 本質 / 不是什麼

- 本質：**線的連續性承擔敘事**。一條路徑既勾出輪廓，也連線前後事物；哪裡繞行、哪裡交叉、哪裡留下空白，都在說明它們的關係。
- 不是：白板教學裡一隻手把許多獨立小圖依次畫出，也不是 `flat-vector` 只去掉填色。路徑必須有來處和去處，不能靠隨意淡入淡出來掩蓋斷線。

## 辨識訊號：每支片子挑 2–3 個

| 訊號 | 長什麼樣 | 適合的主題 |
|---|---|---|
| 連續輪廓 | 一條線繞過多個可辨認的形體，中途不跳點 | 旅程、關聯、品牌故事 |
| 回折共享邊 | 線從一個形體的邊緣折回，成為另一個形體 | 合作、相似與差異 |
| 負形留白 | 線只圍住部分邊界，空白補出主體 | 極簡、情緒、想像 |
| 遊走線頭 | 當前生長的端點清楚，其餘部分安靜 | 過程、引導、尋找 |
| 線團解開 | 繞行逐漸舒展，形成可讀的輪廓或路徑 | 整理、理解、解決問題 |
| 區域性回描 | 同一位置有少量有意重疊，表現強調 | 記憶、反覆、手工感 |
| 線變文字 | 物體的邊線延續成短字或字下的連線 | 命名、Logo、結論 |
| 一筆跨尺度 | 細節邊緣拉遠後成為更大輪廓的一段 | 微觀到宏觀、聯絡 |
| 空間折返 | 路徑走出畫框，稍後在另一處重新進入 | 多地點、時間跨度 |
| 單處色點 | 極少量實色留線上經過的關鍵位置 | 狀態、情感重心、品牌 |

規則：

- 每支挑 2–3 個，至少一個不在下面「最俗的版本」裡；訊號從主題裡選。
- 可有輔助文字或少量獨立線，但主路徑始終能被追蹤。交叉的多少由主題決定，不把「一筆」變成必須塞下所有細節的謎題。

## 這個風格最俗的版本

- 畫面：米白底黑線從左畫到右，依次勾出臉、心形和手，末尾繞成品牌名。
- 聲音：獨奏鋼琴加鉛筆沙沙聲，線每拐一次彎就響一個高音。
- brief 的 style 一欄寫明翻掉了哪幾條，或者為什麼保留經典版。可以從已有的完整路徑出發，講一段回溯、拆解或修復。

## 適配

- 用途：品牌故事、關係講解、Logo 演繹、概念片頭、輕量循環。
- 內容：連線、旅程、創作、人與物的關係，以及能用輪廓表達的過程。
- 不適合：需要精確展示介面、密集數字或複雜機械裝配的片子；一筆不能替代必要的結構資訊。

## 技術路線

- **路徑與顯現**：SVG 和 Canvas 都適合。可從手工整理的向量路徑起步，探索按弧長控制線頭位置與已顯現部分；不要把曲線引數均勻推進誤當成勻速書寫。
- **形狀轉換**：Paper.js 可輔助曲線拆分、求交與整理；需要輪廓插值時可考察 Flubber，但連續線的端點、交叉和繪製方向仍須單獨設計。
- **大畫幅與長路徑**：Canvas 或 PixiJS 可組織分段快取與遮罩。路徑延伸到畫外時，保留世界座標中的連線關係，鏡頭只改變觀察範圍。
- 任意時刻獨立還原路徑形態、線頭與鏡頭；手工擾動固定種子。`--dpr` 用於圓滑邊緣，`--subframes` 從輕，避免快速線頭拖出多條灰線；通常不需額外 `--grain`。

以上是實現方向，具體路徑規劃、插值與遮擋辦法由 Agent 按圖形選擇。

## 材質與渲染

- 工藝依據：筆尖不離開紙面，線寬和彎曲來自手腕的速度與壓力。先用乾淨線條驗證輪廓，再決定是否加入輕微壓力變化。
- 主線寬度以最終尺寸可讀為準，急轉彎處圓滑連線，不出現尖刺或一團過黑的接頭。
- 交叉點要讀得懂：可以按真實描畫留下重疊，也可以用很小的斷口說明上下關係；同一片子保持一致。
- 負形屬於構圖的一部分。輪廓之間留足間距，避免一條連線誤讀成嘴、眼睛或零件邊界。
- 如果使用紙面，紋理固定在紙上；線寬變化沿路徑穩定。主體和連線線用同一套筆觸，不讓人物突然變成精細插畫。

## 配色

下面的色值是示例，看思路，不要原樣照抄。

- 紙與墨：底 `#F5F0E6` / 線 `#252A2B` / 色點 `#C35F4A`。
- 夜色細線：底 `#202C36` / 線 `#E8E5D9` / 色點 `#CBAF69`。
- 淺藍與深綠：底 `#E9F0F2` / 線 `#244B47` / 色點 `#E08B55`。
- 推導：先保證主線與底色的明度差，再從主題裡取一處強調色。色塊只承擔定位和強調，不能把全部輪廓填滿，搶走路徑的作用。

## 字型

英文可用 DM Sans、Manrope，中文用思源黑體，均自託管 OFL 版本。標題保持短，輔助文字比圖形安靜，但不能細到接近線稿。只有適合的短字才沿主線書寫；長標題另行排版，避免為不斷筆而破壞字形。

## 運動

- 線頭沿路徑自然推進，長直段可快，識別形體的關鍵轉折略停。速度變化跟閱讀難度走，不按每個控制點機械停頓。
- 變形時保住端點和主要交叉關係，讓觀眾看見同一條線怎樣改成新形體；跨度過大時允許借畫外空間過渡。
- 進場可以從線頭、負形或整條線的區域性開始。退場可沿原路收回，也可讓線頭牽走整體，不必每次擦掉。

## 畫面怎麼活

- 輪廓成立後以靜為主，給觀眾補全形體的時間，避免全線持續蠕動。
- 情感主題可讓一個小線圈輕微收放，幅度只夠改變鬆緊，不把主體拉變形。
- 旅程主題可讓未完成的線頭緩慢試探一個方向；已畫部分不跟著無意義地抖動。

## 鏡頭語法

| 鏡頭運動 | 表達什麼 | 適合哪類內容 |
|---|---|---|
| 跟隨線頭平移 | 正在經歷的過程 | 旅程、創作、尋找 |
| 停住鏡頭，讓路徑經過 | 建立穩定的觀察點 | 關係、解釋、循環 |
| 拉遠露出整條路徑 | 區域性匯成整體 | 系統、品牌、結論 |
| 回到已畫過的交叉點 | 重新理解前文 | 回憶、修訂、因果 |

## 聲音調色盤

第 1 檔可用柔和撥絃、少量鋼片音和輕噪聲，線條形成一個可讀形體時再給聲音回應。需要真實弓弦、鋼琴或筆尖擬音時，用第 2 檔 Tone.js 配合授權取樣。書寫聲可按長短句出現，不能持續蓋住口播，也不要給每個轉角打點。

律動與和聲（舉例，不止這些）：稀疏的自由分句、輕快的撥絃切分，或一條持續音上緩慢改變和聲。路徑可以從容，也可以果斷，不預設成感傷鋼琴片。

## 原生手法

- 線頭不抬起，前一個物體延伸成下一個：適合旅程和主題關聯（經典）。
- 交叉處輕輕展開，原先的線團變成清楚的關係：適合解釋複雜問題。
- 鏡頭拉遠，讓多段區域性輪廓成為一個更大的形象：適合共同目標和尺度轉換。
- 沿主線回走，只改動一個轉折，後續形體隨之改變：適合選擇、修復和方案對比。
- 主線繞開一塊空白，最後靠負形顯出標題或符號：適合含蓄揭示和記憶點。

## 變化空間

- 結構：隨線前行；從完整圖形倒著找原因；圍繞同一交叉點展開幾個關係。
- 開場：線已經畫了一半；先看到被線包圍的空白；一條鬆弛的線突然被某處牽動。
- 結尾：停在未閉合但可識別的輪廓；拉遠看到整個連線；首尾接好形成自然循環。

## 坑

- 每個圖形各自淡入，連線線只是裝飾：先在靜態路徑上驗證是否真能連續走通。
- 用最短連線穿過主體：繞開語義關鍵部位，寧可多留空白。
- 變形中交叉關係亂跳：減少同時變化的區段，先保住識別點。
- 線頭速度忽快忽慢：檢查實際路徑長度，關鍵停頓另行安排。
- 過度追求一筆導致形體無法辨認：刪細節，或明確採用主線加輔助線的變體。
- 字和線一樣細、一樣密：用字號、字重和留白區分閱讀與觀看。
