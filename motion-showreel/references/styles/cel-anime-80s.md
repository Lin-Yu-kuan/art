# 80 年代賽璐璐動畫（cel-anime-80s）

> 手繪背景托住硬邊色塊的角色，少量關鍵姿態、區域性動作和攝影臺鏡頭共同完成表演。
> 參照（只學語法）：20 世紀 80 年代賽璐璐動畫的上色與合成、有限動畫、手繪背景和多層攝影。不照搬具體角色、機體、標誌性鏡頭或配樂。

## 本質 / 不是什麼

- 本質：**角色色層、背景畫和攝影運動各司其職**。角色用清楚輪廓與少數硬邊陰影表達體積，背景容納更細的色彩變化，表演依靠有分量的關鍵姿態。
- 不是：`comic-pop` 的分格和擬聲字，也不是給現代平滑動畫套顆粒與 VHS。舊式合成質感可以輕微存在，決定風格的仍是繪畫層次和動作取捨。

## 辨識訊號：每支片子挑 2–3 個

| 訊號 | 長什麼樣 | 適合的主題 |
|---|---|---|
| 硬邊陰影 | 角色以少數明確的亮暗色麵塑形 | 人物、機械、力量 |
| 手繪背景 | 環境有筆觸和色彩層次，細節比角色豐富 | 世界、情緒、地點 |
| 保持關鍵姿態 | 一個姿態停住，眼神或衣襬區域性變化 | 情緒、決心、對白 |
| 多層攝影 | 前景、中景、背景以不同速度移動 | 旅程、空間、揭示 |
| 極短衝擊畫 | 動作峰值出現高反差的簡化姿態 | 碰撞、轉折、爆點 |
| 塗抹與拖影畫 | 快動作中用變形輪廓連線關鍵姿態 | 速度、跳躍、轉身 |
| 攝影臺推拉 | 對較大的繪製畫面推近或平移 | 環境、觀察、情緒 |
| 機械高光切換 | 硬質面隨轉動換到新的亮暗色塊 | 裝置、載具、精密 |
| 光學輝光 | 少數亮源有柔邊擴散，暗部仍清楚 | 夜景、能量、氛圍 |
| 有限特效幀 | 煙、火或水由少量明確形狀輪換 | 環境、動作、餘波 |

規則：

- 每支挑 2–3 個，至少一個不在下面「最俗的版本」裡；訊號從主題裡選。
- 年代感不等於每個鏡頭都要機甲、速度線和膠片髒點。選定角色線條、色層和動作密度，跨鏡頭保持一致。

## 這個風格最俗的版本

- 畫面：紅色天空、巨大機體、風吹長髮，鏡頭推近眼睛，白閃後出現片名。
- 聲音：電吉他主旋律配密集鼓點，任何轉身都有誇張破風聲。
- brief 的 style 一欄寫明翻掉了哪幾條，或者為什麼保留經典版。日常空間、靜物、交通和輕喜劇也能用賽璐璐語言。

## 適配

- 用途：動畫式產品概念片、遊戲預告、故事片頭、角色宣傳、音樂向作品。
- 內容：明確動作、情緒轉折、空間氛圍，也適合把器物和機器當成主角。
- 不適合：寫實人物表演、複雜手部近景或低成本長時間連續全身動作。程式碼能力不足時簡化角色和動作，保住關鍵姿態。

## 技術路線

- **分層合成**：Canvas 或 PixiJS 可組織背景畫、角色色層、特效與前景；角色可用自主繪製向量或授權圖集，背景與角色採用不同細節密度。
- **動作**：探索關鍵姿態切換、區域性關節運動與手工過渡幀；SVG 可處理簡單形變。不要預設給所有姿態做平滑補間，繪製幀的停留本身就是節奏。
- **機械與複雜空間**：Three.js 的卡通材質和輪廓可作為輔助方向，但需要校準陰影分割槽、線寬與透視，不能直接把預設三維渲染當手繪成片。
- 指定時刻獨立選取姿態與特效幀，背景位移連續可還原，紋理固定種子。`--subframes` 對保持幀從輕或關閉，避免合出多張重影；`--dpr` 保輪廓，`--grain` 只加少量攝影質感。

以上是實現方向，不規定角色引擎、繪製幀率或逐鏡頭動作。

## 材質與渲染

- 工藝依據：輪廓和顏色畫在透明片上，疊放到背景前拍攝。角色表面顏色平整，背景可以保留顏料與紙面的變化，二者不必使用同一濾鏡。
- 線條順著形體走，轉折、前後遮擋和五官有明確取捨；外輪廓可稍重，內部線不能全部像黑色鐵絲。
- 陰影是設計過的色塊，跟著角色體積和光向變化。單純把照片分成三檔明暗，很難得到清楚的臉和手。
- 背景的筆觸固定在環境上；透明片可有極輕的層間差異，但不要每幀隨機漂移，損壞畫面穩定性。
- 光學輝光只圍繞亮源；陰影和描邊保留色彩。主體、載具與角色都經過同樣的色層處理，避免精細三維物體突然混進畫面。

## 配色

下面的色值是示例，看思路，不要原樣照抄。

- 午後街道：背景 `#B9C8C7` / 角色 `#C97954` / 陰影 `#665C76` / 亮色 `#EBD8A8`。
- 夜間裝置：背景 `#263A56` / 主體 `#899AA7` / 陰影 `#34455F` / 亮源 `#DF9B69`。
- 夏日室內：背景 `#E0D6B4` / 主體 `#6D9990` / 陰影 `#527274` / 強調 `#B6564D`。
- 推導：先按場景光色確定背景，再給主體分配能分離出來的色組。陰影可以偏冷或偏暖，不能只把主色一律壓黑；亮源與強調色控制數量。

## 字型

英文展示可選 Barlow Condensed、Archivo Black，輔助用 IBM Plex Sans；中文用思源黑體或思源宋體，自託管 OFL 字型。片名字型按情緒選，不強制傾斜粗字。長字幕保持穩定，放在有足夠反差的區域，不套複雜描邊和發光。

## 運動

- 先設計準備、發力和停住的姿態，再決定中間需要多少繪製幀。快動作可以少幀，表情轉折則留夠停頓。
- 角色保持時，鏡頭、背景或一個區域性仍可動；不同層不必共用同一種步進節奏。
- 衝擊畫和拖影畫只用於動作峰值，避免連續高反差閃爍。退場可以由角色越過鏡頭、環境遮擋或色面切換完成。

## 畫面怎麼活

- 保持姿態中偶爾眨眼、輕微呼吸或衣角擺動，身體主輪廓不持續變形。
- 背景裡的窗簾、蒸汽或燈光用少量狀態變化，週期不要與人物完全一致。
- 行駛場景讓背景平移、車身小幅震動，人物可以大部分靜止；保持視線與支撐關係。

## 鏡頭語法

| 鏡頭運動 | 表達什麼 | 適合哪類內容 |
|---|---|---|
| 在保持姿態上緩慢推近 | 情緒逐漸明確 | 人物、決心、發現 |
| 多層橫移 | 環境與行進 | 旅行、城市、載具 |
| 固定機位等待動作進入 | 動作的方向與重量 | 出場、碰撞、喜劇 |
| 從環境細節拉到全景 | 地點與氣氛 | 世界介紹、過渡 |

## 聲音調色盤

第 1 檔可用 FM 貝斯、合成絃樂感鋪底、鼓與短噪聲動作音；需電吉他、真實鼓組或管絃樂時，用第 2 檔 Tone.js 配合授權取樣。動作音強調準備與落點，不給每張中間幀配聲。口播或對白存在時，主旋律與破風聲讓位。

律動與和聲（舉例，不止這些）：有推動力的流行節奏、溫暖的日常和聲，或稀疏低音支撐的懸疑氛圍。年代感可以從音色來，不必借用熟悉作品的旋律。

## 原生手法

- 保持一張有力姿態，只讓區域性與鏡頭繼續動：適合情緒和角色建立（經典）。
- 快動作壓成一張拖影畫，再落到清楚的結果姿態：適合速度和力量。
- 前景攝影層掠過，切到下一張背景畫：適合行進和空間轉換。
- 燈光切換帶動角色硬邊陰影整體換形：適合狀態變化與戲劇轉折。
- 特效形狀在散去時留下下一鏡的主輪廓：適合能量、餘波和片頭銜接。

## 變化空間

- 結構：圍繞一次動作建立起因與結果；在環境中等待一個變化；以幾個保持姿態串起旅程。
- 開場：角色已在動作準備中；先看環境裡不尋常的細節；從一個靜物的受光變化開始。
- 結尾：停在有餘韻的姿態；動作完成後回到安靜背景；角色離開，留下發生過變化的空間。

## 坑

- 顆粒很舊，動作卻像平滑網頁補間：重新安排關鍵姿態和停留。
- 角色與背景細節一樣密：降低角色色層複雜度，讓背景承擔環境資訊。
- 只做整張角色貼圖平移：至少設計重心、朝向與接觸點變化。
- 陰影每幀跳到無關位置：依據體積和光向設計色塊。
- 保持幀經運動模糊後變成雙影：減少子幀，明確哪些層需要步進。
- 衝擊畫頻繁閃白：減少次數與亮度變化，讓動作本身承擔衝擊。
- 預設呼叫熟悉角色和場景：重畫主體與環境，只借媒介語法。
