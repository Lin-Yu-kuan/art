# 粒子場（particle-field）

> 成千上萬個點：從混沌中聚成一個詞，沿著看不見的力場流動，在重拍上炸開，再重新組合。
> 參照（只學語法）：資料視覺化中的粒子動畫、品牌片裡的粒子組字、流場藝術。不照搬具體作品。

## 本質 / 不是什麼
- 本質：**粒子有目的**：組字、組形、沿場流動、跟隨主體；整體像一種物質，而不是到處飛的亮點。
- 不是：通用的「粒子爆炸 + 鏡頭光暈」模板；也不是沒有結構的星空背景。

## 辨識訊號：每支片子挑 2–3 個
| 訊號 | 長什麼樣 | 適合的主題 |
|---|---|---|
| 粒子組字 | 混沌中的點聚成一個詞或 logo | drop、記憶點 |
| 流場 | 粒子沿看不見的力場流動 | 流動、趨勢 |
| 重拍炸開 | 一個點在重拍上炸成粒子 | 衝擊、爆發 |
| 尾跡 | 粒子跟著主體拖出軌跡 | 速度、路徑 |
| 塵埃和光點 | 慢慢漂浮的顆粒，有景深 | 氛圍、寧靜 |
| 沙和顆粒 | 粒子像沙一樣堆積、塌落 | 時間、侵蝕 |
| 群集 | 粒子像鳥群或魚群一樣聚散 | 群體、協作 |
| 資料粒子 | 一個粒子代表一個單位，按資料聚成形狀 | 規模、數量 |
| 點雲 | 粒子組成一個三維物體，鏡頭繞著轉 | 產品、空間 |
| 墨點和水彩點 | 粒子是不規則的墨點而不是光點 | 手作、東方 |

規則：
- 每支挑 2–3 個，至少一個不在下面「最俗的版本」裡。
- 訊號從主題裡選，不按順序全上。
- 粒子要有目的：每一次運動都說得出它們要去哪。

## 這個風格最俗的版本
- 畫面：黑底上一團發光的粒子炸開、旋轉、聚成 logo，四周再加一點鏡頭光暈。
- 聲音：上升的 riser、炸開的 impact、閃爍的 shimmer。
- brief 的 style 一欄寫明這支片子翻掉了哪幾條，或者為什麼刻意保留（比如使用者要的就是經典版）。保留時，把力氣花在構圖、鏡頭、節奏或一個意外的記憶點上。

## 適配
- 用途：簽名時刻、Logo 演繹、片頭、宣傳片裡的「匯聚」時刻。
- 內容：AI、資料、網路、社群、品牌、宇宙和自然主題。

## 技術路線
- ≤ 5000 個粒子：Canvas 2D `fillRect`。
- 5000–100000：WebGL 點精靈或者 Three.js `InstancedMesh` / `Points`，位置在頂點著色器裡由 `t` 和每個粒子的屬性（種子、目標）算出來。
- **無狀態**：每個粒子的位置是 `f(序號, t)`（recipes.md 第 7、8 節），不要逐幀積分速度。
- 目標形狀：字型載入完後，在離屏畫布上寫字或畫 logo，按網格取樣得到目標點（一次性、確定性）。

## 材質與渲染
- 粒子小（2–5px），大小和亮度有一點隨機（固定種子）；10–15% 的粒子用強調色。
- 密度決定形狀的可讀性：取樣步長 5–8px（1080p）。
- 可選拖尾：用 recipes.md 第 13 節的時間回採，或者運動模糊 `--subframes 4`。
- 深色背景上粒子用加法混合（`lighter`）會更亮；淺色背景用正常混合。

## 配色
下面的色值是示例，看思路，不要原樣照抄。
- 近黑 `#0B0B0D` / 紙色粒子 `#EFEBE3` / 強調 `#16C172`
- 白底 `#F7F6F2` / 墨色粒子 `#151515` / 強調 `#FF4A1C`
- 規則：粒子最多兩種顏色；強調色的粒子比例固定。
- 推導：粒子最多兩種顏色，強調色粒子的比例固定；淺底深粒子、深底淺粒子都可以，從品牌來。黑底發光粒子是最常見的那組。

## 字型
組字用超粗的展示字型（筆畫越粗，粒子字越清晰）：Archivo Black、Anton、Unbounded Black。

## 運動
- 聚合：彈簧 `{1.5, 0.82}`，每個粒子有隨機延遲（0–0.9 秒），聚合前帶一點噪聲漂移。
- 炸開：`outExpo`，0.4–0.8 秒，方向從中心向外加一點隨機。
- 流動：粒子位置 = 起點 + 沿流場的解析路徑（比如沿一組正弦曲線），或者週期性的噪聲偏移。
- 在一個形狀停留足夠久讓人讀清（≥ 1.5 秒），再變成下一個。

## 畫面怎麼活
- 組成一個形狀後，粒子不完全靜止：每個粒子在目標點附近小幅漂移（2–4px，噪聲在圓上取樣，可循環），整體看起來在呼吸。
- 邊緣偶爾有幾顆粒子脫落飄走，提示這個形狀是由粒子聚成的。

## 鏡頭語法
| 鏡頭運動 | 表達什麼 | 適合哪類內容 |
|---|---|---|
| 急推 + 震屏（炸開時） | 衝擊 | drop |
| 緩慢拉遠，粒子組成更大的形狀 | 尺度 | 揭示 |
| 穿過粒子云 | 沉浸 | 轉場 |

## 聲音調色盤
炸開用 `impact` + `crash`；聚合用 shimmer、上升的 riser；流動用鋪底和顆粒感的高頻。drop 前留一拍靜音。第 1 檔合成即可。

律動與和聲（舉例，不止這些）：四踩的推進，或者復節奏的顆粒感（三連音琶音壓在四拍上）；小調、Dorian，或者一個和絃只靠濾波變化；累加（粒子越聚越多，聲部越疊越厚）和吸氣 → 爆發都合適。

## 原生手法
- 一個點炸成粒子，粒子聚成一個詞：適合 drop 和記憶點。
- 一個詞的粒子流動著重組成另一個詞：適合「A 變成 B」。
- 粒子跟隨一個主體形成尾跡：適合速度和路徑。

## 變化空間
- 結構：混沌 → 秩序 → 再混沌；一個詞變三個詞；粒子從畫面四角匯聚到中心。
- 開場：一個點；一團漂浮的塵埃。
- 結尾：粒子組成 logo 後靜止；粒子散開、只剩一個點（循環）。

## 坑
- 粒子沒有目的，就是模板：每次運動都要回答「它們要去哪」。
- 中心留出一個「洞」：炸開的起始距離從 0 開始分佈。
- 形狀停留太短看不清字。
- 粒子太多、幀時間暴漲：超過 5000 個就換 WebGL。
