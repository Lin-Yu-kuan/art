# 合成波霓虹（synthwave-neon）

> 80 年代人想像中的未來：夜色、霓虹、鍍鉻和合成器。
> 參照（只學語法）：synthwave / outrun / retrowave 視覺、80 年代電影海報和片頭的鍍鉻字、霓虹招牌攝影、錄影帶時代的電視包裝。不照搬具體作品、電影標識和專輯封面。

## 本質 / 不是什麼
- 本質：**從 80 年代看過去的未來**。暗夜打底，光都來自有來源的發光體（霓虹管、螢幕、車燈、太陽）；深紫或深藍做底色，上面一兩種霓虹色；表面要麼是鍍鉻的反光，要麼帶磁帶、映象管的模擬質感。
- 不是：AI 預設的紫粉漸變加到處發光，那種畫面沒有光源，也沒有年代感。也不必把「網格 + 日落 + 鍍鉻字」全部搬上來，那只是這個類型裡最常見的一種畫面。

## 辨識訊號：每支片子挑 2–3 個
觀眾靠兩三個訊號就能認出合成波，全部堆上反而像素材包。

| 訊號 | 長什麼樣 | 適合的主題 |
|---|---|---|
| 透視網格地面 | 向地平線收攏的發光網格，向鏡頭滾動 | 速度、前進、遊戲 |
| 分層落日 | 半圓漸變，水平切口條紋 | 結尾、情緒 |
| 鍍鉻大字 | 豎向多段漸變 + 亮邊 + 星芒高光 | 片名、logo |
| 霓虹燈管招牌 | 燈管有彎折、接頭和支架，字一筆一筆亮 | 品牌、店鋪、夜生活 |
| 夜城天際線 | 剪影樓群，窗格燈光一盞盞亮滅 | 城市、科技、都市情緒 |
| 車燈與光軌 | 紅色尾燈拖出長曝光線，路燈一盞盞掠過 | 駕駛、旅程、速度 |
| 棕櫚與海岸 | 粉藍天空下的棕櫚剪影、低矮建築 | 度假、夏天、生活方式 |
| 雷射與掃描光束 | 舞廳裡的扇形雷射，隨鼓點掃動 | 音樂、演出、派對 |
| 80 年代電子屏 | 向量線框、琥珀或綠色字元、街機介面 | 遊戲、開發者、硬體 |
| 雨夜倒影 | 溼地面上被雨點打碎的霓虹倒影 | 敘事、懸念、開場 |
| 錄影帶質感 | 跟蹤噪聲、色彩滲出、螢幕角落的 OSD 字 | 回憶、懷舊、檔案 |

規則：
- 至少一個訊號不是網格或日落。
- 訊號從主題裡選：講音樂的可以用舞廳雷射，講遊戲的可以用街機螢幕，講城市的可以用雨夜招牌。
- 使用者點名要經典 outrun，或者給的參考就是這種畫面，才把網格、日落、鍍鉻字三件套一起上。

## 這個風格最俗的版本
- 畫面：網格地面從頭滾到尾 + 畫面正中一顆條紋落日 + 鍍鉻字從地平線升起 + 紫粉漸變的天空。
- 聲音：四踩加門控軍鼓、八分鋸齒貝斯、♭VI – ♭VII – i 循環。
- brief 的 style 一欄寫明這支片子翻掉了哪幾條，或者為什麼刻意保留（比如使用者要的就是經典版）。保留時，把力氣花在別的地方：構圖、鏡頭、節奏，或者一個別人沒做過的記憶點。

## 適配
- 用途：片頭、音樂向短片、復古主題的宣傳、作品集的一段。
- 內容：音樂、遊戲、復古品牌、夜生活、汽車、城市。
- 不適合：主題和 80 年代、夜色都無關，使用者也沒點名時，不要用；它不是通用的「科技感」。

## 技術路線
Canvas 2D 畫網格、天際線、燈管、光軌（透視網格用投影公式算線）；需要空間穿行的（駕駛、貼地飛行）用 Three.js 搭場景。WebGL 後期做 bloom 和輕微的掃描線；錄影帶質感按 `crt-vhs.md` 的後期混搭進來，只用一兩項。雨夜倒影 = 場景豎直翻轉 + 模糊 + 隨 t 變化的波紋位移，再壓暗。

## 材質與渲染
只做選中的訊號，下面是各自的做法：
- 霓虹燈管：亮芯是一條接近白色的細線，外面多層越來越寬、越來越淡的同色線（或者 bloom）。燈管有厚度、彎頭和金屬支架；熄滅的燈管是暗灰色的玻璃管，不會憑空消失。
- 透視網格：橫線間距隨距離指數縮小，隨時間向鏡頭滾動（`offset = (t * speed) % gap`）。
- 落日：半圓 + 豎向漸變 + 水平切口條紋（條紋間距從上到下變大）。
- 鍍鉻字：豎向多段漸變（天藍 → 白 → 深藍 → 橙）+ 亮邊 + 一個星芒高光。
- 天際線：剪影樓群，亮窗用固定種子分佈；遠處的樓更藍、更淡，疊一層霧。
- 光軌：沿路徑的長線，頭亮尾暗，像長曝光照片。
- 星空：固定種子的點，偶爾閃爍。

## 配色
- 示例（看思路，不要原樣照抄）：深紫 `#140A2E` / 洋紅 `#FF2E97` / 青 `#00E5FF`；深藍 `#0B1033` / 琥珀 `#FFB300` / 青 `#3FE0D0`；近黑 `#0A0A12` / 尾燈紅 `#FF3B30` / 路燈白 `#F2F2F2`。
- 推導：底色在深紫到深藍之間選一個（很暗）；霓虹色最多兩種，從主題裡來，品牌色能當霓虹用就用品牌色。洋紅加青只是其中一種，琥珀加青（電子屏）、紅加白（車燈和路燈）、單一的粉（一塊招牌）都成立。
- 發光只給有光源的東西，背景保持暗。

## 字型
80 年代感的展示字型：Monoton、Audiowide、Michroma、Orbitron（謹慎）、粗斜體（Russo One）；霓虹手寫字可以用 Pacifico / Mr Dafoe 這類（OFL）；電子屏訊號用等寬像素字型。

## 運動
- 前進感從訊號裡挑一種：網格滾動、光軌向後拉、天際線視差、路燈一盞盞掠過。勻速在這裡是對的，它表達的是一直在路上。
- 大字用彈簧 `{1.6, 0.9}` 推出或升起。
- 霓虹亮起：先閃兩下（亮暗各 1–2 幀），再穩定亮著；招牌按筆畫順序通電。
- 節拍：重拍上霓虹亮度脈衝一次。

## 畫面怎麼活
- 某根燈管接觸不良，隔一陣閃一兩下（全片兩三次就夠）；天際線上的窗一盞盞亮滅；溼地面上的倒影被雨點打碎。
- 用了網格和日落時：網格一直前滾，日落的橫條緩慢上移。
- 遠處的星點、掃描線微微閃，亮度低於主體。

## 鏡頭語法
| 鏡頭運動 | 表達什麼 | 適合哪類內容 |
|---|---|---|
| 貼地向前飛行（網格、公路） | 速度、前進 | 開場、過渡 |
| 車內或後視鏡視角 | 午夜駕駛、回望 | 敘事 |
| 仰拍霓虹招牌 | 宏大、標誌 | 標題、logo |
| 沿街橫移，招牌一塊塊掠過 | 巡遊 | 段落 |
| 推近一塊螢幕，進入螢幕裡的世界 | 進入、穿越 | 轉場 |
| 俯拍雨夜路口 | 城市、孤獨 | 開場 |

## 聲音調色盤
合成波的聲音訊號也挑兩三個：門控大混響軍鼓（`snare` + reverb 0.5）、八分音符鋸齒貝斯（`bass` 帶 glide）、寬鋸齒鋪底（`pad` voices 7、cents 20）、帶顫音的鋸齒 lead、FM 電鋼、琶音器、music bus 上一點 `wow`（像錄影帶裡的音樂）。BPM 80–118。第 1 檔合成很合適。

律動與和聲（舉例，不止這些）：四踩加門控軍鼓是最常見的那種，用之前先想想別的：half-time 的 darksynth、帶 shuffle 的 italo、開場只有琶音器沒有鼓、整體降速降調的 vaporwave 味。和聲在小調、Dorian 裡選，♭VI – ♭VII – i 之外還可以試 i – ♭VII – ♭VI – V，或者整段只停在一個和絃上靠音色變化推進。

## 原生手法
- 霓虹招牌逐筆通電，有一筆接觸不良，最後才亮：適合 logo、標題。
- 字先出現在溼地面的倒影裡，鏡頭抬起才看到真正的招牌：適合開場，留一點懸念。
- 光軌在長曝光裡寫出一個形狀或 logo：適合落版。
- 推進一塊電子屏，螢幕裡的線框世界變成下一鏡：適合轉場。
- 穿過一個霓虹框進入下一鏡：適合轉場。
- 字從地平線升起並亮起霓虹、太陽條紋隨節拍開合：經典 outrun 的手法，使用者要經典版時用。

## 變化空間
- 結構：一次午夜駕駛；一條街的招牌逐個點亮；街機螢幕裡一局打到最後一關；舞廳雷射跟著鼓點越掃越密；同一個街角從黃昏到深夜。
- 開場：漆黑中一根燈管閃兩下亮起；雨夜地面上的一片倒影；後視鏡裡越來越近的車燈。
- 結尾：整條街的招牌熄滅，只剩 logo 亮著；車開遠，只剩兩點尾燈；螢幕關機，畫面收成一條亮線。

## 坑
- 做成 AI 預設的紫粉漸變：畫面裡要有光源和年代訊號，用訊號表裡的東西撐畫面，不靠漸變。
- 三件套一次全上、又沒有理由：觀眾看到的是素材包，記不住這支片子。換成跟主題有關的訊號。
- 發光太多，畫麵糊成一團：bloom 只給亮部（閾值 > 0.8）。
- 漸變在編碼後出現色帶：加輕微顆粒（`--grain 3`）。
- 熄滅的燈管直接消失：真實的燈管關掉後還在，是一根暗灰色的玻璃管。
