# 資料動態（data-motion）

> 數字和圖表本身就是主角：柱子長出來、線條畫出來、數字滾動落定，每一個變化都對應一個事實。
> 參照（只學語法）：資料新聞的動態圖（The Pudding、NYT、Bloomberg 的視覺化）、Tufte 的資料墨水比、Hans Rosling 式的動態圖表。不照搬具體圖表。

## 本質 / 不是什麼
- 本質：**每個視覺變化都編碼一個資料**（長度、面積、位置、顏色）；去掉一切不傳達資訊的裝飾；圖表一邊動一邊講。
- 不是：裝飾性的「科技感」假圖表；也不是 3D 餅圖。

## 辨識訊號：每支片子挑 2–3 個
| 訊號 | 長什麼樣 | 適合的主題 |
|---|---|---|
| 長出來的柱子 | 從 0 開始長，同步計數 | 對比、排名 |
| 畫出來的折線 | 線條隨時間畫出，標籤跟著線頭走 | 趨勢、時間 |
| 滾動計數 | 一個數字滾動到終值，落定時輕輕砸一下 | 單一成績 |
| 高亮一個、其餘變灰 | 一個資料保持顏色，其他退成灰 | 我們 vs 其他 |
| 刻度變化 | 拉遠改變刻度，大柱子變成小點 | 指數增長、規模 |
| 單點陣圖 | 一個點或一個小圖示代表一個單位，堆成整體 | 人數、數量感 |
| 面積和比例 | 圓、方塊的面積表示佔比 | 份額、構成 |
| 地圖 | 地圖上的點、熱區、連線 | 地域分佈 |
| 排名賽跑 | 條形圖隨時間交換位置 | 歷史變化 |
| 註釋標註 | 引線指向一個點，寫一句結論 | 拐點、關鍵事件 |

規則：
- 每支挑 2–3 個，至少一個不在下面「最俗的版本」裡。
- 訊號從主題裡選，不按順序全上。
- 圖表類型由資料決定：時間序列用線，對比用柱，構成用面積或單點陣圖。訊號挑的是在資料允許的範圍裡怎麼講。

## 這個風格最俗的版本
- 畫面：深色底、發光的條形圖賽跑、角落裡一個滾動計數器、結尾一個大數字反色。
- 聲音：越來越密的 tick 加數字落定時的 impact。
- brief 的 style 一欄寫明這支片子翻掉了哪幾條，或者為什麼刻意保留（比如使用者要的就是經典版）。保留時，把力氣花在構圖、鏡頭、節奏或一個意外的記憶點上。

## 適配
- 用途：資料爆點、產品宣傳裡的成績展示、年度回顧。
- 內容：增長、對比、排名、分佈、時間變化。**資料必須來自使用者或可靠來源**。

## 技術路線
Canvas 2D 或 SVG，自己寫比例尺（`scale = v => lerp(r0, r1, (v - d0) / (d1 - d0))`）。曲線用 SVG path + `stroke-dashoffset` 畫出來，或者 Canvas 逐點畫到當前進度。數字用等寬字型。

## 材質與渲染
- 去掉多餘的網格線和邊框；座標軸只保留必要的刻度，顏色很淡。
- 柱子和麵積從 0 開始長；線條有起點的圓點和終點的標籤。
- 高亮一個資料，其餘變灰（這是最有力的手法）。
- 標籤直接貼在資料旁邊，不要圖例。

## 配色
下面的色值是示例，看思路，不要原樣照抄。
- 底 `#FAFAF7` / 墨 `#1A1A1A` / 灰 `#BDBAB3` / 強調 `#E4572E`
- 底 `#0E0F12` / 白 `#EDEDED` / 灰 `#4A4D55` / 強調 `#4FD1C5`
- 規則：顏色只有語義（高亮 / 其他、增長 / 下降），不做裝飾；最多兩個語義色。
- 推導：淺底或深底都可以；顏色只有語義，最多兩個語義色（高亮和其他、增長和下降），從品牌或資料含義來。橙紅加灰是最常見的組合。

## 字型
數字用等寬或帶等寬數字的字型（JetBrains Mono、IBM Plex Sans、Inter Tight 的 tnum）；標題用編輯感的無襯線或襯線體。

## 運動
- 柱子和麵積：`glide` 或彈簧 `{2.4, 0.85}`，錯峰 40–80 毫秒。
- 線條：按時間勻速畫出（時間軸是線性的，勻速在這裡是正確的），畫到當前點時標籤跟著跑。
- 數字滾動：`outExpo` 1.5–2.5 秒，落定時輕輕砸一下。
- 排序變化：元素平滑交換位置（彈簧），不要瞬移。

## 畫面怎麼活
- 以靜為主：在這種風格里運動編碼資料，資料落定後還在晃，會被讀成數值在變。
- 可以活的只有「當前」：線條末端一個呼吸的圓點、最新那個資料點的輕微脈衝、標籤跟著線頭走。

## 鏡頭語法
| 鏡頭運動 | 表達什麼 | 適合哪類內容 |
|---|---|---|
| 固定機位 | 讓資料自己說話 | 大多數圖表 |
| 推近到一個資料點 | 聚焦 | 關鍵數字、拐點 |
| 拉遠改變刻度 | 尺度的震撼 | 指數增長、「原來這麼大」 |
| 沿時間軸平移 | 時間推進 | 長時間序列 |

## 聲音調色盤
tick（每個資料點一下，越來越密）、數字落定時的 `impact` 或 `bell`、輕柔的鋪底。第 1 檔合成即可。

律動與和聲（舉例，不止這些）：直拍，或者讓資料本身生成節奏（數值變化的密度就是 tick 的密度）；數值上升時音階上行、下降時下行。累加曲線（每進一組資料進一個聲部）很合適。

## 原生手法
- 高亮一個、其餘變灰：適合「我們 vs 其他」。
- 拉遠改變刻度，原來的大柱子變成小點：適合指數增長、規模對比。
- 一個數字滾動到終值，畫面反色：適合單一成績。

## 變化空間
- 結構：一個數字講完一個故事；前後對比；排名賽跑。
- 開場：一個巨大的問號或者 0；座標軸從一個點展開。
- 結尾：最重要的那個數字定格，下面一行來源小字。

## 坑
- **編造資料**：不確定的數字一律標出來讓使用者核對；來源寫在畫面上。
- 柱子不從 0 開始、座標軸被截斷，會誤導觀眾。必須截斷時，畫面上寫明「縱軸未從 0 開始」。
- 數字停留太短讀不完：關鍵數字至少停 2.5 秒。
- 倍數說錯：「漲了 9 倍」是原來的 10 倍，「漲到原來的 9 倍」才是 9 倍。畫面上的結論要能從圖上的數算出來，審片時真的算一遍。
- 示意資料沒有標：使用者沒給真實資料、只是演示效果時，每一個出現圖表的鏡頭都標「示意資料」；真實資料不要出現這個角標。
- 同一組數前後對不上：縮圖裡的終值和展開後的終值不一致，或者推近、展開之後計數從 0 重來。
- 單位、幣種、時間範圍漏寫，或者跟使用者給的不一致。
- 先出資料再出座標軸：順序應該是座標系先出，資料再長出來，最後只標一件事。
