# 軟萌 3D（soft-3d-toy）

> 圓潤的啞光幾何體、黏土和玩具的質感、柔和的影子，東西會彈、會擠、會蹦，讓人想伸手去捏。
> 參照（只學語法）：黏土動畫、潮玩、品牌 3D 插畫裡圓潤的幾何風格。不照搬具體角色和 IP。

## 本質 / 不是什麼
- 本質：**所有邊都是圓角**、**啞光材質**（高粗糙度，帶一點次表面散射的感覺）、柔和的大面積光和接觸陰影；運動誇張而有彈性（擠壓與拉伸）。
- 不是：寫實渲染；也不是低多邊形的硬邊風格。

## 辨識訊號：每支片子挑 2–3 個
| 訊號 | 長什麼樣 | 適合的主題 |
|---|---|---|
| 擠壓與拉伸 | 落地壓扁、彈起拉長 | 活力、輕鬆 |
| 連鎖反應 | 一個物體撞倒下一個，多米諾式傳下去 | 流程、因果 |
| 黏土指紋 | 表面有手捏的凹痕和指紋 | 手作、溫度 |
| 潮玩小角色 | 圓頭大身、兩個點做眼睛 | 吉祥物、品牌角色 |
| 積木與拼插 | 方塊按卡扣拼起來 | 組合、搭建 |
| 充氣和氣球 | 鼓起來、漏氣、飄走 | 增長、慶祝 |
| 果凍和軟糖 | 半透明、晃動的軟體 | 食品、趣味 |
| 迷你場景 | 桌面大小的小房間、小城 | 場景、生活 |
| 捏成新形狀 | 一個物體被捏、被拉成下一個形狀 | 轉變、變身 |
| 倒進容器 | 很多小物體倒進一個形狀裡填滿 | 匯聚、結尾 |

規則：
- 每支挑 2–3 個，至少一個不在下面「最俗的版本」裡。
- 訊號從主題裡選，不按順序全上。

## 這個風格最俗的版本
- 畫面：奶油底上珊瑚、薄荷、天藍的圓球和方塊，一個球掉下來彈兩下，所有東西擠進 logo。
- 聲音：馬林巴、pop、boing 彈簧聲，輕快的大調。
- brief 的 style 一欄寫明這支片子翻掉了哪幾條，或者為什麼刻意保留（比如使用者要的就是經典版）。保留時，把力氣花在構圖、鏡頭、節奏或一個意外的記憶點上。

## 適配
- 用途：產品宣傳（友好型產品）、吉祥物登場、講解短片、Logo 演繹。
- 內容：消費類 App、教育、兒童、食品、社群、遊戲化功能。

## 技術路線
Three.js：`RoundedBoxGeometry`（addons）、球體、膠囊體、圓環拼出物體；`MeshStandardMaterial` / `MeshPhysicalMaterial`，roughness 0.6–0.9，sheen 可以增加絨感；一盞大面積柔光（`RectAreaLight` 或大的方向光 + 軟陰影）加環境光；地面用 `ShadowMaterial` 接陰影。後期可加輕微的景深。`--dpr 2`。

## 材質與渲染
- 顏色飽和但不刺眼的粉彩；同一物體的不同部分用相鄰的色。
- 接觸陰影（物體落地的地方一團柔和的暗）比投影更重要。
- 表面可以有極細的噪聲凹凸（黏土指紋感，謹慎使用）。
- 背景是純色或非常柔和的漸變，地面和背景無縫銜接。

## 配色
下面的色值是示例，看思路，不要原樣照抄。
- 奶油 `#FFF4E6` / 珊瑚 `#FF8A73` / 薄荷 `#7ED9C3` / 天藍 `#7CB7FF` / 黃油 `#FFD66B`
- 薰衣草底 `#E9E4FF` / 紫 `#8B7CFF` / 桃 `#FFB59E` / 墨 `#2B2540`（只給眼睛和文字）
- 規則：一個物體最多三個顏色；背景比主體淺、低飽和。
- 推導：背景比主體淺、飽和度低，一個物體最多三個顏色。主色從品牌推，在 OKLab 里拉出柔和的明暗；奶油加糖果色是最常見的那組，也可以試大地色黏土、單色系、深色背景上的高飽和小物件。

## 字型
圓潤的粗體：Fredoka、Baloo 2、Nunito Black、Rubik（OFL）；中文用站酷快樂體、思源黑體 Heavy。字也可以擠出成 3D 圓角字。

## 運動
- 彈簧 `{2.8, 0.45}`：明顯的回彈；落地時擠壓（y 縮 30%、xz 擴），彈起時拉伸。
- 預備動作誇張一些（下蹲再跳）；跟隨動作（耳朵、天線晚一點停）。
- 物體之間的碰撞要有時差和擠壓。

## 畫面怎麼活
- 物體待機時輕輕呼吸（擠壓 2–3%）；有眼睛的眨一下；天線、耳朵這類小配件還在餘擺。
- 小動作錯開時間，別讓所有東西同一拍一起動。

## 鏡頭語法
| 鏡頭運動 | 表達什麼 | 適合哪類內容 |
|---|---|---|
| 45° 俯視的平台視角 | 一個小世界 | 場景、流程 |
| 跟著跳躍的物體上下 | 活力 | 角色登場 |
| 推近到一個物體 | 特寫 | 產品細節 |
| 緩慢環繞一個轉檯 | 展示 | 產品、吉祥物 |

## 聲音調色盤
俏皮：`pop`（音高隨物體大小變化）、軟 `boom`、木琴、馬林巴（`mallet`，material 'xylo' / 'marimba'）、輕快的拍手和 shaker。BPM 100–124。

律動與和聲（舉例，不止這些）：有彈性的直拍或 shuffle；大調、Lydian、加九度；音畫同形（每次彈跳一個音，音高跟著高度走）最合適；`cowbell`、`rim`、`shaker` 做玩具打擊樂。不側鏈或很輕。

## 原生手法
- 一個物體落下把另一個彈飛，連鎖反應：適合流程和因果（「一個動作引發一串結果」）。
- 物體被捏成下一個形狀：適合轉變、變身。
- 很多小物體倒進一個容器拼成 logo：適合結尾。

## 變化空間
- 結構：一條多米諾式的連鎖反應；一個角色的一天；一個盒子裡蹦出三個功能。
- 開場：一個球從畫面上方掉下來彈兩下；一個盒子在晃動。
- 結尾：所有物體擠進 logo 形狀裡，最後一個蹦上去落定。

## 坑
- 彈過頭顯得廉價：同類元素統一彈簧檔位，主體比小物件彈得少。
- 材質太亮太滑，就成了塑膠：粗糙度要高。
- 畫角色時別畫寫實五官：最多兩個點做眼睛。
