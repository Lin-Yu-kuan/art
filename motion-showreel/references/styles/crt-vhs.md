# 復古電視 / VHS（crt-vhs）

> 映象管的弧面、掃描線、熒光點和光暈；錄影帶的跟蹤噪聲、色彩滲漏和抖動。畫面像是從一臺舊電視裡放出來的。
> 參照（只學語法）：80–90 年代電視臺標識、錄影帶片頭、模擬訊號的失真。不照搬具體電視臺的標識和節目畫面。

## 本質 / 不是什麼
- 本質：內容（任何風格）先畫好，再經過一層**模擬訊號的物理模型**：弧面變形、掃描線、RGB 熒光點、色差、亮部光暈、偶爾的跟蹤條和訊號抖動。
- 不是：在畫面上平鋪一張掃描線圖片；也不是每一幀都在劇烈故障的「賽博」濾鏡。

## 辨識訊號：每支片子挑 2–3 個
| 訊號 | 長什麼樣 | 適合的主題 |
|---|---|---|
| 掃描線和熒光點 | 一行行掃描線，近看是 RGB 熒光點 | 螢幕感、質感 |
| 弧面變形 | 畫面四角向內彎，邊緣暗 | 舊電視 |
| 色差和滲色 | 紅藍通道錯開，顏色溢位邊緣 | 模擬訊號 |
| 跟蹤噪聲帶 | 一條橫向幹擾帶慢慢滾過 | 錄影帶、不穩定 |
| 螢幕 OSD 字 | PLAY ▶、REC ●、時間碼、頻道號 | 錄影、檔案 |
| 換臺雪花 | 雪花噪聲幾幀後鎖定新畫面 | 段落切換 |
| 開關機亮線 | 畫面收成一條亮線再縮成一個點 | 開場、結尾 |
| 快進撕裂 | 畫面加速，橫向撕開幾道 | 時間流逝 |
| 測試卡和彩條 | 彩條、測試圖、臺標角標 | 電視臺、節目 |
| 錄影帶實物 | 磁帶盒、標籤手寫字、插入錄影機 | 回憶、家庭錄影 |
| 褪色和磨損 | 飽和度低、對比偏、偶爾掉幀 | 年代感、懸疑 |

規則：
- 每支挑 2–3 個，至少一個不在下面「最俗的版本」裡。
- 訊號從主題裡選，不按順序全上。
- 訊號層是質感，內容是主角：訊號再多，也要讓內容一眼看清。

## 這個風格最俗的版本
- 畫面：全程劇烈故障、洋紅和青的色差、角落一個「PLAY ▶」、開頭彩條、結尾關機收成一個點。
- 聲音：合成波加磁帶抖動，切換時一聲電視嗡鳴。
- brief 的 style 一欄寫明這支片子翻掉了哪幾條，或者為什麼刻意保留（比如使用者要的就是經典版）。保留時，把力氣花在構圖、鏡頭、節奏或一個意外的記憶點上。

## 適配
- 用途：片頭、懷舊主題的宣傳片、作品集裡的復古段、Logo 演繹。
- 內容：遊戲史、媒體史、復古品牌、音樂、懸疑。

## 技術路線
Canvas 畫內容 → WebGL 後期（recipes.md 第 12 節的模板再加 VHS 效果）。後期在著色器裡實現：弧面、掃描線、熒光點陣、色差、bloom（亮部模糊後疊加）、跟蹤噪聲（按 t 移動的水平噪聲帶）、顏色滲漏（色度水平模糊）。先渲一幀確認著色器生效。不要 `--grain`（顆粒在著色器裡按幀固定種子生成）。

## 材質與渲染
- 弧面：`uv` 按距離中心的平方向外推；畫面四角變暗、圓角黑邊。
- 掃描線：`sin(uv.y * 行數 * π)` 調變亮度，行數 ≈ 畫面高度的 1/2–1/3。
- 熒光點：按像素列交替加強 R/G/B（很弱）。
- VHS：色度訊號水平模糊 3–6px 並右移 1–2px；頂部或底部偶爾出現一條跟蹤噪聲帶；整體水平抖動 ±1px（低頻噪聲）。
- 撞擊或切換時：短暫加強色差、跳幀、畫面上下滾動一次。

## 配色
下面的色值是示例，看思路，不要原樣照抄。
- 內容本身的配色加上 CRT 的特性：黑不是純黑（`#0B0D0B`），白偏暖或偏冷。
- 電視臺風：深藍 `#0A1A6B` / 亮黃 `#FFD400` / 白 / 洋紅 `#FF2E88`
- 恐怖 / 懸疑：灰綠 `#1A2A22` / 蒼白 `#C9D6C9` / 血紅 `#B3001B`
- 推導：內容本身的配色經過 CRT 處理：黑不是純黑，白偏暖或偏冷，飽和度略高並溢位。電視臺風、家庭錄影的褪色暖調、監控畫面的灰綠都可以；洋紅加青是最常見的那組。

## 字型
等寬或像素字型做 OSD（螢幕顯示，比如 PLAY ▶、時間碼）：VT323、Share Tech Mono；標題可以用 80 年代感的粗斜體（Righteous、Monoton 謹慎用）。

## 運動
- 內容按自己的風格運動；訊號層的效果按事件觸發（切臺、撞擊）或者緩慢漂移。
- 換臺轉場：黑屏 → 雪花噪聲 2–4 幀 → 新畫面從中間一條亮線展開（CRT 開機）。

## 畫面怎麼活
- 一條滾動幹擾帶慢慢往上走；畫面隔幾秒有一次 1px 的同步抖動；REC 圓點或時間碼閃爍。
- 顆粒交給 `--grain`，不要在頁面裡逐幀畫噪點。

## 鏡頭語法
| 鏡頭運動 | 表達什麼 | 適合哪類內容 |
|---|---|---|
| 推近到螢幕，看到熒光點 | 進入電視裡的世界 | 開場、轉場 |
| 拉遠露出電視機外殼（程式碼畫的） | 「這是一段錄影」 | 回憶、結尾 |
| 換臺 | 切換話題 | 段落切換 |

## 聲音調色盤
低保真：訊號底噪（`ambience({ kind: 'tape' })`，很輕）、換臺的 `glitch` 和咔噠聲、合成器鋪底（帶一點音高抖動）。第 1 檔合成即可；可以把整個音樂 bus 加 `lowpass: 6000` 模擬磁帶的頻響。

律動與和聲（舉例，不止這些）：80–90 年代電視的直拍，或者無拍的訊號漂移；小調、Dorian、半音下行，換臺時可以整段換調。媒介感來自 music bus 的 `wow: 0.3–0.6` + `lowpass: 6000`。

## 原生手法
- CRT 開機 / 關機（亮線展開 / 收縮成一個點）：適合開場和結尾。
- 換臺：適合多個段落、年代切換。
- 錄影帶快進（畫面加速 + 橫向撕裂）：適合時間流逝。

## 變化空間
- 結構：一臺電視換過 6 個頻道；一盤錄影帶從開頭到結尾；一檔節目的片頭。
- 開場：雪破圖 → 訊號鎖定；黑屏上一個「PLAY ▶」。
- 結尾：關機收縮成一個光點；畫面停在一幀暫停的錄影，OSD 閃爍。

## 坑
- 效果太重，內容看不清：訊號層是質感，不是主角。
- 每幀隨機的噪聲導致編碼後糊成一片：噪聲按幀固定種子，噪聲帶要有結構。
- 著色器在軟體渲染下非常慢：先測單幀耗時。
