# 雜誌拼貼（editorial-collage）

> 剪下來的照片和色紙、撕邊、膠帶、貼紙、手寫標註，層層疊疊地拼出一頁會動的雜誌。
> 參照（只學語法）：時尚和音樂雜誌的拼貼版式、達達拼貼、當代社交媒體的 scrapbook 風。不照搬具體作品和受版權保護的圖片。

## 本質 / 不是什麼
- 本質：**每個元素都像一張被剪下來的紙**（有白邊、撕邊、投影），排布有意不對齊；手寫字、圈畫、箭頭作為第二層；元素像被一隻手放上去。
- 不是：整齊的網格版式；也不是貼滿表情包的廉價貼紙風。

## 辨識訊號：每支片子挑 2–3 個
| 訊號 | 長什麼樣 | 適合的主題 |
|---|---|---|
| 剪紙白邊 | 照片和色紙帶一圈白邊和輕投影 | 人物、作品 |
| 撕邊 | 紙的邊緣是撕開的毛邊 | 揭示、打破 |
| 膠帶 | 半透明、兩端鋸齒的膠帶把東西貼住 | 手作、記錄 |
| 半調照片 | 照片做成單色網點再疊一張色紙 | 時尚、音樂 |
| 手寫標註 | 馬克筆的圈、箭頭、下劃線、星號 | 強調賣點 |
| 勒索信字母 | 每個字母剪自不同的紙 | 神秘、宣言 |
| 色紙幾何塊 | 剪出來的圓、條、不規則塊 | 抽象、節奏 |
| 貼紙和標籤 | 價籤、圓點貼、編號標籤 | 產品、清單 |
| 訂書釘和回形針 | 金屬小物件把紙片釘在一起 | 檔案、檔案 |
| 雜誌頁面元素 | 頁碼、欄目名、刊頭、條形碼 | 出版、品牌 |
| 拍立得照片 | 底邊寬的白框照片 | 回憶、人物 |

規則：
- 每支挑 2–3 個，至少一個不在下面「最俗的版本」裡。
- 訊號從主題裡選，不按順序全上。

## 這個風格最俗的版本
- 畫面：牛皮紙底、膠帶、拍立得、紅色手寫圈、勒索信標題，每張紙都歪著落下來。
- 聲音：紙張擬音加輕快的撥絃 shuffle。
- brief 的 style 一欄寫明這支片子翻掉了哪幾條，或者為什麼刻意保留（比如使用者要的就是經典版）。保留時，把力氣花在構圖、鏡頭、節奏或一個意外的記憶點上。

## 適配
- 用途：宣傳短片、金句卡點、人物或團隊介紹、活動預告。
- 內容：潮流、生活方式、創意團隊、年輕品牌、個人作品集。

## 技術路線
Canvas 2D。素材來自使用者提供的照片或產品圖（裁成不規則形狀），或者程式碼畫的色紙和圖形。撕邊用噪聲生成多邊形路徑作為 clip；投影用 `shadowBlur` 很小、偏移很小的投影。手寫標註用 SVG 路徑描邊或者 Canvas 逐段畫線。

## 材質與渲染
- 剪紙：不規則多邊形 clip + 2–4px 白邊 + 輕投影。每張紙有一個固定的小旋轉（±6°，種子決定）。
- 膠帶：半透明的矩形，兩端是鋸齒邊，略微旋轉。
- 半調照片：照片可以做成單色半調，再疊一個色紙。
- 手寫層：馬克筆質感的線（圓頭、輕微抖動），圈、箭頭、下劃線、星號。

## 配色
下面的色值是示例，看思路，不要原樣照抄。
- 牛皮紙 `#E8DCC6` / 墨 `#1B1B1B` / 番茄紅 `#E8452C` / 鈷藍 `#2A4BD7`
- 白 `#FAFAF7` / 黑 `#111` / 熒光綠 `#B6FF3B` / 粉 `#FFB4D9`
- 規則：底色 1 個，紙片顏色 2–3 個，手寫標註只用一個顏色。
- 推導：底色 1 個（紙色、白、深色都可以）+ 紙片 2–3 個 + 手寫標註 1 個顏色，從主題或品牌來；牛皮紙加番茄紅是最常見的。

## 字型
- 標題：粗襯線或怪誕體剪成紙片（DM Serif Display、Archivo Black、Rubik Mono One）；可以每個字母一張紙，做成勒索信的風格（謹慎使用）。
- 標註：手寫體（Caveat、Gochi Hand、站酷快樂體）。

## 運動
- 「被放上去」：紙片從畫面外或上方落下，帶一點旋轉，彈簧 `{2.8, 0.55}` 落定，落定時投影變小（貼近紙面）。
- 手寫標註按筆畫順序畫出來（`stroke-dashoffset`），速度像真的在寫。
- 可以用步進（12fps）增加手作感。

## 畫面怎麼活
- 膠帶的一角翹起又貼回；手寫的圈在關鍵詞上補一筆；一張照片碎片慢慢下沉一點，投影跟著變小。
- 這些小動作按 12fps 步進，和「手放上去」的質感一致。

## 鏡頭語法
| 鏡頭運動 | 表達什麼 | 適合哪類內容 |
|---|---|---|
| 俯視平移過一張大桌面 | 翻閱、瀏覽 | 列表、作品牆 |
| 推近到一張紙片 | 聚焦 | 重點資訊 |
| 一隻「手」把紙片拿走 | 換頁 | 段落轉場 |

## 聲音調色盤
紙張擬音（`swipe` 加 `highpass`、`click` 做膠帶撕扯聲）、馬克筆劃線聲（帶通噪聲）；音樂用輕快的鼓、撥絃、keys。第 1 檔合成即可。

律動與和聲（舉例，不止這些）：breakbeat、shuffle 或 tresillo，帶一點手工的松（`S.swing`、`S.humanize`）；大調、Mixolydian、Dorian；`rim`、`shaker`、`cowbell` 做手工打擊樂。小房間，不側鏈。

## 原生手法
- 撕開一張紙，後面就是下一鏡：適合轉場和揭示。
- 紙片一層層蓋上去，最後拼成一張完整的海報或 logo：適合結尾。
- 手寫圈出重點：適合強調數字和賣點。

## 變化空間
- 結構：一本手賬一天的記錄；一面情緒板逐漸貼滿；一個人物的剪貼簿。
- 開場：空桌面，第一張紙落下；一卷膠帶撕開的聲音和畫面。
- 結尾：所有紙片拼成標題；鏡頭拉遠，整面牆就是一張雜誌封面。

## 坑
- 元素太多太雜就成了噪音：同時最多 5–7 個紙片在畫面裡。
- 用了沒有授權的照片和圖片：只用使用者提供的素材或程式碼畫的圖形。
- 投影太重太虛，會像廉價 PPT。
