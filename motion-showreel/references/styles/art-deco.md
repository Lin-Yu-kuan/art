# 裝飾藝術（art-deco）

> 階梯、扇面和成組的平行線圍繞一根秩序清楚的軸線展開，裝飾本身負責組織畫面。
> 參照（只學語法）：裝飾藝術建築立面、交通海報、金屬鑲嵌與漆面工藝。不照搬具體建築輪廓、海報構圖、商標和字型檔案。

## 本質 / 不是什麼

- 本質：**把機械時代的秩序變成裝飾**。重複線條有間隔，階梯有層級，軸線控制重心；圖案、字和主體像同一套建築構件，開合、升降都服從這套結構。
- 不是：給 `dark-keynote` 加一圈金邊，也不是任意黑金奢華海報。放射線和對稱不必每次出現，但幾何裝飾必須參與構圖，不能只是貼花。

## 辨識訊號：每支片子挑 2–3 個

| 訊號 | 長什麼樣 | 適合的主題 |
|---|---|---|
| 階梯輪廓 | 寬度逐級收窄的臺階、塔冠或字框 | 上升、里程碑、等級 |
| 扇形展開 | 一組扇骨從共同軸心依次張開 | 揭幕、選擇、匯聚 |
| 成束平行線 | 等距線在轉角處一起折返，形成軌道 | 交通、連線、流程 |
| 幾何鑲嵌 | 金屬細條分隔漆面、石材或純色色面 | 工藝、品牌、精密 |
| 縱向拉伸 | 高挑門洞、窄長字面、向上的分層 | 建築、雄心、紀念 |
| 偏軸海報構圖 | 主體沿斜線推進，留出清楚的標題區 | 旅行、速度、現代生活 |
| 巢狀拱門 | 門框套著門框，尺度向內遞減 | 進入、層次、探索 |
| 角部折線 | 直角、倒角和短折線約束邊界 | 名牌、證書、資訊分割槽 |
| 幾何植物 | 葉片、羽毛被整理成重複的扇面與弧段 | 自然、生活方式、季節 |
| 拉絲定向反光 | 金屬條只沿同一工藝方向出現窄反光 | 質感、產品、細節 |

規則：

- 每支挑 2–3 個，至少一個不在下面「最俗的版本」裡；訊號從主題裡選。
- 先定主軸、比例和留白，再放裝飾。同一層級的線寬與間距保持一致，不要求全片左右映象。

## 這個風格最俗的版本

- 畫面：黑底金線、正中日芒、兩邊對稱扇面，門開啟後出現寬字距標題，最後撒金粉。
- 聲音：大樂隊銅管齊奏，開門必配鑔片，落版必來一次盛大的和絃。
- brief 的 style 一欄寫明翻掉了哪幾條，或者為什麼保留經典版。可以從交通海報的斜向速度、淺色漆面或區域性鑲嵌入手。

## 適配

- 用途：品牌宣傳、活動片頭、Logo 演繹、作品集章節、里程碑展示。
- 內容：建築、交通、工藝、文化活動，以及希望表現秩序和儀式感的現代品牌。
- 不適合：密集操作教學、需要大量長句的說明，或靠隨意手繪和自然鬆弛成立的主題。

## 技術路線

- **圖形與排版**：SVG 或 Canvas 適合階梯、扇面、平行線與遮罩。可考慮 Paper.js 整理重複路徑和曲線交接，先驗證幾何節奏，再加表面質感。
- **金屬與漆面**：以平面海報為主時，可探索 Canvas 漸變或 PixiJS 的區域性材質遮罩。需要門框厚度、鑲條側面和移動高光時，再考慮 Three.js。
- **運動組織**：按構件分組處理軸心、軌道與開合方向；庫可以輔助幾何和插值，不把庫的即時播放狀態作為幀依據。
- 同一時刻獨立還原所有構件的位置與光照，拉絲紋理固定種子。細金屬線先在最終尺寸下檢查；`--dpr` 視邊緣質量增加，`--subframes` 從低值試起，`--grain` 只在確有印刷或漆面需要時加入。

以上是候選方向，不規定幾何生成演算法、材質實現或庫的組合。

## 材質與渲染

- 工藝依據：金屬鑲條、漆面和石材各有邊界。先建立分割槽，再決定哪一塊有反光；整屏統一金屬漸變會把鑲嵌變成塑膠貼紙。
- 金屬條寬窄有層級，轉角連線乾淨；交叉位置明確誰連續、誰截止，避免線頭互相穿出。
- 漆面保留大塊平整暗面，反光少而寬；拉絲金屬的紋理方向隨構件走。印刷版本則用平面墨色，不必模擬真實金屬。
- 高光由光源與表面方向決定。同一扇門上的鑲條共同響應，不能每一根線各自掃光。
- 主體或 Logo 也按幾何結構整理輪廓；有官方品牌資產時保留其形狀，把裝飾放在承托結構上。

## 配色

下面的色值是示例，看思路，不要原樣照抄。

- 深漆與黃銅：底 `#162C2A` / 金屬 `#C4A064` / 字 `#F3E9D5`。
- 象牙與硃砂：底 `#EEE3CC` / 主色 `#963F32` / 深線 `#263C42`。
- 午夜與銀色：底 `#18243B` / 主色 `#BFC6D0` / 強調 `#93714F`。
- 推導：從品牌取一個主色，配大面積穩定底色，再給線與字足夠反差。金銀只佔結構中的少量位置；淺底、啞光或無金屬版本同樣成立。

## 字型

英文展示可選 Poiret One、Josefin Sans，輔助用 Jost；中文用思源黑體或思源宋體，自託管 OFL 字型。展示字可稍放寬字距，正文保持正常閱讀密度。細字型放大用，標籤用較實的字重；幾何字框不能壓住文字的呼吸空間。

## 運動

- 階梯沿同一方向逐級抬升，扇面圍繞明確的軸心張開，軌道里的線勻速通過轉角。構件有機械行程，停下時乾淨。
- 主動作用平穩加速和短減速，允許一組構件有小幅錯時。避免所有裝飾各自彈跳，把有秩序的組合拆散。
- 進場可由遮擋、升降或套疊完成；離場順著已建立的軌道收回，也可保持框架只更換內容。

## 畫面怎麼活

- 落版以靜為主，標題和框架穩定，允許一束窄反光緩慢經過一條金屬邊。
- 有機械主題時，一小組扇骨或刻度做低幅往復，運動範圍不跨進閱讀區。
- 印刷海報版本可以完全靜止，靠區域性切換重心延續節奏；紙紋和墨色不用持續抖動。

## 鏡頭語法

| 鏡頭運動 | 表達什麼 | 適合哪類內容 |
|---|---|---|
| 正面固定，構件開合 | 儀式與秩序 | 片頭、Logo、資訊揭示 |
| 沿縱軸緩慢上移 | 層級與上升 | 里程碑、建築、成長 |
| 順斜向主線平移 | 速度與目的地 | 交通、旅行、連線 |
| 從鑲嵌區域性拉遠 | 工藝組成整體 | 品牌、產品細節 |

## 聲音調色盤

第 1 檔可用短撥絃、圓潤貝斯、輕手鼓和少量金屬敲擊，表達構件的開合與落位。需要銅管、簧管或刷鼓質感時，用第 2 檔 Tone.js 配合授權取樣；不要用刺耳的合成短音冒充真實銅管。反光不必配音，聲音優先跟結構變化。有口播時減少中頻齊奏。

律動與和聲（舉例，不止這些）：輕快的切分與搖擺、莊重的慢速和絃，或平直剋制的現代電子節奏。年代感由畫面和配器共同決定，不強制每支都做爵士派對。

## 原生手法

- 扇面或套門圍繞主軸展開，露出內容：適合揭幕、片頭（經典）。
- 平行鑲條從邊框轉成道路或連線線：適合交通、組織關係和服務網路。
- 階梯輪廓逐層改變寬度，構成下一組圖形：適合等級、成長和階段推進。
- 斜向海報裡的速度線收攏成題簽邊界：適合從過程切到結論。
- 同一構圖在平面印刷與淺浮雕之間切換：適合工藝、材質版本或品牌細節。

## 變化空間

- 結構：圍繞一根軸線逐層揭示；沿斜向路線穿過幾個主題；同一框架比較不同版本。
- 開場：先見偏角的一段鑲條；大色面中出現一個階梯缺口；主體已經在場，裝飾隨後響應。
- 結尾：保留完整的幾何名牌；裝飾退到角部讓內容居前；沿最後一條軌道自然接回開場。

## 坑

- 去掉金色就認不出風格：先用單色檢查階梯、線束和比例是否成立。
- 裝飾比主體複雜：降低裝飾層級，讓觀眾先看內容，再看工藝。
- 所有鏡頭強制居中對稱：允許斜向和偏軸構圖，靠重複比例維持一致。
- 線寬隨縮放忽粗忽細：明確哪些屬於真實構件、哪些屬於平面版式，分別處理。
- 大片發光和金粉遮住幾何關係：控制高光範圍，保住暗面與硬邊。
- 標題字距過大、中文被橫向壓縮：用合適字型與留白調整，不拉壞字形。
