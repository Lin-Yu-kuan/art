# 預設剪輯工作區

所有制作預設先在這裡預覽、調整獨立音軌，使用者確認當前預覽通過後再生成 MP4。Agent 應主動啟動服務並開啟工作區；不能開啟瀏覽器時提供本機連結，等待使用者反饋。無聲、無口播、短片、循環片都適用，長片按下方說明逐章預覽。無需使用者額外要求開啟編輯器，也不預設生成代理 MP4。

使用者點選「匯出影片」或在對話中說當前版本可以匯出，即為匯出確認；不再重複詢問。修改內容後應讓使用者復看。使用者明確要求跳過預覽、直接匯出時可按其指示執行並記錄。原有 `preview.mjs` 用於輕量除錯，`build.sh`、分章構建與驗收繼續作為確認後的匯出工具，動畫與聲音的實現不變。

使用者在需求階段表示希望看製作過程時，提前以 `--progress` 開啟同一入口，逐階段釋出風格幀、音色短樣和可播放成果；見 [`progress.md`](progress.md)。製作階段只讀，最終短片釋出 `review --final` 後仍在此頁確認與匯出。未提出時保留本文的預設最終預覽流程。

## 開啟已有專案

```sh
node <skill>/scripts/editor.mjs <project> --size 1920x1080 --fps 30
```

開啟終端輸出的本機網址。尺寸、幀率必須與本片確認規格相同。時長讀取專案 `timeline.js` 的 `DUR`，也可用 `--duration <seconds>` 或 `editor.json` 的 `duration` 指定；場景實際 `window.DUR` 不一致時會提示錯誤。無需先渲染 MP4，也不呼叫 TTS 或合成配樂。專案沒有音訊時可以無聲預覽。

可用 `--audio audio/final.wav` 明確原始混音。已有匯出質量設定可傳 `--workers`、`--subframes`、`--shutter`、`--dpr`、`--grain`、`--crf`；即時預覽不模擬匯出器的子幀混合、DPR 超取樣或 ffmpeg 顆粒，介面會提示。不要聲稱這幾項已經逐像素匹配。

## 工作區佈局

畫面和時間線共用一個工作區。預設收起調音與製作進度，給畫面留出空間；需要時用頂欄按鈕開啟。預覽工具條支援適應視窗、比例縮放、放大後拖動、Ctrl/⌘ 滾輪縮放和最大化，Esc 還原。拖動畫面與時間線之間的橫向分隔條可分配上下空間；分隔條也支援方向鍵與雙擊復位，軌道較多時在時間線內部滾動。所有顯示操作只改變預覽佈局，保留原場景尺寸、時間軸與匯出引數。

## 第一版支援的操作

- 原場景在固定寬高的獨立 iframe 內運行同一個 `render(t)`。畫面軌顯示 `SHOTS`，播放頭可拖動，支援逐幀、時間線縮放與循環試聽選區。複雜場景可能即時掉幀，不改變離線匯出的幀數。
- 真實音訊波形，按專案原始檔生成並快取；口播、BGM、音效分別顯示。靜音、音軌增益會計入匯出；增益調的是軌間比例，編輯後的最終混音仍按原驗收標準統一到 −14 LUFS。
- BGM 和音效片段可拖動、切分、裁剪、移除，設定源入點、時長、片段增益和淡入淡出。切分點在淡入淡出區間內時會提示調整，避免切分意外改變聲音包絡。片段之間允許重疊，重疊處相加。
- 口播與已有整段混音的時間位置鎖定，可調增益或靜音，不能剪字、移動或改變速度。畫面、字幕和語義時間戳保持繫結。循環選區只用於試聽，不裁切最終匯出。
- 撤銷、重做、自動儲存和重新整理恢復。儲存檔案為 `.showreel-editor/session.json`，不修改動畫、使用者原稿或音訊；源音訊變化後不會自動套用舊編輯。原檔案及舊會話保留在磁碟。
- 音訊有改動後點選「更新試聽」，或直接播放時自動更新。只重新混音，不渲染影片；播放的是匯出將使用的同一份 WAV，不使用另一套近似的瀏覽器混音。長片混音仍需要等待，結果按編輯內容和原始檔簽名快取。

## 音軌從哪裡來

優先讀取專案根目錄 `editor.json` 的明確軌道配置；否則讀取 `audio/mix.json` 的各輸入軌、增益和人聲避讓區間。新生成的 mix 記錄會附帶增益，舊記錄未記錄增益時介面會說明預設值，必要時用 `editor.json` 填入原值。**未編輯狀態始終直接播放原始最終混音，不重新處理它。**

只有 `audio/final.wav` 或合成後的 `audio/music.wav` 時，按一條已混合軌顯示，不能聲稱能恢復獨立口播、BGM 或音效。可在生成音訊時保留獨立檔案，再顯式配置：

```json
{
  "duration": 60,
  "size": "1920x1080",
  "audio": "audio/final.wav",
  "tracks": [
    {"id": "voice", "kind": "voice", "file": "audio/narration.wav", "gain": 1},
    {"id": "bgm", "kind": "bgm", "file": "audio/bgm.wav", "gain": 0.35},
    {"id": "sfx", "kind": "sfx", "file": "audio/sfx.wav", "gain": 0.5}
  ]
}
```

軌道類型為 `voice`、`bgm`、`sfx`、`mix`，路徑相對專案目錄。內建合成器的 `audio.mjs build score.mjs --stems` 可匯出匯流排分軌，但匯流排不必等同於 BGM/SFX，混響與母帶也可能集中在總混音；須按真實內容配置，不能把分軌相加就宣稱還原原混音。工作區最多 32 軌、256 個音訊片段。

第一版針對單個 `render(t)` 頁面，多頁面長片先逐章開啟工作區預覽、檢查相鄰章節的承接，使用者確認後才執行原章節構建器；不假稱支援整片跨頁面連播或自動彙總多章音訊編輯。同一頁面的不同區間構成多章時，開啟該頁面，用循環選區定位各章，不通過縮短 `--duration` 改變場景時長。工作區中的聲音修改必須同步到實際匯出所使用的混音及校驗記錄，不能在長片拼接時丟回原混音；具體見 `long-form.md`。

## 匯出與相容

介面中只有點選「匯出影片」才啟動原來的 `render.mjs`，先檢查確定性，匯出後執行完整規格的 `inspect.mjs qa`，並生成文字審片材料。階段、實際幀進度和錯誤在介面顯示，支援取消；失敗或取消的任務不會發布成片。使用者在對話中確認匯出時，Agent 可操作該按鈕；未在工作區編輯聲音時，也可呼叫已確認規格的原構建命令。影像仍需按 `review.md` 審片，技術驗收不替代使用者終審。

輸出為新的 `out/editor-<task-id>.mp4`，不會覆蓋 `out/final.mp4`。該任務使用的編輯快照、驗收與審片材料儲存在 `.showreel-editor/exports/<task-id>/`。原有 `build.sh` 不自動讀取工作區編輯；重建該編輯版應在工作區再次匯出。要把編輯混音用於其他構建，須同時同步音訊路徑和有效混音校驗記錄；僅改 `AUDIO_FILE` 會與原 `audio/mix.json` 不匹配，不能跳過校驗。

工作區匯出會將專案的 `timeline.js` 顯式交給驗收工具，保留 `SHOTS`、`HOLDS` 和 `DROPS` 的審片依據。驗收輸出儲存在任務目錄的 `qa.log`，`receipt.json` 記錄日誌位置及是否使用了時間軸；沒有時間軸的舊專案仍可按原方式匯出。

服務僅監聽本機，關閉終端服務後停止訪問。原始檔、程式碼和編輯記錄均留在專案目錄，無遠端賬號或新 npm 包。迴歸測試：

```sh
node --test <skill>/scripts/test/editor-model.test.mjs <skill>/scripts/test/editor.test.mjs
```
