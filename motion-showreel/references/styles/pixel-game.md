# 16-bit 像素遊戲（pixel-game）

> 所有東西畫在一塊很小的邏輯畫布上，整數倍放大；角色姿勢一頓一頓地變，特效每幀都在動，像一段精緻的 16-bit 遊戲動畫。
> 參照（只學語法）：SNES / MD 時代的角色動畫和過場、現代像素遊戲的光影。不照搬任何遊戲的角色、關卡和 UI。

## 本質 / 不是什麼
- 本質：**低邏輯解析度**（128×96、160×90、320×180）+ **固定調色盤** + **姿勢步進**（每秒 8–12 張）+ 特效逐幀；每個像素都清清楚楚。
- 不是：縮小後放大的模糊向量圖；也不是把照片加個像素化濾鏡。

## 辨識訊號：每支片子挑 2–3 個
| 訊號 | 長什麼樣 | 適合的主題 |
|---|---|---|
| 角色動作 | 待機、奔跑、蓄力、釋放，每秒 8–12 張姿勢 | 能力、行動 |
| 橫版卷軸關卡 | 平台、磚塊、視差背景向後滾 | 旅程、挑戰 |
| 俯視 RPG | 格子地圖、對話框逐字出現 | 敘事、探索 |
| HUD | 血條、分數、心形、計時器 | 資料、進度 |
| 戰鬥特效 | 閃光、爆點、傷害數字跳出 | 衝擊、對比 |
| 物品欄與升級 | 道具格子、等級提升的閃光 | 功能、成長 |
| 標題畫面 | PRESS START、選單遊標、存檔槽 | 開場、結尾 |
| 世界地圖 | 小路連起一個個關卡點 | 路線圖、階段 |
| 像素字型介面 | 對話框、按鈕、像素字 | 文案、說明 |
| 掌機四色 | 只有四個灰綠色階的 1-bit / 2-bit 畫面 | 懷舊、極簡 |
| 等距像素 | 等距視角的小房間或小鎮 | 空間、場景 |

規則：
- 每支挑 2–3 個，至少一個不在下面「最俗的版本」裡。
- 訊號從主題裡選，不按順序全上。
- 低解析度、固定調色盤、姿勢步進是這種風格的約束，選了就要守；訊號挑的是畫什麼、按什麼遊戲類型講。

## 這個風格最俗的版本
- 畫面：紫藍夜空、一個小人跳進畫面、頂磚出金幣、結尾「GAME OVER」或「PRESS START」。
- 聲音：方波晶片旋律、跳躍聲、金幣叮。
- brief 的 style 一欄寫明這支片子翻掉了哪幾條，或者為什麼刻意保留（比如使用者要的就是經典版）。保留時，把力氣花在構圖、鏡頭、節奏或一個意外的記憶點上。

## 適配
- 用途：作品集、循環動圖、Logo 演繹、遊戲化的產品宣傳。
- 內容：遊戲、懷舊、開發者文化、可愛的角色、魔法 / 冒險隱喻。

## 技術路線
離屏 Canvas（邏輯解析度）畫好每一幀，再用 `drawImage` 按最大整數倍放大到顯示畫布，`imageSmoothingEnabled = false`、CSS `image-rendering: pixelated`。所有座標 `Math.round`。需要 CRT 感時疊加 `crt-vhs.md` 的著色器。不要 `--grain`、不要 `--dpr`。

## 材質與渲染
- 角色用填充矩形和像素串程式化地拼（例如 24×32 像素的角色），姿勢做成引數（手臂角度、身體起伏、道具角度），每幀把引數量化到網格。
- 不用漸變、`shadowBlur`、半透明；陰影和高光都是調色盤裡的色塊。
- 輪廓光：主光源給角色描 1 像素的亮邊。
- 粒子：預先按序號生成的像素點（確定性），出生和死亡由時間計算。

## 配色
下面的色值是示例，看思路，不要原樣照抄。
- 固定 16–32 色：夜空 `#0D0B1E` `#1E1A3A` `#2E2860`，暖色角色 `#C9563C` `#E8A54B` `#F4D58D`，魔法色 `#4FD8FF` `#B77CFF` `#FFF1A8`，地面 `#3B3A4A` `#5B5A6B`。
- 規則：畫面裡每一個像素都來自這組顏色；需要「漸變」時用抖動（dithering）。
- 推導：先定一組 16–32 色的調色盤，從主題來：夜景、森林、沙漠、掌機四色、品牌色推出來的色階都行；畫面裡每個像素都只來自這組顏色。紫藍夜空加暖色角色是最常見的那組。

## 字型
像素字型（Press Start 2P、Silkscreen、Pixelify Sans，OFL）；中文用點陣圖風格的字型，或者在邏輯畫布上用 ≥ 18px 的字按 alpha 閾值轉成硬邊像素。

## 運動
- `stepped(t, 10)` 量化角色姿勢，引數在關鍵幀之間用緩動過渡，但取值時按步進幀取樣。
- 特效（火花、飛彈、閃光）每幀都動。
- 用狀態機組織：待機 → 蓄力 → 釋放 → 收招 → 循環。
- **鏡頭和光照保持每幀平滑**，否則看起來像掉幀。

## 畫面怎麼活
- 角色待機動畫（兩幀呼吸、眨眼）；HUD 的心形或分數閃；背景裡的水、火把、雲按 4–8fps 步進循環；問號塊隔一會兒頂一下。
- 小循環步進，鏡頭仍然每幀平滑。

## 鏡頭語法
| 鏡頭運動 | 表達什麼 | 適合哪類內容 |
|---|---|---|
| 整像素橫向卷軸 | 前進、旅程 | 關卡式敘事 |
| 撞擊時震屏 1–2 邏輯像素 | 力量 | 釋放、命中 |
| 切換到特寫（換一塊更小的邏輯區域） | 強調 | 關鍵道具、表情 |
| 黑場圓形收縮（iris） | 結束、轉場 | 段落切換 |

## 聲音調色盤
晶片音樂：方波旋律（`lead({ wave: 'square' })`）、方波或三角波低音、噪聲鼓（短 `hat`、`snare`），`blip`、`glitch`、上滑的 `pop`。BPM 130–160。第 1 檔合成最合適。

律動與和聲（舉例，不止這些）：直拍 130–160，也可以 shuffle（RPG 村莊）或 6/8；大調、Mixolydian（冒險）、和聲小調（Boss 戰）、♭VI – ♭VII – I（通關）。晶片感用 bus 的 `crush: 4–6`、`crushRate: 11000–22000`，幹聲。

## 原生手法
- 蓄力粒子螺旋聚攏 → 釋放閃光：適合「能力」「爆發」。
- 像素塊溶解成下一鏡：適合轉場。
- 一個年代一個解析度（從 64 像素到 320 像素）：適合進化、歷史主題。

## 變化空間
- 結構：一個角色的一次施法；一關微型關卡；一個物品的升級路線。
- 開場：黑屏中一個像素亮起；角色從畫外跳進來。
- 結尾：無縫循環回待機；分數板 / 存檔畫面裡出現 logo。

## 坑
- 亞像素位置導致邊緣發虛：所有繪製座標取整。
- 中文筆畫糊成一團。
- 鏡頭也步進了，畫面像卡頓。
