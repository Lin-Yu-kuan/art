# 驚豔手法庫

這份檔案回答一個問題：**為什麼有的程式碼影片讓人「哇」，有的只是「能動」？**

> 這裡寫的是**預設做法**，不是每支片子都要遵守的規定。所選風格（`styles/<slug>.md`）和內容優先：瑞士編輯風不用回彈彈簧，生成抽象可以固定機位、勻速旋轉，安靜的片子變化本來就少。全域底線只有 SKILL.md 裡那幾條。內容來自對 Opus 5.5 釋出後公開傳播的程式碼影片（動效作品集、UI 變形、遊戲史短片、產品宣傳片、像素動畫等）的拆解，再加上動態設計行業的通用方法。

## 連續敘事：讓內容在鏡頭裡發生

適用於講解、產品演示和敘事片；Logo、動態排版、循環、刻意靜止的風格按自身語法制作。風格庫只決定畫面語言，不決定每段的故事或版式。

分鏡先解決以下問題，再選擇轉場和特效：

- **變化**：這一段要讓觀眾看懂什麼變化？用物件的移動、形變、組合、拆分、關係或數量變化呈現；文字用來命名和解釋，避免只有標題卡換頁。
- **承接**：下一鏡從上一鏡繼承哪個主體、位置、方向或圖形關係？在場景需要時保留物件身份與空間線索，別每句清空舞臺重擺一遍。
- **運動**：主動作有起因、過程與結果。跨句或跨鏡延續的軌跡使用統一時間，不重啟動畫；接縫要看位置、尺度、方向和速度是否意外跳變。涉及接觸或釋放時，再檢查接觸點、輪廓與旋轉是否銜接。自然停頓可以落定，不要求全片勻速漂浮。
- **同步**：一個關鍵變化、相應鏡頭和音效引用同一個事件。口播句段只是錨點，不是切鏡表；詞級事件須有真實詞時間或人工錨點，缺少時明確降級為句級。

示意資料、物理類比或機制動畫必須忠實於使用者內容，不從參考作品搬用主題、角色、文案、配色或場景。涉及事即時，圖形不能暗示原稿沒有的結論。

連續動作核心的專案，在風格確認時連同靜幀交一段 6–10 秒動作預演（短於 6 秒的片子用全片）；製作時用同一個 `render(t)` 做帶聲音預覽，檢查實際變化、主體承接和節奏。抽幀用於構圖、連續小樣用於運動，兩者都要看。暫時隱藏字幕後檢查物件的行為是否還能被理解，可幫助發現只有文字換頁的問題；這只是講解片的審片方法，不對動態排版或靜態風格強制使用。

**別用偽運動補空白**：背景噪聲、粒子、呼吸光和無目的推鏡不能替代資訊發展；加模糊或改成 60fps 也不能修復靜態卡片輪播。先改分鏡與物件狀態，再調整緩動、跟隨、拖影和幀率。

## 1. 驚豔公式

**上限來自對標，不來自規則。**動筆前先為這支片子挑 1–2 個對標作品，寫下學什麼、不學什麼（SKILL.md 第 2 步）。下面的公式和手法是幫你把對標的水準落到程式碼裡的工具。


觀眾在資訊流裡給你 1 秒。留住他們的，是**意外但合理**的運動。拆開看通常有四個因素（權重隨風格變化，安靜的風格里密度可以很低）：

| 乘數 | 0 分的樣子 | 10 分的樣子 |
|---|---|---|
| 變化密度 | 一個畫面放 3 秒，元素慢慢淡入 | 每一拍都有東西變形、進場、切換，眼睛一直有事可做 |
| 運動質感 | 勻速平移、所有元素同時出現 | 彈簧落定、預備動作、過沖、錯峰跟隨、快速運動帶拖影 |
| 簽名時刻 | 每段的強度都差不多 | 有一個瞬間讓人想倒回去看：「這是怎麼做到的？」 |
| 音畫同步 | 背景音樂和畫面各走各的 | 撞擊、切點、重拍、音效都在同一幀上 |

**統一性是隱藏的第五項**：手法再多，只要顏色、字型、運動性格保持一致，看起來就是「一個作品」；一旦不統一，就成了「模板合集」。

## 2. 節奏結構：時長模板

無口播的音樂片先定 BPM，再把結構排在小節上。120 BPM 下 1 拍 = 0.5 秒，1 小節 = 2 秒；128 BPM 下 1 小節 = 1.875 秒。有口播時先定語義動作和真即時間，音樂配合講述；下列小節模板不約束口播鏡頭。

### 15 秒（8 小節 @ 128 BPM ≈ 15 秒，或 8 小節 @ 120 BPM = 16 秒）

| 小節 | 段落 | 做什麼 |
|---|---|---|
| 1 | **Hook** | 第 0 幀就在動。一個強烈的圖形動作（點炸開成線、字砸進畫面、形狀變形） |
| 2–3 | **建立** | 視覺系統亮相：配色、字型、運動性格。每拍一個變化 |
| 4–5 | **加速** | 切點變密（每拍 → 每半拍），鏡頭開始推，元素變多 |
| 5 末 | **吸氣** | 最後一拍留空或降速（riser 聲上升、畫面縮成一個點或停住） |
| 6–7 | **Drop / 簽名時刻** | 全片最強的一下：反色、撞擊、鏡頭急推、粒子組字、大變形 |
| 8 | **落版** | 定格到 logo 或一句話，或者無縫回到第 0 幀 |

### 6 秒（Logo sting / 社交平台 bumper）
預備（0–1 秒）→ 爆發（1–2.5 秒）→ 形成（2.5–4.5 秒）→ 定格（4.5–6 秒）。整個片子只有一個想法。

### 30 秒（16 小節 @ 128 BPM）
Hook（1 小節）→ 第一段（4 小節）→ 小高潮（1 小節）→ 第二段（換一種視覺手法，4 小節）→ 吸氣（1 小節）→ Drop（3 小節）→ 落版（2 小節）。一定要有**兩種不同的速度**，30 秒全程同一個速度會讓人疲勞。

### 加速：段落變短，速度不變
想讓片子越來越急，不用提 BPM。BPM 不動，每段佔的拍數一段比一段少，比如 6 → 4 → 4 → 3 → 2 → 1 → 1（單位是八分音符或拍），最後一段放長，給落版或笑點留位置。轉場時長、計數器的滾動時長也跟著縮。音樂從頭到尾是同一個速度，聽感和看感卻一路收緊。排法：先列出每段想要的時長，取整到網格，再整體調成有規律的遞減。拿參考片跑 `inspect.mjs grid`，輸出裡 `segment lengths in steps` 那一行就是它的段長序列。

### 循環（Loop，4–12 秒）
沒有開頭和結尾，最後一幀 = 第一幀（位置、速度、方向都一樣）。結構是「一次完整的呼吸」：聚 → 散 → 聚。

## 3. 變化密度與呼吸

- **作品集、宣傳短片這類快節奏用途**：預設每 0.5–1 拍有一個可見變化；敘事感強或安靜的風格可以放寬到每 1–2 小節。沒有設計意圖卻超過 1 秒完全不動的段落，就是「空拍」。`inspect.mjs motion` 會把它找出來。
- **變化有大小之分**：重拍放大變化（切鏡頭、變形、反色），拍點放中變化（元素進場、位移），八分 / 十六分音符放微變化（閃爍、小抖動、計數器跳字）。三層疊在一起，畫面才有層次，而不是一直在「鬧」。
- **呼吸是刻意設計的例外**：drop 前的半拍到一拍空白、簽名時刻之後的一次慢鏡頭，都是為了讓下一個衝擊更強。沒有呼吸的片子，聽起來就像一直開著最大音量。
- **一次只突出一件事**：同一時刻最多一個主運動，其他元素要麼靜止，要麼跟隨。眼睛追不過來的運動等於沒有運動。
- **停留的鏡頭也可以是活的**：主過程仍在發展時保留必要運動；風格需要時可加少量材質或狀態循環，幅度比主動作低一檔。循環要有作用，不為湊運動指標新增漂浮、光點或噪聲。每個風格檔案的「畫面怎麼活」可作參考；安靜的風格允許靜止，`HOLDS` 裡宣告意圖即可。
- **量一下**：`inspect.mjs motion`（`qa` 也會帶上）按鏡頭報出畫面變化的比例、完全不動的幀步佔比和突然的跳變。數字只是線索：瑞士編輯風的落版本來就不動，像素風本來就一幀動一幀停。

## 4. 運動質感

### 4.1 彈簧和緩動（預設）
預設情況下，尺寸、位置、圓角的變化用閉式彈簧（`motion.js` 的 `spring` / `springTo`），引數一旦定下就是這支片子的「運動性格」：

| 用途 | 手感 | `{ freq, damp }` |
|---|---|---|
| 按鈕、開關、指示條前沿 | 快、利落 | `{ 3.6, 0.8 }` |
| 卡片、容器、鏡頭 | 預設 | `{ 2.4, 0.75 }` |
| 大字、3D 物體、Logo 定版 | 沉穩，幾乎不回彈 | `{ 1.6, 0.95 }` |
| 吉祥物、貼紙、俏皮元素 | 明顯回彈 | `{ 2.8, 0.45 }` |

同類元素用同一檔。例外：瑞士編輯風用 `snap`、不回彈；像素風按步進；生成抽象和循環裡的勻速旋轉是對的。一個值要多次改變目標時用 `springTo` 的疊加寫法，不要重啟彈簧，這樣動作是連續的，任意一幀也能單獨算出來。

### 4.2 緩動曲線
不用彈簧的地方也別用 `linear` 或者到處 `inOutCubic`。常用三條：`snap`（硬起步、長滑行：版式跳變、擦除）、`glide`（≈ outExpo：到達、鏡頭落定）、`whip`（甩鏡、硬切過渡）。**離場比進場快**：進場 0.4–0.6 秒，離場 0.2–0.3 秒。

### 4.3 動畫的十二法則，挑最有用的四條
- **預備（anticipation）**：大動作之前先往反方向收一點（縮小 5%、後退幾像素），時長約主動作的 1/4。
- **過沖與落定（overshoot / settle）**：交給彈簧去做。
- **跟隨與重疊（follow-through / overlap）**：一組元素錯峰出發（`stagger`，30–60 毫秒一個），從中心向外或者沿著閱讀方向。
- **擠壓與拉伸（squash & stretch）**：快速移動的條狀元素，前沿和後沿用兩個不同的彈簧（前沿快、後沿慢），移動時自然就被拉長（見 recipes.md 的「前後沿」）。這是高階 UI 動效最常見的手法。

### 4.4 運動模糊與拖影
快速運動沒有模糊會顯得「卡」，像幻燈片。兩種做法：
- 渲染引數 `--subframes 4`（每幀 4 個子幀混合，180° 快門），對所有運動都生效，代價是渲染時間 × 4。
- 只在快速運動的元素上畫「拖影」：沿速度方向複製 3–5 份遞減透明度，或者在形變時臨時拉長。成本低，可控性更強。

### 4.5 步進動畫（on twos）
像素、賽璐璐、定格、手繪風格：角色姿勢用 `stepped(t, 12)` 量化到每秒 8–12 張，**但鏡頭和光照保持每幀平滑**。鏡頭也步進的話，看起來就是掉幀。

## 5. 轉場語法

轉場是作品集類影片最見功力的地方。**規則：下一個畫面要從上一個畫面裡的某個元素「長」出來。**整支片子選 2–3 種轉場，統一成一套語法。

| 轉場 | 怎麼做 | 適合 |
|---|---|---|
| **形狀變形**（morph） | 同一個元素改變尺寸、圓角、顏色，變成下一個狀態（按鈕 → 載入圈 → 對勾 → 卡片） | UI 動效、產品功能串聯，「一鏡到底」 |
| **匹配剪輯**（match cut） | 上一鏡的圓 = 下一鏡的太陽 / 鏡頭 / 句號；上一鏡的線 = 下一鏡的地平線 | 敘事和比喻 |
| **穿越**（zoom-through） | 鏡頭急推進一個字母的孔、一個按鈕、一個像素，裡面就是下一個場景 | 能量很強，適合放在 drop |
| **遮罩擦除**（shape wipe） | 用場景裡的形狀（大字、色塊、斜線）當遮罩，掃過畫面露出下一鏡 | 排版類、品牌類 |
| **甩鏡**（whip pan） | 鏡頭在 4–6 幀內橫甩，疊加方向性運動模糊，落到下一鏡 | 快節奏、換段落 |
| **色塊淹沒**（color flood） | 強調色從一個點擴散鋪滿畫面，再退開露出下一鏡 | 反色 drop、切換色調 |
| **切片 / 百葉**（slice） | 畫面切成 N 條，錯峰滑走 | 編輯感、雜誌感 |
| **文字即視窗**（type as window） | 巨大的字裡面是下一鏡的畫面，字放大到出畫 | 片頭、標題 |
| **像素化 / 溶解**（shader dissolve） | 著色器按噪聲閾值溶解，或者像素塊放大後再縮回 | 復古、科技、故障風 |
| **無限縮放**（infinite zoom） | 每一層畫面的某個細節就是下一層的全景 | 簽名時刻 |

避免把交叉淡化當作所有鏡頭的預設銜接。音樂卡點片可讓硬切落在重拍；口播片按語義和注意力轉移決定切點，硬切不必配撞擊聲，不在每個句號後強行轉場。

**揭開的那一幀落在拍上。**轉場從拍點開始的話，新畫面往往要過幾幀才露出來，觀眾會覺得聲音先到、畫面後到。所以要倒著排：先看新畫面在轉場進行到多少時第一次露出來（擦除幾乎是 0，光圈展開可能是 0.3），轉場起點等於拍點減去這段時間，用 `timeline.js` 的 `revealOn(hit, dur, reveal)` 算（recipes.md 第 14 節）。拍點那一幀要有整屏看得出的變化。鏡頭衝擊（放大 2–4% 再彈回）加在整個舞臺上，新舊兩層一起衝；只衝新層的話，新層還沒露出來，那一下就落空了。

**複雜轉場給夠時長。**緩入緩出的兩頭幾乎看不出變化，0.3 秒的簽名轉場，觀眾只讀到中間那 0.2 秒，會當成普通擦除。形狀越複雜，時長越長（0.45–0.6 秒），渲完用 `inspect.mjs strip --at` 看連續幀確認。

**換風格、換媒介的轉場，借下一個風格自己的材料。**年代回顧、媒介混搭這類片子裡，轉場的樣子最好由下一個風格「怎麼出現」來定：墨會洇開，紙會被掃進來，像素會一格格點亮，膠片會燒邊，霓虹燈管會通電閃兩下。做法：
1. 找到新風格里負責出現、點亮或鋪開的那個物理過程；
2. 先用這個過程侵蝕舊畫面（舊畫被墨吃掉、被掃描線壓暗、被紙邊蓋住）；
3. 新畫面從這個過程的形狀裡露出來，起點放在畫面裡某個物體上（主角、一個點、一個字母）；
4. 揭開那一幀對拍，加一下短暫的高亮或過沖。
這樣一個轉場同時告別了舊風格、預告了新風格，通用擦除做不到這一點。每個風格檔案「原生手法」裡寫的轉場，就是這條的現成答案。

## 6. 鏡頭

2D 畫面一樣有鏡頭。用一個虛擬相機矩陣（`motion.js` 的 `camera`：中心、縮放、旋轉）統一控制，**所有跟隨主體的效果都經過同一個世界座標 → 螢幕座標的函式**，不要手寫螢幕座標。

| 運動 | 表達 | 寫法要點 |
|---|---|---|
| 慢推（push in） | 聚焦、緊張感上升 | 縮放 1.0 → 1.08，整段持續，`inOutSine` |
| 急推（crash zoom） | 衝擊、強調 | 4–8 幀內縮放 ×1.5–3，配撞擊聲和震屏 |
| 拉遠揭示（pull out） | 尺度、全貌、「原來是這樣」 | 從細節拉到全景，簽名時刻常用 |
| 旋轉（dutch / roll） | 動感、失衡 | 不超過 ±8°，用彈簧回正 |
| 視差（parallax） | 深度 | 前景、中景、背景按不同係數移動（1.4 / 1.0 / 0.6） |
| 跟隨（follow） | 主體在運動 | 相機用比主體慢一檔的彈簧追，帶一點滯後 |
| 震屏（shake） | 撞擊 | `shake(t, hits)`，衰減 0.2–0.3 秒，幅度 8–20px |
| 焦點轉移（rack focus） | 注意力從 A 轉到 B | 對非焦點層做模糊（Canvas `filter: blur()` 或 WebGL） |

**快節奏用途裡，主體在關鍵時刻通常要佔畫面高度的 1/3 以上。**Opus 沒有鏡頭指令時會預設固定機位、主體偏小，所以要在分鏡裡寫明鏡頭。固定機位也可以是一種風格選擇（瑞士編輯、生成抽象），但要是有意為之。

## 7. 動態排版

- **極端的尺寸對比**：巨大的字（畫面高度的 20–40%）配極小的技術註釋（12–16px 等寬字），比所有字都中等大小要高階得多。
- **一屏一句**：同一時刻最多 5–7 個詞（中文約 12 個字）。每段文字至少停留：英文 字母數 ÷ 15 + 1.5 秒，中文 字數 ÷ 4.5 + 1.5 秒（在它完全顯示之後才開始計時）。快節奏靠的是**減少字數**，不是壓縮停留時間。
- **逐字 / 逐詞進場**：從基線下方的遮罩裡彈上來（recipes.md 的「遮罩逐字」）、錯峰 30–50 毫秒。中文按字或按詞拆，不要按筆畫。
- **字是圖形**：字可以當遮罩、當容器、當網格、被切開、被拉伸、變成粒子。可變字型可以直接動畫字重（`font-variation-settings`）。
- **左對齊 + 網格**：居中大字是 AI 預設風格的頭號標誌。試試左對齊、貼網格、出血（字被畫面邊緣裁掉一部分）。
- **字要有自己的地盤**：字和繁忙的畫面（體塊、粒子、陣列）同屏時，先給字劃一塊禁入區，讓主體避開（stack.md 第 4 節）。字故意被遮擋（字在建築後面）也可以，但被擋住的部分不能超過一個字母，詞還能一眼讀出來。
- **數字要跳**：計數器用緩動滾動，配 tick 音效，在終值上用彈簧砸一下。
- **字型**：展示字型要有性格（Archivo、Space Grotesk、Syne、Unbounded、Instrument Serif、Fraunces 以外的襯線體、JetBrains Mono 做註釋）；中文用思源黑體 / 思源宋體 / 站酷系列這類可商用字型，按用到的字做子集（見 stack.md）。

## 8. 配色

- **2 + 1**：背景色、主色，再加一個只給「主角」用的強調色。主角是唯一帶強調色的元素，所以它一齣現觀眾就知道該看哪裡。
- **淺色背景被嚴重低估**：一份對上千支公開 Opus 5.5 影片的色彩統計裡，動態圖形 / 介面類有 57% 是深色中性、43% 是淺色中性。淺色並不少見，而且淺色（暖灰、米白、紙色）更容易做出編輯感和高階感，也更能跳出 AI 預設的「深色科技風」。
- **反色是現成的 drop**：在重拍上讓背景和前景互換 1–2 拍，幾乎不花成本就有衝擊力。
- **顏色可以當節奏**：強調色隨段落變化（每 4 小節換一個色相，相鄰色相過渡用 OKLab 插值，即 `motion.js` 的 `mix`）。
- **品牌色優先**。使用者給了品牌色就用品牌色，需要更多顏色時在 OKLab 裡推導明暗，不要憑空發明新的色相。

## 9. 質感層

質感是「高階」的最後 10%，但用錯了會很廉價。

| 質感 | 做法 | 什麼時候用 | 代價 |
|---|---|---|---|
| 膠片顆粒 | `render.mjs --grain 4–8`（在 ffmpeg 里加，不畫在頁面上） | 編輯感、電影感、淺色背景 | 幾乎沒有 |
| 運動模糊 | `--subframes 4` | 快速運動多 | 渲染時間 × 4 |
| 超取樣 | `--dpr 2` | 細線、小字、3D 邊緣有鋸齒 | 渲染時間約 × 3 |
| CRT / 掃描線 / 弧面 | WebGL 後期（recipes.md） | 復古遊戲、終端 | 中等 |
| 色差（chromatic aberration） | WebGL 後期，只在撞擊的 2–4 幀加強 | 衝擊、故障 | 中等 |
| 半調 / 網點 / 抖動 | WebGL 後期或 Canvas 像素操作 | 印刷感、復古 | 中等 |
| 光暈（bloom） | Three.js 後期或 WebGL 模糊疊加 | 3D、霓虹，**只給發光體** | 中到高 |
| 景深 | Three.js 後期或分層模糊 | 3D 產品、微距 | 高 |

**不要在頁面裡逐幀畫噪點**：每一幀都不可壓縮，編碼又慢又糊。用 `--grain`。

## 10. 簽名時刻選單

短片可集中設計一個清楚的記憶點，放在情緒最高處。長片按內容設理解落點，避免每章複製同一種 drop。要選能被一句話描述的手法：

- **粒子組字**：幾千個點從混沌中聚成 logo 或一個詞，再炸開（recipes.md 的「粒子組字」，無狀態寫法）。
- **一鏡到底的形變鏈**：一個形狀連續變成 8–12 個 UI 狀態，從不切鏡頭，每次變形都卡在拍點上（twoclipping 的 UI 變形模板就是這個思路）。
- **無限縮放**：每一層的一個細節就是下一層。
- **穿越進字母**：鏡頭衝進標題的一個孔，裡面是下一個世界。
- **媒介切換**：同一個主體，從像素 → 向量 → 3D → 手繪，每拍換一種（遊戲史短片的手法）。
- **3D 文字擠出 / 爆炸圖**：平面字在重拍上擠出成 3D，繞一圈再拍平。
- **液態 / 著色器轉場**：畫面像液體一樣流動著融進下一鏡。
- **資料爆點**：一個數字從 0 滾到終值，最後一位落定時整個畫面反色、震屏。
- **分屏複製**：同一個動作在 2 → 4 → 16 格里錯幀重複。
- **鏡面 / 萬花筒**：畫面在一拍內對稱複製成萬花筒。

## 11. 禁止清單：AI 預設味及替代方案

每支片子的 brief 裡都要寫具體的禁止項，從下面這份預設清單裡挑適用的，再加上這支片子特有的：

| 預設味 | 為什麼廉價 | 改成 |
|---|---|---|
| 深色背景 + 居中大字 + 漸變 | 沒有任何約束時 Opus 最容易出來的樣子 | 淺色背景或品牌色背景；左對齊網格；巨大的字出血 |
| 所有元素同時淡入淡出 | 沒有層次、沒有重量 | 錯峰 + 遮罩進場 + 彈簧；離場比進場快 |
| 紫 → 粉 → 藍漸變、到處發光 | AI 科技風的訓練集平均值 | 2+1 配色；光只給真正發光的東西 |
| 通用粒子爆炸、鏡頭光暈 | 模板感 | 粒子必須有目的（組字、跟隨、形成） |
| 勻速平移 | 機械 | 彈簧 / glide |
| 無意的機位固定、主體很小 | 畫面空、沒有能量 | 用鏡頭運動或版式變化製造能量；主體夠大 |
| 角落裡的 HUD 標籤、細邊框、偽資料 | 裝飾性噪音 | 刪掉；註釋只在有資訊時出現 |
| 滿屏小字、長句 | 手機上看不清 | 一屏一句，字號 ≥ 畫面高度的 4% |
| 彈跳緩動（bounce）到處用 | 廉價、玩具感 | 彈簧的阻尼 ≥ 0.6，只給俏皮元素 |
| emoji 當圖示、SVG 畫的人臉 | 業餘 | 抽象圖形；需要人物就走綠幕方案 |
| Inter / Roboto / Arial 做展示字型 | 像 demo 頁面 | 有性格的展示字型 |
| 循環的接縫處跳一下 | 一眼就能看出來 | 最後一幀 = 第一幀，包括速度 |

聲音也有自己的預設味（A 小調四踩、每個重拍都 impact + crash、鐘聲落版……），見 sound.md 第 12 節。

**例外**：品牌規範本身就這樣用（比如品牌就是深色 + 霓虹），或者使用者明確要求。這時候它就是品牌的簽名，不是 AI 味。
