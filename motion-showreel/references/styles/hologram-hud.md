# 全息空間介面（hologram-hud）

> 一個有空間關係的物件懸在暗處，線框、切面和標註圍繞它展開，資訊始終指得回物件。
> 參照（只學語法）：科幻空間介面、線框視覺化、體積掃描圖形。不照搬影視介面、軍用標識或具體產品螢幕。

## 本質 / 不是什麼

- 本質：**讓發光的資訊附著在可理解的三維空間裡**。物體有前後，標註有錨點，切面和掃描說明內部關係；觀眾移動視角後，仍能知道在看哪裡。
- 不是：`minimal-ui` 的暗色發光版，也不是 `synthwave-neon` 的裝飾霓虹。這裡的線、環、數值必須解釋物件，不能靠滿屏轉圈和亂碼偽裝技術。

## 辨識訊號：每支片子挑 2–3 個

| 訊號 | 長什麼樣 | 適合的主題 |
|---|---|---|
| 有深度的線框 | 前後邊線亮度不同，轉動後結構仍清楚 | 產品、系統、空間 |
| 錨定標註 | 引線一端貼住物件，另一端連著可讀標籤 | 功能、組成、定位 |
| 掃描切片 | 一張切面穿過物件，顯示經過處的資訊 | 檢查、內部、發現 |
| 區域性實體化 | 一部分由線框變成較實的面，周圍保留透視 | 重點、狀態、選中 |
| 深度分層 | 前景刻度、中心物件、遠處參照各有距離 | 層級、複雜系統 |
| 空間標尺 | 長度、方位或範圍依附物件的座標 | 尺度、方向、邊界 |
| 剖層懸開 | 不同結構層平行分開，引線維持對應 | 架構、模組、原理 |
| 受限殘影 | 掃描經過後留下短暫、逐漸消退的輪廓 | 檢測、路徑、變化 |
| 投射基準面 | 物件下方有弱網格或範圍面，幫助判斷位置 | 導航、部署、佈局 |
| 狀態區域性變色 | 一塊結構或一個連線變色，其餘保持原狀 | 診斷、進展、差異 |

規則：

- 每支挑 2–3 個，至少一個不在下面「最俗的版本」裡；訊號從主題裡選。
- 每一層介面都應回答一個具體問題。可用定性的狀態和示意結構，真實遙測、醫學或效能資料必須有來源。

## 這個風格最俗的版本

- 畫面：正中旋轉地球，四周青色同心圓，隨機百分比不斷跳動，最後一次掃描閃白。
- 聲音：持續低頻嗡鳴，每塊面板開啟都配蜂鳴和金屬衝擊。
- brief 的 style 一欄寫明翻掉了哪幾條，或者為什麼保留經典版。可選單個區域性剖層、暖色投射或少量固定標註。

## 適配

- 用途：技術概念片、產品結構講解、系統示意、科幻片頭、資料狀態展示。
- 內容：空間關係、探測、連線、複雜物件的分層理解。
- 不適合：還原真實操作介面的教程、大段文字閱讀，以及沒有依據卻要給出專業診斷結論的內容。

## 技術路線

- **空間物件**：Three.js 可作為線框、切面和深度關係的起點。探索簡化網格、邊線與區域性透明面，先保證單色下結構可讀。
- **標籤層**：SVG、Canvas 或 DOM 可承載文字與引線；標籤位置由空間錨點投影而來，再處理遮擋與避讓。必要時固定閱讀區，讓引線連線物件。
- **發光與掃描**：可探索 WebGL 的區域性亮度、深度衰減與後期泛光；PixiJS 適合較平面的 HUD 層。不要用一層全屏模糊同時糊掉文字和物體。
- 所有掃描進度、殘影歷史和物件姿態都從指定時刻還原，不依賴上幀累積。噪聲固定種子；`--dpr` 先保文字與細線，`--subframes` 從輕，`--grain` 不作為預設效果。

這些是候選工具，不規定投影演算法、著色器或現成 HUD 元件。

## 材質與渲染

- 視覺依據：這裡模擬的是科幻投射影像，不聲稱再現真實全息光學。用薄的發光面、線框和深度衰減建立規則，全片遵守同一套規則。
- 邊線有清楚的亮芯和有限光暈；前景邊、背面邊、輔助線拉開亮度，避免透明物體變成無從分辨的線團。
- 決定背面結構是被遮住、降低亮度還是用虛線顯示，按物件層級統一處理。透明度不能代替遮擋設計。
- 掃描影響經過的區域性，切面與物件相交處準確對齊；標註可讀時保持穩定，不能跟著掃光忽明忽暗。
- 發光可以輕微照到基準面，範圍隨物件位置變化。主體、連線線和標籤的空間歸屬明確，螢幕角落的輔助圖例則保持二維。

## 配色

下面的色值是示例，看思路，不要原樣照抄。

- 青色投射：底 `#101B27` / 主線 `#70D8DE` / 狀態 `#F0B66C`。
- 琥珀儀器：底 `#211D19` / 主線 `#E7BD73` / 輔助 `#A9C5B9`。
- 冷白與紅：底 `#18242D` / 主線 `#DCE7EA` / 狀態 `#D76A60`。
- 推導：選一個主發光色，用明度區分深度；強調色只給一類狀態。品牌色過暗時提亮線芯，不能只靠擴大光暈增加可見度。

## 字型

英文標題可選 Space Grotesk，數值與短標籤用 IBM Plex Mono，中文用思源黑體，均自託管 OFL 字型。文字不做逐行掃描和色散。短標題比標籤大一檔，數字按真實位數留空間，裝飾刻度不能冒充正文。

## 運動

- 物件轉動要慢到能認清結構，檢視某處時減速或停住。標籤隨錨點運動，但保持正向可讀，必要時淡出被遮擋的標籤。
- 面板按所解釋的結構出現，不讓所有環形元件一直各轉各的。掃描、剖切、狀態變化一次突出一個。
- 進場可先建立實體輪廓，再補資訊；退場可收回一個層級，也可讓投射有序熄滅。彈性只適合輕介面反饋，不用於整個空間物件。

## 畫面怎麼活

- 一個弱掃描面緩慢通過區域性，掃描完的物件保持穩定，不持續變換噪聲。
- 投射邊緣可有很小的亮度呼吸，文字和關鍵狀態不隨之閃爍。
- 有真實動態資料時按資料節奏更新對應區域；沒有資料時停住讀數，以輕微視差維持空間感。

## 鏡頭語法

| 鏡頭運動 | 表達什麼 | 適合哪類內容 |
|---|---|---|
| 小角度環繞後停住 | 確認空間結構 | 產品、系統、物體介紹 |
| 沿切面推進 | 從外部進入內部 | 原理、剖層、檢測 |
| 固定機位，圖層懸開 | 分辨組成與連線 | 架構、模組 |
| 從區域性退到基準面全貌 | 當前物件所在的位置 | 網路、部署、整體關係 |

## 聲音調色盤

第 1 檔可用柔和 FM 音、低音脈衝、短噪聲掃過與稀疏提示音。需要更細的空間聲場時，用第 2 檔 Tone.js 的合成與效果處理，音軌可離線重建。掃過聲跟切面經過的範圍走，提示音只對應有效狀態變化；口播下壓低持續嗡鳴與高頻蜂鳴。

律動與和聲（舉例，不止這些）：留有空隙的電子脈衝、緩慢變化的持續和聲，或輕快但不密集的技術感節奏。探索、展示、故障各有情緒，不統一用警戒音樂。

## 原生手法

- 掃描線經過，輪廓與區域性資訊顯現：適合探測和首次介紹（經典）。
- 剖層向外懸開，引線保留原來的連線：適合分層架構和內部結構。
- 某個區域性由透明線框變實，其他結構退暗：適合定位重點和狀態說明。
- 從空間物件的一張切面進入二維圖解：適合從概覽轉入詳細講解。
- 將一個區域性錨點擴充套件為下一張關係圖的中心：適合系統之間的連續轉場。

## 變化空間

- 結構：圍繞一個物件逐層檢查；沿連線從節點走到系統；比較同一物件的兩個狀態。
- 開場：只見一個有問題的區域性；先亮起基準面再出現物件；完整物件中逐漸分出資訊層。
- 結尾：收起輔助層留下重點；停在清楚的剖面總結；投射縮成下一個物件的錨點。

## 坑

- 數字看起來在工作卻沒有含義：刪掉裝飾讀數，真實資料標清來源和單位。
- 標籤與物件一起轉到背面：標籤面向觀眾，錨點保持空間位置，遮擋時隱藏或移位。
- 全部透明邊線同樣亮：先建立前後層級，再考慮泛光。
- 殘影依賴上一幀導致亂序渲染不同：按時間重建殘影片段。
- 所有物件、圓環和鏡頭同時轉：固定大部分參照，只動當前重點。
- 泛光讓文字白成一塊：文字單獨保持清晰，壓低光暈。
- 借示意視覺暗示真實檢測能力：用途與資料相符，概念場景明確標示意。
