# 油畫筆觸（painterly）

> 一幅會動的畫：每一筆都有方向、厚度和顏料的顆粒，光在畫布上流動，畫裡的東西輕輕地活著。
> 參照（只學語法）：印象派和後印象派的筆觸語言、厚塗（impasto）、外光派的光色、當代數字繪畫的筆刷動畫。不照搬具體畫作的構圖和名作的畫面。

## 本質 / 不是什麼
- 本質：**畫面是一筆一筆畫出來的**。形狀由筆觸組成，筆觸的方向跟著物體的結構和光走；顏色是一個區域裡幾種顏色的並置，不是一個平塗色加噪點；畫是活的，但筆觸不亂跳。
- 不是：照片加一個油畫濾鏡；也不是每幀重新隨機生成筆觸（那是閃爍，不是生命）。

## 辨識訊號：每支片子挑 2–3 個
| 訊號 | 長什麼樣 | 適合的主題 |
|---|---|---|
| 方向場筆觸 | 筆觸沿物體結構排列：天空旋轉、地面沿透視、牆面豎直 | 風景、空間 |
| 短促色點 | 冷暖交錯的短筆觸，遠看才混成顏色 | 光、空氣、戶外 |
| 厚塗 | 筆觸有厚度和高光，像顏料堆起來 | 質感、情感濃烈 |
| 區域色組 | 每個區域有 5–8 種相近的顏色交錯 | 一切 |
| 可見的畫布紋理 | 筆觸之間露出畫布的布紋 | 手工、真實 |
| 畫出來的過程 | 畫面一筆一筆被畫出來 | 開場、創作 |
| 光的流動 | 光斑在水面、樹葉上明滅 | 時間、情緒 |
| 粗輪廓線 | 深色的粗線勾出物體，線本身也是筆觸 | 表現力、強烈 |
| 刮刀痕 | 大塊平直的刮刀抹痕 | 現代、粗獷 |
| 未完成的邊緣 | 畫面邊緣留著沒畫完的底稿和畫布 | 過程、真誠 |

規則：
- 每支挑 2–3 個，至少一個不在下面「最俗的版本」裡。
- 訊號從主題裡選，不按順序全上。
- 學的是筆觸的語言，不是某一幅名畫：可以「像印象派那樣處理光」，但不要復刻名作的構圖。

## 這個風格最俗的版本
- 畫面：星空漩渦式的旋轉天空、向日葵、黃藍對比、一切都在打轉。
- 聲音：古典鋼琴或絃樂四重奏。
- brief 的 style 一欄寫明這支片子翻掉了哪幾條，或者為什麼刻意保留（比如使用者要的就是經典版）。保留時，把力氣花在構圖、鏡頭、節奏或一個意外的記憶點上。

## 適配
- 用途：品牌情緒片、片頭、文化和藝術類宣傳、節日和紀念、作品集裡的一段。
- 內容：藝術、文化、美食、旅行、季節、懷舊、高階手工品牌。
- 不適合：需要清晰傳達大量資訊的產品講解；文字很多的片子（筆觸會和小字打架）；渲染時間緊的專案（這種風格很慢）。

## 技術路線
Canvas 2D 兩步：先畫一張平塗的底稿（離屏，決定構圖和明暗），再用筆觸渲染器整幅重畫：在網格上撒筆觸（位置用固定種子，只算一次），每一筆從底稿取色、按區域色組偏移、沿方向場取角度，畫成帶深色邊的彎曲短條。小物件和主體單獨一層、用更細的筆觸畫，否則會被大筆觸打碎。靜態部分快取，每幀只重畫會動的區域。先在 960×540 測單幀耗時，常見 50–150 毫秒。

## 材質與渲染
- 方向場：按區域寫（天空沿雲的走向、水面橫向、牆豎直、地面沿透視），隨時間連續擺動，不按幀重新隨機。
- 區域色組：每個區域定 5–8 個相近的顏色，每一筆從組裡抽一個，再混 30–40% 底稿色保留明暗。只做顏色抖動會變成「同一個顏色的噪點」。
- 筆觸：長度、寬度隨區域變化（遠處短細、近處粗長），每一筆有很細的深色邊，厚塗時加一道高光邊。
- 畫布：底下一層布紋紋理，筆觸之間偶爾露出來。
- 主體：單獨一層、單獨引數，最後用一圈清晰的輪廓或高光把它從背景里拉出來。

## 配色
下面的色值是示例，看思路，不要原樣照抄。
- 外光：天藍 `#6FA8DC` / 草綠 `#93C47D` / 暖黃 `#F6D365` / 紫影 `#8E7CC3` / 畫布 `#EFE6D2`
- 暖室內：赭石 `#B5651D` / 深紅 `#7B2D26` / 金黃 `#E1B44C` / 橄欖 `#6B6B3A` / 暗褐 `#2B1D14`
- 冷夜：深藍 `#1B2A49` / 群青 `#3A5BA0` / 月黃 `#F2E2A0` / 墨綠 `#1F3B2D`
- 推導：先定光（外光、室內、夜晚），再給每個區域定色組：受光面偏暖、陰影偏冷（加一點補色），不要用黑色畫陰影。黃藍強對比是最常見的那組。

## 字型
筆觸畫面裡的字要少：標題用有手寫感或古典氣質的襯線（Cormorant Garamond、EB Garamond、Playfair Display），或者乾脆用筆刷畫出來；中文用思源宋體、霞鶩文楷。字放在畫面安靜的區域，或者放在一塊平塗的色塊上。

## 運動
- 筆觸的位置固定，運動來自方向場的連續擺動、光斑的移動和少數主體的動作。
- 開場可以「畫出來」：筆觸按區域順序在 0.5–1.5 秒內逐筆出現。
- 鏡頭慢推慢移，筆觸大小按螢幕像素定（推近時重畫，筆觸不跟著變粗）。
- 主體的動作可以步進（12fps），和筆觸的手工感一致。

## 畫面怎麼活
- 方向場隨時間緩慢搖曳，筆觸像被風吹動的草；水面和樹葉上的光斑明滅。
- 一兩個主體的小動作：一縷炊煙、一隻飛過的鳥、窗簾被風鼓起。
- 只給方向場和光做連續變化，整屏不要換種子重畫（那會讀成閃爍）。

## 鏡頭語法
| 鏡頭運動 | 表達什麼 | 適合哪類內容 |
|---|---|---|
| 極慢的推近到一處筆觸 | 走進畫裡 | 記憶點、細節 |
| 從畫框外拉進畫框內 | 畫活了 | 開場 |
| 橫移，像在美術館裡走過一幅長畫 | 時間、旅程 | 敘事 |
| 固定機位，只有光在變 | 一天、季節 | 情緒 |

## 聲音調色盤
原聲質感：第 2 檔的鋼琴取樣、`pluck` 模擬撥絃、柔和的 `pad` 當絃樂鋪底；環境聲（風、鳥、水）很適合。混響中等偏大。

律動與和聲（舉例，不止這些）：3/4 的圓舞曲感、慢速的分解和絃、無鼓；印象派的和聲色彩（大七、九和絃、全音階、平行和絃）；也可以反著用：筆觸畫面配一段現代電子樂，形成反差。

## 原生手法
- 畫面一筆一筆被畫出來：適合開場、「創作」類主題。
- 一個區域的筆觸旋轉、重組成下一鏡：適合轉場。
- 畫框外是現實（或另一種風格），鏡頭穿進畫框：適合「走進作品」。
- 光從一邊掃過，畫面從冷調變暖調：適合時間流逝。
- 星空漩渦加向日葵：經典，人人都會想到。

## 變化空間
- 結構：同一個場景從清晨畫到夜晚；一張空白畫布被畫滿；一個物件在四個季節裡各畫一次；畫家的視角，一筆一筆畫出產品。
- 開場：空白畫布上落下第一筆；一個畫框裡先是底稿，顏色一層層鋪上。
- 結尾：鏡頭拉遠，原來是掛在牆上的一幅畫，旁邊的標籤是 logo；顏料幹了，畫面定格。

## 坑
- 每幀重新隨機筆觸：整屏都在閃。筆觸位置固定，只讓方向場連續變化。
- 只做顏色抖動，沒有區域色組：畫面變成「同一個顏色的噪點」。
- 小物件和主體被大筆觸打碎：單獨一層、單獨引數。
- 渲染太慢：靜態部分快取，先測單幀耗時，開渲前報預計時間。
- 字壓在繁忙的筆觸上讀不清：字放在平塗區域，或者給字一塊安靜的底。
- 復刻名作構圖：只學筆觸和光的語言。
