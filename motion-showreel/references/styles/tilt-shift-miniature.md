# 移軸微縮（tilt-shift-miniature）

> 從稍高的角度看一個縮小的世界，清晰範圍落在正在發生的事上，周圍的景物逐漸失焦。
> 參照（只學語法）：移軸微縮攝影、實體沙盤、微縮佈景的定格與延時影像。不照搬具體城市沙盤、攝影構圖和模型資產。

## 本質 / 不是什麼

- 本質：**用觀察尺度、選擇性焦點和動作節奏，讓一個完整場景顯得微小**。建築、人物與道路的比例關係先成立，微縮感再來自高機位、有限的清晰範圍和可觀察的區域性活動。
- 不是：`soft-3d-toy` 的圓潤黏土世界，也不是 `isometric-infographic` 的無透檢視解。物件可以寫實或簡化，不能只給任意畫面上下加模糊就算完成。

## 辨識訊號：每支片子挑 2–3 個

| 訊號 | 長什麼樣 | 適合的主題 |
|---|---|---|
| 俯斜觀察 | 略高機位同時看見屋頂與立面 | 城市、園區、全域 |
| 窄清晰區 | 當前事件清楚，前後景逐漸變軟 | 注意力、區域性故事 |
| 微型活動 | 小人、車輛或器械沿有目的的路線行動 | 服務、交通、日常 |
| 時間壓縮 | 大動作略快，形成可讀的往返或輪換 | 流程、建設、一天 |
| 模型邊緣 | 區域效能看到底座、切口或佈景邊界 | 展示、方案、揭示 |
| 比例參照 | 人、門、車等常識尺度互相校準 | 空間、基礎設施 |
| 焦點接力 | 清晰範圍從一個事件移到另一個 | 多節點、講解、連線 |
| 微縮表面 | 牆面、樹冠和路面細節有所簡化 | 沙盤、品牌小世界 |
| 低處掠過 | 鏡頭短暫貼近小人物或物件，再回到高處 | 個體與系統 |
| 區域性燈光循環 | 路燈、窗燈或訊號燈沿真實邏輯變化 | 時間、執行、城市生活 |

規則：

- 每支挑 2–3 個，至少一個不在下面「最俗的版本」裡；訊號從主題裡選。
- 焦點跟著正在講的內容走，不強制橫向清晰帶。底座和延時是可選手法，微縮感不能只靠失焦。

## 這個風格最俗的版本

- 畫面：俯拍玩具小鎮，滿地糖果色小房子，車像螞蟻一樣繞圈，畫面上下糊成兩條帶。
- 聲音：木琴循環配輕快口哨，每輛車經過都來一下可愛音效。
- brief 的 style 一欄寫明翻掉了哪幾條，或者為什麼保留經典版。可以選夜間設施、區域性工作臺或安靜的自然場景。

## 適配

- 用途：服務流程講解、園區與城市概覽、品牌故事、產品使用場景、循環展示。
- 內容：區域性行動如何組成整體、一天的變化、空間組織、執行中的小系統。
- 不適合：密集 UI 操作、細小文字說明，或要求工程比例與視距精確測量的展示。

## 技術路線

- **三維佈景**：Three.js 可組織低複雜度場景、相機、燈光與景深；建模先考慮比例參照和活動路線，再增加細節。
- **景深**：可探索基於深度的後期處理；真要表現傾斜焦平面時，再研究相應著色方案。普通景深配合高機位也能形成微縮感，不把上下模糊遮罩當成完整光學模擬。
- **分層近似**：固定機位可用 Canvas 或 PixiJS 分開前、中、後景，分別控制清晰程度。侷限要明確：鏡頭大幅繞行時，平面近似容易暴露。
- 車輛、燈光與焦點位置都按時間獨立還原，佈景隨機分佈固定種子。`--dpr` 先保清晰區細節；時間壓縮的運動適量用 `--subframes`，逐格版本則減少；`--grain` 通常關閉。

以上是可選方向，不要求真實鏡頭模型或物理交通模擬。

## 材質與渲染

- 視覺依據：微縮攝影會同時給出尺度線索與有限景深；實體沙盤還會簡化材質和細節。先決定拍的是「像模型的世界」還是「確實有底座的模型」。
- 人、門、路寬和車尺寸保持一致。植被可以簡化，但樹不能無意中比樓層還小，路面紋理也不能像巨大的砂礫。
- 主體附近有接觸陰影，樓體有立面明暗；材料可以啞光，但不把全部物件做成同一種軟塑膠。
- 景深按物件距離連續變化，清晰區邊緣不出現硬帶；高物體穿過焦區時，應有合理的區域性清晰變化。
- 遠景保留大輪廓，不能糊到空間關係消失。字幕與圖例屬於畫外說明時保持清晰，不能隨場景一起失焦。

## 配色

下面的色值是示例，看思路，不要原樣照抄。

- 日光街區：環境 `#DCE5DD` / 建築 `#B97B59` / 植被 `#637C5D` / 焦點 `#D7B44B`。
- 夜間設施：環境 `#233843` / 主體 `#718C91` / 燈光 `#E4B96B`。
- 素色沙盤：環境 `#E7E1D4` / 主體 `#B9B6A8` / 強調 `#B95743`。
- 推導：先按場景分配環境、建築和活動物體的色組，再用品牌色標當前重點。避免所有小物件都高飽和；明暗和焦點應比顏色更先引導視線。

## 字型

英文可用 Manrope、Public Sans，中文用思源黑體，自託管 OFL 字型。主要說明放在畫面留白或固定字幕區，場內路牌只保留確需閱讀的短字。標題比場內標籤大兩檔左右，別把整篇說明塞進沙盤標牌。

## 運動

- 小物體的運動有目的地、轉彎和停靠；節奏可以略快，但沿路滑行的車不能穿樓，人物不能漂浮越過臺階。
- 選擇延時、正常速度或逐格作為主要節奏。焦點與鏡頭儘量平穩，避免三種速度同時互相爭搶。
- 進場可從區域性活動拉遠，或先見底座再進入場景；離場可沿路線移到下一個區域，不必每次旋轉整座小鎮。

## 畫面怎麼活

- 一兩輛車按不同週期經過，一輛停靠後再出發；週期與線路有差別，避免同步繞圈。
- 小範圍內有開門、燈亮或機構往復，動作只佔場景的一小部分。
- 自然題材可讓樹冠輕微擺動或水面細波經過；建築、地面與遠處模型保持穩定。

## 鏡頭語法

| 鏡頭運動 | 表達什麼 | 適合哪類內容 |
|---|---|---|
| 高位固定，區域性活動 | 觀察一個執行系統 | 城市、服務、循環 |
| 緩慢橫移，焦點隨事件交接 | 空間上的連續過程 | 物流、流程、線路 |
| 從低處拉到俯斜全景 | 個體與整體的關係 | 品牌、設施、故事 |
| 同機位改變焦點 | 相鄰事件之間的聯絡 | 對比、因果、講解 |

## 聲音調色盤

第 1 檔可用輕打擊、柔和貝斯、短撥絃與低密度環境噪聲。需要車輛、街道或工坊的真實聲景時，用第 2 檔 Tone.js 配合授權取樣；遠處聲更輕、更少高頻，近處事件才突出。時間壓縮無需把所有擬音一併加速變尖；口播出現時保留最少的定位聲。

律動與和聲（舉例，不止這些）：輕快而穩定的循環、夜間稀疏電子節拍，或沒有明顯鼓點的日常氛圍。微縮可以嚴謹、安靜或繁忙，不必一直賣萌。

## 原生手法

- 從真實尺度的區域性拉遠，露出微縮全貌：適合尺度揭示（經典）。
- 焦點沿一條路線接力，所到之處才變清楚：適合流程和空間講解。
- 鏡頭越過模型邊緣，從場景內部轉到工作臺：適合方案、製作與幕後。
- 同一機位壓縮時間，讓燈光或活動完成一次輪換：適合一天、執行和變化。
- 區域性設施抬起露出下面一層，活動路線繼續對應：適合基礎設施和服務原理。

## 變化空間

- 結構：跟隨一次運送；觀察一個地點的不同時段；在幾個相鄰區域之間交接重點。
- 開場：清晰區裡只有一個活動物體；先見模型切口；從近似正常尺度的區域性開始。
- 結尾：回到整體並留下少量活動；焦點停在最終目的地；沿路線接回最初的事件。

## 坑

- 只有上下模糊，場景仍像普通遊戲畫面：檢查機位、尺度參照與運動節奏。
- 景深糊掉正在講的物件：焦點先服從敘事，再追求攝影感。
- 模型處處圓潤變成軟萌玩具：保留建築硬邊與材料區別。
- 小人和車輛同步運動：錯開起點、停留與週期，但保持確定性。
- 過快的鏡頭加過窄清晰區讓人眩暈：減少鏡頭位移，給焦點交接留時間。
- 模糊跨越前後物體產生亮邊：檢查遮擋邊緣，必要時分層處理。
- 場內標籤小到看不見：把必要說明移到畫外閱讀區。
